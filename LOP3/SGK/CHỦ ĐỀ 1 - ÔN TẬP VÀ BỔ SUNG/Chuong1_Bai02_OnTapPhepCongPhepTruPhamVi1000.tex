\textbf{Phần 2. Trắc nghiệm đúng sai}
\setcounterpageref{ex}{0}

\begin{ex} %[3D1H02]
Xét tính đúng sai của các phép tính:
\choiceTF
{\True $230 + 170 = 400$.}
{\True $500 - 240 = 260$.}
{$456 + 123 = 569$.}
{\True $456 + 123 = 579$.}
\loigiai{
\begin{itemize}
    \item $230 + 170 = 400$: Đúng.
    \item $500 - 240 = 260$: Đúng.
    \item $456 + 123 = 579 \neq 569$. Ý 3 Sai, Ý 4 Đúng.
\end{itemize}
\begin{itemize}
    \item a) \textbf{Đúng}.
    \item b) \textbf{Đúng}.
    \item c) \textbf{Sai}.
    \item d) \textbf{Đúng}.
\end{itemize}
}
\end{ex}

\begin{ex} %[3D1V02]
Khối lớp 3 có 160 học sinh nam và 145 học sinh nữ. Xét tính đúng sai:
\choiceTF
{\True Toàn khối lớp 3 có tất cả 305 học sinh.}
{\True Số học sinh nam nhiều hơn số học sinh nữ là 15 bạn.}
{Số học sinh nữ ít hơn số học sinh nam là 25 bạn.}
{\True Nếu thêm 5 học sinh nữ thì tổng số học sinh là 310 bạn.}
\loigiai{
\begin{itemize}
    \item Tổng: $160 + 145 = 305$ học sinh. Đúng.
    \item Hiệu: $160 - 145 = 15$ bạn. Đúng.
    \item Nữ ít hơn nam 15 bạn (không phải 25). Sai.
    \item $305 + 5 = 310$ học sinh. Đúng.
\end{itemize}
\begin{itemize}
    \item a) \textbf{Đúng}.
    \item b) \textbf{Đúng}.
    \item c) \textbf{Sai}.
    \item d) \textbf{Đúng}.
\end{itemize}
}
\end{ex}

\textbf{Phần 3. Trả lời ngắn}
\setcounterpageref{ex}{0}

\begin{ex} %[3D1H02]
Tính tổng: $354 + 215$.
\shortans{569}
\loigiai{
\textbf{Đáp số:} $569$\\
$354 + 215 = 569$.
}
\end{ex}

\begin{ex} %[3D1H02]
Tính hiệu: $789 - 345$.
\shortans{444}
\loigiai{
\textbf{Đáp số:} $444$\\
$789 - 345 = 444$.
}
\end{ex}

\begin{ex} %[3D1V02]
Tính giá trị biểu thức: $500 - 150 + 230$.
\shortans{580}
\loigiai{
\textbf{Đáp số:} $580$\\
$350 + 230 = 580$.
}
\end{ex}

\begin{ex} %[3D1V02]
Thùng thứ nhất có $240\text{ l}$ dầu, thùng thứ hai có ít hơn thùng thứ nhất $60\text{ l}$ dầu. Hỏi cả hai thùng có tất cả bao nhiêu lít dầu?
\shortans{420}
\loigiai{
\textbf{Đáp số:} $420$\\
Thùng 2: $240 - 60 = 180\text{ l}$. Tổng: $240 + 180 = 420\text{ l}$.
}
\end{ex}

\begin{ex} %[3D1V02]
Tính nhanh: $145 + 280 + 55$.
\shortans{480}
\loigiai{
\textbf{Đáp số:} $480$\\
$(145 + 55) + 280 = 200 + 280 = 480$.
}
\end{ex}

\begin{ex} %[3D1C02]
Tổng của hai số là $650$. Nếu tăng số thứ nhất thêm $50$ đơn vị và giảm số thứ hai đi $30$ đơn vị thì tổng mới là bao nhiêu?
\shortans{670}
\loigiai{
\textbf{Đáp số:} $670$\\
Tổng mới: $650 + 50 - 30 = 670$.
}
\end{ex}
