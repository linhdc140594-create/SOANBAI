### BÀI 1 (2,0 ĐIỂM): CÁC PHÉP TÍNH VỚI PHÂN SỐ VÀ HỖN SỐ (0,5 ĐIỂM/Ý)
*(Mỗi ý gồm 6 dòng kẻ chấm mờ phủ kín ô để học sinh trình bày, không có chữ Bài làm)*

#### Mã đề 101:
* **a) (0,5đ):** $\dfrac{2}{3} + \dfrac{5}{6} = \dfrac{4}{6} + \dfrac{5}{6} = \dfrac{9}{6} = \dfrac{3}{2}$ (hoặc $1\dfrac{1}{2}$).
* **b) (0,5đ):** $2\dfrac{1}{4} - \dfrac{5}{8} = \dfrac{9}{4} - \dfrac{5}{8} = \dfrac{18}{8} - \dfrac{5}{8} = \dfrac{13}{8}$ (hoặc $1\dfrac{5}{8}$).
* **c) (0,5đ):** $\dfrac{3}{4} \times \dfrac{8}{9} = \dfrac{3 \times 8}{4 \times 9} = \dfrac{24}{36} = \dfrac{2}{3}$.
* **d) (0,5đ):** $\dfrac{5}{7} : \dfrac{10}{21} = \dfrac{5}{7} \times \dfrac{21}{10} = \dfrac{5 \times 21}{7 \times 10} = \dfrac{3}{2}$ (hoặc $1{,}5$).

#### Mã đề 102:
* **a) (0,5đ):** $\dfrac{3}{5} + \dfrac{7}{10} = \dfrac{6}{10} + \dfrac{7}{10} = \dfrac{13}{10} = 1{,}3$.
* **b) (0,5đ):** $3\dfrac{1}{2} - \dfrac{5}{6} = \dfrac{7}{2} - \dfrac{5}{6} = \dfrac{21}{6} - \dfrac{5}{6} = \dfrac{16}{6} = \dfrac{8}{3}$.
* **c) (0,5đ):** $\dfrac{4}{5} \times \dfrac{15}{16} = \dfrac{4 \times 15}{5 \times 16} = \dfrac{60}{80} = \dfrac{3}{4}$.
* **d) (0,5đ):** $\dfrac{6}{11} : \dfrac{9}{22} = \dfrac{6}{11} \times \dfrac{22}{9} = \dfrac{6 \times 22}{11 \times 9} = \dfrac{4}{3}$.

#### Mã đề 103:
* **a) (0,5đ):** $\dfrac{1}{4} + \dfrac{5}{8} = \dfrac{2}{8} + \dfrac{5}{8} = \dfrac{7}{8}$.
* **b) (0,5đ):** $2\dfrac{2}{3} - \dfrac{5}{9} = \dfrac{8}{3} - \dfrac{5}{9} = \dfrac{24}{9} - \dfrac{5}{9} = \dfrac{19}{9}$.
* **c) (0,5đ):** $\dfrac{5}{6} \times \dfrac{9}{10} = \dfrac{5 \times 9}{6 \times 10} = \dfrac{45}{60} = \dfrac{3}{4}$.
* **d) (0,5đ):** $\dfrac{4}{9} : \dfrac{8}{15} = \dfrac{4}{9} \times \dfrac{15}{8} = \dfrac{4 \times 15}{9 \times 8} = \dfrac{5}{6}$.

#### Mã đề 104:
* **a) (0,5đ):** $\dfrac{2}{7} + \dfrac{9}{14} = \dfrac{4}{14} + \dfrac{9}{14} = \dfrac{13}{14}$.
* **b) (0,5đ):** $3\dfrac{1}{3} - \dfrac{7}{12} = \dfrac{10}{3} - \dfrac{7}{12} = \dfrac{40}{12} - \dfrac{7}{12} = \dfrac{33}{12} = \dfrac{11}{4}$.
* **c) (0,5đ):** $\dfrac{7}{8} \times \dfrac{4}{21} = \dfrac{7 \times 4}{8 \times 21} = \dfrac{1}{6}$.
* **d) (0,5đ):** $\dfrac{8}{13} : \dfrac{12}{39} = \dfrac{8}{13} \times \dfrac{39}{12} = \dfrac{8 \times 39}{13 \times 12} = 2$.

### BÀI 3 (2,5 ĐIỂM): BÀI TOÁN HÌNH HỌC VÀ THỰC TẾ
*(Được đóng khung bao quanh kèm 13 dòng kẻ chấm mờ để học sinh trình bày thoải mái)*

#### Mã đề 101:
* **a) (1,0đ):**
  * Tổng số phần bằng nhau: $2 + 3 = 5$ (phần) *(0,25đ)*
  * Chiều rộng mảnh đất là: $60 : 5 \times 2 = 24\,\text{m}$ *(0,25đ)*
  * Chiều dài mảnh đất là: $60 - 24 = 36\,\text{m}$ *(0,5đ)*
* **b) (0,75đ):**
  * Diện tích mảnh đất là: $36 \times 24 = 864\,\text{m}^2$ *(0,5đ)*
  * Đổi sang héc-ta: $864\,\text{m}^2 = 0{,}0864\,\text{ha}$ *(0,25đ)*
* **c) (0,75đ):**
  * Diện tích đất trồng rau là: $864 \times \dfrac{3}{5} = 518{,}4\,\text{m}^2$ *(0,5đ)*
  * Đáp số: a) $36\,\text{m};\, 24\,\text{m}$; b) $864\,\text{m}^2;\, 0{,}0864\,\text{ha}$; c) $518{,}4\,\text{m}^2$ *(0,25đ)*

#### Mã đề 102:
* **a) (1,0đ):** Tổng số phần: $2 + 3 = 5$ (phần). Rộng: $75 : 5 \times 2 = 30\,\text{m}$; Dài: $75 - 30 = 45\,\text{m}$.
* **b) (0,75đ):** Diện tích thửa ruộng: $45 \times 30 = 1350\,\text{m}^2 = 0{,}135\,\text{ha}$.
* **c) (0,75đ):** Diện tích cấy lúa: $1350 \times \dfrac{4}{5} = 1080\,\text{m}^2$.

#### Mã đề 103:
* **a) (1,0đ):** Tổng số phần: $3 + 5 = 8$ (phần). Rộng: $80 : 8 \times 3 = 30\,\text{m}$; Dài: $80 - 30 = 50\,\text{m}$.
* **b) (0,75đ):** Diện tích khu đất: $50 \times 30 = 1500\,\text{m}^2 = 0{,}15\,\text{ha}$.
* **c) (0,75đ):** Diện tích làm nhà kho: $1500 \times \dfrac{2}{3} = 1000\,\text{m}^2$.

#### Mã đề 104:
* **a) (1,0đ):** Tổng số phần: $4 + 5 = 9$ (phần). Rộng: $90 : 9 \times 4 = 40\,\text{m}$; Dài: $90 - 40 = 50\,\text{m}$.
* **b) (0,75đ):** Diện tích vườn cây: $50 \times 40 = 2000\,\text{m}^2 = 0{,}2\,\text{ha}$.
* **c) (0,75đ):** Diện tích trồng bưởi: $2000 \times \dfrac{3}{4} = 1500\,\text{m}^2$.
