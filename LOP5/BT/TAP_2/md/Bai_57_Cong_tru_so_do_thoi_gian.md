# Bài 57: Cộng, trừ số đo thời gian

## PHẦN I. ĐỀ BÀI (NGÂN HÀNG CÂU HỎI ĐIỀN ĐÁP SỐ)

**Câu 1.** Tính: $3\text{ giờ } 15\text{ phút} + 2\text{ giờ } 30\text{ phút}$. Kết quả có số phút là bao nhiêu?

**Câu 2.** Tính: $4\text{ giờ } 35\text{ phút} + 1\text{ giờ } 40\text{ phút}$. Kết quả đổi thành bao nhiêu giờ $15$ phút?

**Câu 3.** Tính: $2\text{ ngày } 14\text{ giờ} + 3\text{ ngày } 18\text{ giờ}$. Kết quả có số giờ dư (sau khi đổi ngày) là bao nhiêu?

**Câu 4.** Tính: $5\text{ phút } 20\text{ giây} + 3\text{ phút } 45\text{ giây}$. Kết quả đổi thành bao nhiêu phút $5$ giây?

**Câu 5.** Tính: $7\text{ giờ } 45\text{ phút} - 3\text{ giờ } 20\text{ phút}$. Kết quả có số phút là bao nhiêu?

**Câu 6.** Tính: $5\text{ giờ } 15\text{ phút} - 2\text{ giờ } 40\text{ phút}$. Đổi $5\text{ giờ } 15\text{ phút} = 4\text{ giờ } 75\text{ phút}$. Kết quả có số phút là bao nhiêu?

**Câu 7.** Tính: $4\text{ phút } 10\text{ giây} - 1\text{ phút } 35\text{ giây}$. Kết quả có số giây là bao nhiêu?

**Câu 8.** Một người đi từ $A$ lúc $7\text{ giờ } 15\text{ phút}$ và đến $B$ lúc $9\text{ giờ } 45\text{ phút}$. Thời gian đi hết bao nhiêu phút?

**Câu 9.** Một trận bóng đá bắt đầu lúc $15\text{ giờ } 30\text{ phút}$, kéo dài $90$ phút và nghỉ giữa hiệp $15$ phút. Trận đấu kết thúc lúc mấy giờ $15$ phút?

**Câu 10.** Một ô tô khởi hành từ $A$ lúc $6\text{ giờ } 30\text{ phút}$, đi hết $2\text{ giờ } 45\text{ phút}$. Xe đến $B$ lúc mấy giờ $15$ phút?

**Câu 11.** Tính: $12\text{ năm } 6\text{ tháng} - 4\text{ năm } 8\text{ tháng}$. Kết quả có số tháng là bao nhiêu?

**Câu 12.** Tính: $8\text{ ngày } 6\text{ giờ} - 3\text{ ngày } 12\text{ giờ}$. Kết quả có số giờ là bao nhiêu?

**Câu 13.** Bạn Lan học bài từ $19\text{ giờ } 30\text{ phút}$ đến $21\text{ giờ } 10\text{ phút}$. Lan học trong bao nhiêu phút?

**Câu 14.** Một người thợ làm sản phẩm thứ nhất hết $1\text{ giờ } 20\text{ phút}$, làm sản phẩm thứ hai hết $1\text{ giờ } 35\text{ phút}$. Làm cả hai sản phẩm hết bao nhiêu phút?

**Câu 15.** Ở câu trên, sản phẩm thứ hai làm lâu hơn sản phẩm thứ nhất bao nhiêu phút?

**Câu 16.** Một người đi xe máy từ quê ra phố hết $3\text{ giờ } 15\text{ phút}$. Khi về người đó đi ô tô chỉ hết $2\text{ giờ } 30\text{ phút}$. Thời gian về nhanh hơn thời gian đi bao nhiêu phút?

**Câu 17.** Một cuộc thi chạy tiếp sức có 3 vận động viên: VĐV 1 chạy hết $45$ giây, VĐV 2 hết $48$ giây, VĐV 3 hết $47$ giây. Cả đội chạy hết bao nhiêu phút?

**Câu 18.** Tính: $15\text{ giờ } 20\text{ phút} + 4\text{ giờ } 50\text{ phút}$. Kết quả đổi thành bao nhiêu giờ $10$ phút?

**Câu 19.** Một tàu hỏa rời ga Hà Nội lúc $22\text{ giờ}$ đêm hôm trước và đến Vinh lúc $4\text{ giờ } 30\text{ phút}$ sáng hôm sau. Thời gian tàu chạy hết bao nhiêu phút?

**Câu 20.** Tính: $10\text{ phút } - 3\text{ phút } 40\text{ giây}$. Kết quả có số giây là bao nhiêu?

**Câu 21.** Tính: $6\text{ giờ } - 2\text{ giờ } 15\text{ phút}$. Kết quả có số phút là bao nhiêu?

**Câu 22.** Một ca làm việc bắt đầu lúc $8\text{ giờ}$ và kết thúc lúc $16\text{ giờ } 30\text{ phút}$, trong đó nghỉ trưa $1\text{ giờ } 30\text{ phút}$. Thời gian làm việc thực tế là bao nhiêu giờ?

**Câu 23.** Một chương trình truyền hình dự kiến chiếu $1\text{ giờ } 15\text{ phút}$ nhưng bị lố $18$ phút. Chương trình chiếu hết bao nhiêu phút?

**Câu 24.** Tính: $3\text{ ngày } 8\text{ giờ} + 1\text{ ngày } 16\text{ giờ}$. Kết quả là đúng bao nhiêu ngày?

**Câu 25.** Tính: $7\text{ giờ } 12\text{ phút} - 2\text{ giờ } 30\text{ phút}$. Kết quả có số phút là bao nhiêu?

## PHẦN II. ĐÁP ÁN VÀ LỜI GIẢI CHI TIẾT

### Câu 1
- **Đáp số:** `45`
- **Lời giải:** 15 + 30 = 45 phút.

### Câu 2
- **Đáp số:** `6`
- **Lời giải:** $5\text{ giờ } 75\text{ phút} = 6\text{ giờ } 15\text{ phút}$.

### Câu 3
- **Đáp số:** `8`
- **Lời giải:** $14 + 18 = 32\text{ giờ} = 1\text{ ngày } 8\text{ giờ}$. Số giờ là 8.

### Câu 4
- **Đáp số:** `9`
- **Lời giải:** $8\text{ phút } 65\text{ giây} = 9\text{ phút } 5\text{ giây}$.

### Câu 5
- **Đáp số:** `25`
- **Lời giải:** 45 - 20 = 25 phút.

### Câu 6
- **Đáp số:** `35`
- **Lời giải:** 75 - 40 = 35 phút.

### Câu 7
- **Đáp số:** `35`
- **Lời giải:** $3\text{ phút } 70\text{ giây} - 1\text{ phút } 35\text{ giây} = 2\text{ phút } 35\text{ giây}$.

### Câu 8
- **Đáp số:** `150`
- **Lời giải:** $9\text{ giờ } 45\text{ phút} - 7\text{ giờ } 15\text{ phút} = 2\text{ giờ } 30\text{ phút} = 150$ phút.

### Câu 9
- **Đáp số:** `17`
- **Lời giải:** Tổng thời gian là $105$ phút = $1\text{ giờ } 45\text{ phút}$. Kết thúc lúc $15\text{h}30 + 1\text{h}45 = 17\text{ giờ } 15\text{ phút}$.

### Câu 10
- **Đáp số:** `9`
- **Lời giải:** $6\text{h}30 + 2\text{h}45 = 8\text{h}75 = 9\text{ giờ } 15\text{ phút}$.

### Câu 11
- **Đáp số:** `10`
- **Lời giải:** $11\text{ năm } 18\text{ tháng} - 4\text{ năm } 8\text{ tháng} = 7\text{ năm } 10\text{ tháng}$.

### Câu 12
- **Đáp số:** `18`
- **Lời giải:** $7\text{ ngày } 30\text{ giờ} - 3\text{ ngày } 12\text{ giờ} = 4\text{ ngày } 18\text{ giờ}$.

### Câu 13
- **Đáp số:** `100`
- **Lời giải:** $21\text{h}10 - 19\text{h}30 = 1\text{ giờ } 40\text{ phút} = 100$ phút.

### Câu 14
- **Đáp số:** `175`
- **Lời giải:** $1\text{h}20 + 1\text{h}35 = 2\text{h}55 = 175$ phút.

### Câu 15
- **Đáp số:** `15`
- **Lời giải:** $35 - 20 = 15$ phút.

### Câu 16
- **Đáp số:** `45`
- **Lời giải:** $3\text{h}15 - 2\text{h}30 = 45$ phút.

### Câu 17
- **Đáp số:** `140`
- **Lời giải:** $45 + 48 + 47 = 140$ giây.

### Câu 18
- **Đáp số:** `20`
- **Lời giải:** $19\text{h}70 = 20\text{ giờ } 10\text{ phút}$.

### Câu 19
- **Đáp số:** `390`
- **Lời giải:** Từ 22h đến 24h là 2 giờ; từ 0h đến 4h30 là 4h30. Tổng là $6\text{ giờ } 30\text{ phút} = 390$ phút.

### Câu 20
- **Đáp số:** `20`
- **Lời giải:** $9\text{ phút } 60\text{ giây} - 3\text{ phút } 40\text{ giây} = 6\text{ phút } 20\text{ giây}$.

### Câu 21
- **Đáp số:** `45`
- **Lời giải:** $5\text{ giờ } 60\text{ phút} - 2\text{ giờ } 15\text{ phút} = 3\text{ giờ } 45\text{ phút}$.

### Câu 22
- **Đáp số:** `7`
- **Lời giải:** Tổng thời gian là 8h30. Trừ nghỉ 1h30 còn 7 giờ.

### Câu 23
- **Đáp số:** `93`
- **Lời giải:** $75 + 18 = 93$ phút.

### Câu 24
- **Đáp số:** `5`
- **Lời giải:** $4\text{ ngày } 24\text{ giờ} = 5\text{ ngày}$.

### Câu 25
- **Đáp số:** `42`
- **Lời giải:** $6\text{h}72 - 2\text{h}30 = 4\text{h}42$. Số phút là 42.
