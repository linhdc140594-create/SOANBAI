# Bài 58: Nhân, chia số đo thời gian với một số

## PHẦN I. ĐỀ BÀI (NGÂN HÀNG CÂU HỎI ĐIỀN ĐÁP SỐ)

**Câu 1.** Tính: $1\text{ giờ } 15\text{ phút} \times 3$. Kết quả có số phút là bao nhiêu?

**Câu 2.** Tính: $2\text{ giờ } 25\text{ phút} \times 3$. Đổi kết quả thành mấy giờ $15$ phút?

**Câu 3.** Tính: $3\text{ phút } 12\text{ giây} \times 4$. Kết quả có số giây là bao nhiêu?

**Câu 4.** Tính: $1\text{ ngày } 8\text{ giờ} \times 3$. Kết quả đúng bằng bao nhiêu ngày?

**Câu 5.** Một người thợ làm xong một chiếc ghế hết $1\text{ giờ } 45\text{ phút}$. Người đó làm $4$ chiếc ghế như thế hết bao nhiêu giờ?

**Câu 6.** Tính: $6\text{ giờ } 40\text{ phút} : 2$. Kết quả có số phút là bao nhiêu?

**Câu 7.** Tính: $7\text{ giờ } 30\text{ phút} : 3$. Kết quả là mấy giờ $30$ phút?

**Câu 8.** Tính: $9\text{ phút } 36\text{ giây} : 4$. Kết quả có số giây là bao nhiêu?

**Câu 9.** Một tổ may $5$ chiếc áo hết $7\text{ giờ } 30\text{ phút}$. Trung bình may một chiếc áo hết bao nhiêu phút?

**Câu 10.** Người ta đóng gói $6$ gói quà hết $1\text{ giờ } 12\text{ phút}$. Trung bình đóng mỗi gói hết bao nhiêu phút?

**Câu 11.** Một vận động viên hoàn thành $4$ vòng sân hết $8\text{ phút } 40\text{ giây}$. Trung bình mỗi vòng chạy hết bao nhiêu giây?

**Câu 12.** Tính: $2\text{ giờ } 15\text{ phút} \times 4$. Kết quả đúng bằng bao nhiêu giờ?

**Câu 13.** Tính: $15\text{ giờ } 45\text{ phút} : 5$. Kết quả có số phút là bao nhiêu?

**Câu 14.** Bác An đóng $8$ cái bàn hết $20$ giờ. Hỏi trung bình đóng một cái bàn hết bao nhiêu phút?

**Câu 15.** Tính: $4\text{ ngày } 12\text{ giờ} \times 2$. Kết quả bằng bao nhiêu ngày?

**Câu 16.** Tính: $13\text{ giờ } 20\text{ phút} : 4$. Kết quả là mấy giờ $20$ phút?

**Câu 17.** Một máy in in $50$ trang sách hết $2\text{ phút } 30\text{ giây}$. Để in $100$ trang sách như thế hết bao nhiêu giây?

**Câu 18.** Một máy bơm bơm $3$ bể nước như nhau hết $4\text{ giờ } 30\text{ phút}$. Bơm mỗi bể hết bao nhiêu phút?

**Câu 19.** Tính: $2\text{ phút } 45\text{ giây} \times 4$. Kết quả bằng bao nhiêu phút?

**Câu 20.** Tính: $21\text{ phút } 15\text{ giây} : 3$. Kết quả có số giây là bao nhiêu?

**Câu 21.** Một ca nô đi $3$ chuyến hết $4\text{ giờ } 15\text{ phút}$. Hỏi ca nô đi $6$ chuyến như thế hết bao nhiêu phút?

**Câu 22.** Một người thợ làm việc $8$ giờ mỗi ngày, làm trong $5$ ngày được trả $2$ triệu đồng. Mỗi giờ làm việc được bao nhiêu nghìn đồng?

**Câu 23.** Tính: $(1\text{ giờ } 20\text{ phút} + 2\text{ giờ } 10\text{ phút}) \times 2$. Kết quả có số phút là bao nhiêu?

**Câu 24.** Tính: $(5\text{ giờ } 30\text{ phút} - 1\text{ giờ } 50\text{ phút}) : 2$. Kết quả có số phút là bao nhiêu?

**Câu 25.** Bác Bình đi bộ $3$ vòng công viên hết $45$ phút. Nếu đi $5$ vòng như thế hết bao nhiêu phút?

---

## PHẦN II. ĐÁP ÁN VÀ LỜI GIẢI CHI TIẾT

### Câu 1
- **Đáp số:** `45`
- **Lời giải:** $1\text{h} \times 3 = 3\text{h}$; $15 \times 3 = 45$ phút.

### Câu 2
- **Đáp số:** `7`
- **Lời giải:** $6\text{ giờ } 75\text{ phút} = 7\text{ giờ } 15\text{ phút}$.

### Câu 3
- **Đáp số:** `48`
- **Lời giải:** $12 \times 4 = 48$ giây.

### Câu 4
- **Đáp số:** `4`
- **Lời giải:** $3\text{ ngày } 24\text{ giờ} = 4\text{ ngày}$.

### Câu 5
- **Đáp số:** `7`
- **Lời giải:** $1\text{h}45 \times 4 = 4\text{h}180\text{ phút} = 7\text{ giờ}$.

### Câu 6
- **Đáp số:** `20`
- **Lời giải:** $40 : 2 = 20$ phút.

### Câu 7
- **Đáp số:** `2`
- **Lời giải:** $7\text{h} : 3 = 2\text{h}$ dư 1h (60 phút); $90 : 3 = 30$ phút. Kết quả $2\text{h}30$.

### Câu 8
- **Đáp số:** `24`
- **Lời giải:** $9\text{ phút} : 4 = 2\text{ phút}$ dư 1 phút (60 giây); $96 : 4 = 24$ giây.

### Câu 9
- **Đáp số:** `90`
- **Lời giải:** $7\text{ giờ } 30\text{ phút} = 450$ phút. $450 : 5 = 90$ phút.

### Câu 10
- **Đáp số:** `12`
- **Lời giải:** $72\text{ phút} : 6 = 12$ phút.

### Câu 11
- **Đáp số:** `130`
- **Lời giải:** $8\text{ phút } 40\text{ giây} = 520$ giây. $520 : 4 = 130$ giây.

### Câu 12
- **Đáp số:** `9`
- **Lời giải:** $8\text{ giờ } 60\text{ phút} = 9\text{ giờ}$.

### Câu 13
- **Đáp số:** `9`
- **Lời giải:** $45 : 5 = 9$ phút.

### Câu 14
- **Đáp số:** `150`
- **Lời giải:** $20\text{ giờ} = 1\,200$ phút; $1\,200 : 8 = 150$ phút.

### Câu 15
- **Đáp số:** `9`
- **Lời giải:** $8\text{ ngày } 24\text{ giờ} = 9\text{ ngày}$.

### Câu 16
- **Đáp số:** `3`
- **Lời giải:** $13\text{h} : 4 = 3\text{h}$ dư 1h (60 phút); $80 : 4 = 20$ phút. Kết quả là $3\text{h}20$.

### Câu 17
- **Đáp số:** `300`
- **Lời giải:** $150 \times 2 = 300$ giây.

### Câu 18
- **Đáp số:** `90`
- **Lời giải:** $270 : 3 = 90$ phút.

### Câu 19
- **Đáp số:** `11`
- **Lời giải:** $8\text{ phút } 180\text{ giây} = 11\text{ phút}$.

### Câu 20
- **Đáp số:** `5`
- **Lời giải:** $15 : 3 = 5$ giây.

### Câu 21
- **Đáp số:** `510`
- **Lời giải:** $4\text{h}15 = 255$ phút. $255 \times 2 = 510$ phút.

### Câu 22
- **Đáp số:** `50`
- **Lời giải:** Tổng số giờ là $8 \times 5 = 40$ giờ. $2\,000 : 40 = 50$ nghìn đồng.

### Câu 23
- **Đáp số:** `0`
- **Lời giải:** $3\text{h}30 \times 2 = 7\text{ giờ } 0\text{ phút}$. Số phút là 0.

### Câu 24
- **Đáp số:** `50`
- **Lời giải:** $3\text{h}40 : 2 = 1\text{ giờ } 50\text{ phút}$.

### Câu 25
- **Đáp số:** `75`
- **Lời giải:** Mỗi vòng hết $45 : 3 = 15$ phút. $5$ vòng hết $15 \times 5 = 75$ phút.
