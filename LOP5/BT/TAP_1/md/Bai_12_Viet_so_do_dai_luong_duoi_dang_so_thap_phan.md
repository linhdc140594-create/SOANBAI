# Bài 12: Viết số đo đại lượng dưới dạng số thập phân

## PHẦN I. ĐỀ BÀI (NGÂN HÀNG CÂU HỎI ĐIỀN ĐÁP SỐ)

**Câu 1.** Viết số đo $3\text{ m } 5\text{ dm}$ dưới dạng số thập phân có đơn vị mét là $3{,}a\text{ m}$. Chữ số $a$ là bao nhiêu?

**Câu 2.** Viết số đo $4\text{ m } 25\text{ cm}$ dưới dạng số thập phân có đơn vị mét là $4{,}bc\text{ m}$. Tổng hai chữ số $b + c$ là bao nhiêu?

**Câu 3.** Viết số đo $8\text{ cm } 6\text{ mm}$ dưới dạng số thập phân có đơn vị xăng-ti-mét là $8{,}6\text{ cm}$. Chữ số hàng phần mười là bao nhiêu?

**Câu 4.** Viết số đo $2\text{ km } 350\text{ m}$ dưới dạng số thập phân có đơn vị ki-lô-mét là $2{,}35\text{ km}$. Chữ số hàng phần trăm là bao nhiêu?

**Câu 5.** Viết số đo $7\text{ km } 45\text{ m}$ dưới dạng số thập phân có đơn vị ki-lô-mét là $7{,}045\text{ km}$. Chữ số hàng phần mười của số này là bao nhiêu?

**Câu 6.** Viết số đo $5\text{ tấn } 8\text{ tạ}$ dưới dạng số thập phân có đơn vị tấn là $5{,}8\text{ tấn}$. Chữ số hàng phần mười là bao nhiêu?

**Câu 7.** Viết số đo $3\text{ tấn } 250\text{ kg}$ dưới dạng số thập phân có đơn vị tấn là $3{,}25\text{ tấn}$. Chữ số hàng phần mười là bao nhiêu?

**Câu 8.** Viết số đo $6\text{ tấn } 50\text{ kg}$ dưới dạng số thập phân có đơn vị tấn là $6{,}05\text{ tấn}$. Chữ số hàng phần trăm là bao nhiêu?

**Câu 9.** Viết số đo $4\text{ kg } 75\text{ g}$ dưới dạng số thập phân có đơn vị ki-lô-gam là $4{,}075\text{ kg}$. Chữ số hàng phần nghìn là bao nhiêu?

**Câu 10.** Viết số đo $12\text{ kg } 8\text{ g}$ dưới dạng số thập phân có đơn vị ki-lô-gam là $12{,}008\text{ kg}$. Chữ số hàng phần trăm là bao nhiêu?

**Câu 11.** Viết số đo $5\text{ m}^2\text{ } 35\text{ dm}^2$ dưới dạng số thập phân có đơn vị mét vuông là $5{,}35\text{ m}^2$. Chữ số hàng phần mười là bao nhiêu?

**Câu 12.** Viết số đo $8\text{ m}^2\text{ } 7\text{ dm}^2$ dưới dạng số thập phân có đơn vị mét vuông là $8{,}07\text{ m}^2$. Chữ số hàng phần trăm là bao nhiêu?

**Câu 13.** Viết số đo $15\text{ dm}^2\text{ } 8\text{ cm}^2$ dưới dạng số thập phân có đơn vị đề-xi-mét vuông là $15{,}08\text{ dm}^2$. Chữ số hàng phần mười là bao nhiêu?

**Câu 14.** Đổi $4{,}5\text{ m}$ thành bao nhiêu đề-xi-mét?

**Câu 15.** Đổi $2{,}75\text{ m}$ thành bao nhiêu xăng-ti-mét?

**Câu 16.** Đổi $1{,}5\text{ km}$ thành bao nhiêu mét?

**Câu 17.** Đổi $0{,}75\text{ tấn}$ thành bao nhiêu ki-lô-gam?

**Câu 18.** Đổi $3{,}2\text{ tạ}$ thành bao nhiêu yến?

**Câu 19.** Đổi $2{,}5\text{ m}^2$ thành bao nhiêu đề-xi-mét vuông?

**Câu 20.** Đổi $0{,}08\text{ m}^2$ thành bao nhiêu xăng-ti-mét vuông?

**Câu 21.** Một sợi dây dài $3\text{ m } 60\text{ cm}$ được cắt thành các đoạn dài $0{,}9\text{ m}$. Cắt được bao nhiêu đoạn?

**Câu 22.** Một con bò nặng $3\text{ tạ } 50\text{ kg}$. Viết khối lượng con bò dưới dạng số thập phân có đơn vị tấn là $0{,}35\text{ tấn}$. Chữ số hàng phần trăm là bao nhiêu?

**Câu 23.** Một khu đất hình chữ nhật có chiều dài $20\text{ m}$, chiều rộng $15\text{ m}$. Diện tích khu đất viết dưới dạng số thập phân có đơn vị héc-ta là $0{,}03\text{ ha}$. Chữ số hàng phần trăm là bao nhiêu?

**Câu 24.** Viết số đo $500\text{ m}$ dưới dạng số thập phân có đơn vị ki-lô-mét là $0{,}5\text{ km}$. Phần nguyên của số đó là bao nhiêu?

**Câu 25.** Một mảnh vườn có chu vi $48\text{ m}$. Nửa chu vi mảnh vườn đổi ra ki-lô-mét là $0{,}024\text{ km}$. Chữ số hàng phần nghìn là bao nhiêu?

## PHẦN II. ĐÁP ÁN VÀ LỜI GIẢI CHI TIẾT

### Câu 1
- **Đáp số:** `5`
- **Lời giải:** $3\text{ m } 5\text{ dm} = 3\frac{5}{10}\text{ m} = 3{,}5\text{ m}$. Chữ số $a$ là 5.

### Câu 2
- **Đáp số:** `7`
- **Lời giải:** $4\text{ m } 25\text{ cm} = 4\frac{25}{100}\text{ m} = 4{,}25\text{ m}$. Tổng là $2 + 5 = 7$.

### Câu 3
- **Đáp số:** `6`
- **Lời giải:** $8\text{ cm } 6\text{ mm} = 8{,}6\text{ cm}$. Chữ số hàng phần mười là 6.

### Câu 4
- **Đáp số:** `5`
- **Lời giải:** $2\text{ km } 350\text{ m} = 2{,}35\text{ km}$. Chữ số hàng phần trăm là 5.

### Câu 5
- **Đáp số:** `0`
- **Lời giải:** $7\text{ km } 45\text{ m} = 7\frac{45}{1000}\text{ km} = 7{,}045\text{ km}$. Chữ số hàng phần mười là 0.

### Câu 6
- **Đáp số:** `8`
- **Lời giải:** $5\text{ tấn } 8\text{ tạ} = 5{,}8\text{ tấn}$. Chữ số hàng phần mười là 8.

### Câu 7
- **Đáp số:** `2`
- **Lời giải:** $3\text{ tấn } 250\text{ kg} = 3{,}25\text{ tấn}$. Chữ số hàng phần mười là 2.

### Câu 8
- **Đáp số:** `5`
- **Lời giải:** $6\text{ tấn } 50\text{ kg} = 6\frac{50}{1000}\text{ tấn} = 6{,}05\text{ tấn}$. Chữ số hàng phần trăm là 5.

### Câu 9
- **Đáp số:** `5`
- **Lời giải:** $4\text{ kg } 75\text{ g} = 4{,}075\text{ kg}$. Chữ số hàng phần nghìn là 5.

### Câu 10
- **Đáp số:** `0`
- **Lời giải:** $12\text{ kg } 8\text{ g} = 12{,}008\text{ kg}$. Chữ số hàng phần trăm là 0.

### Câu 11
- **Đáp số:** `3`
- **Lời giải:** $5\text{ m}^2\text{ } 35\text{ dm}^2 = 5{,}35\text{ m}^2$. Chữ số hàng phần mười là 3.

### Câu 12
- **Đáp số:** `7`
- **Lời giải:** $8\text{ m}^2\text{ } 7\text{ dm}^2 = 8\frac{7}{100}\text{ m}^2 = 8{,}07\text{ m}^2$. Chữ số hàng phần trăm là 7.

### Câu 13
- **Đáp số:** `0`
- **Lời giải:** $15\text{ dm}^2\text{ } 8\text{ cm}^2 = 15{,}08\text{ dm}^2$. Chữ số hàng phần mười là 0.

### Câu 14
- **Đáp số:** `45`
- **Lời giải:** $4{,}5\text{ m} = 4{,}5 \times 10 = 45\text{ dm}$.

### Câu 15
- **Đáp số:** `275`
- **Lời giải:** $2{,}75\text{ m} = 2{,}75 \times 100 = 275\text{ cm}$.

### Câu 16
- **Đáp số:** `1500`
- **Lời giải:** $1{,}5\text{ km} = 1{,}5 \times 1\,000 = 1\,500\text{ m}$.

### Câu 17
- **Đáp số:** `750`
- **Lời giải:** $0{,}75\text{ tấn} = 0{,}75 \times 1\,000 = 750\text{ kg}$.

### Câu 18
- **Đáp số:** `32`
- **Lời giải:** $3{,}2\text{ tạ} = 3{,}2 \times 10 = 32\text{ yến}$.

### Câu 19
- **Đáp số:** `250`
- **Lời giải:** $2{,}5\text{ m}^2 = 2{,}5 \times 100 = 250\text{ dm}^2$.

### Câu 20
- **Đáp số:** `800`
- **Lời giải:** $0{,}08\text{ m}^2 = 0{,}08 \times 10\,000 = 800\text{ cm}^2$.

### Câu 21
- **Đáp số:** `4`
- **Lời giải:** $3\text{ m } 60\text{ cm} = 3{,}6\text{ m}$. Số đoạn là: $3{,}6 : 0{,}9 = 4$ (đoạn).

### Câu 22
- **Đáp số:** `5`
- **Lời giải:** $3\text{ tạ } 50\text{ kg} = 350\text{ kg} = 0{,}35\text{ tấn}$. Chữ số hàng phần trăm là 5.

### Câu 23
- **Đáp số:** `3`
- **Lời giải:** Diện tích là $20 \times 15 = 300\text{ m}^2 = \frac{300}{10000}\text{ ha} = 0{,}03\text{ ha}$. Chữ số hàng phần trăm là 3.

### Câu 24
- **Đáp số:** `0`
- **Lời giải:** Phần nguyên là 0.

### Câu 25
- **Đáp số:** `4`
- **Lời giải:** Nửa chu vi là $24\text{ m} = 0{,}024\text{ km}$. Chữ số hàng phần nghìn là 4.
