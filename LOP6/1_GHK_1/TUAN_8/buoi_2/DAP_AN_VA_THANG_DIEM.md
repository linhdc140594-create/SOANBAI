### CÂU 13 (1,5 ĐIỂM). BÀI TOÁN THỰC TẾ ỨNG DỤNG ƯCLN

* **Mã đề 101:**
  * **a) (0,75đ):** Gọi số tổ nhiều nhất có thể chia là $a$ ($a \in \mathbb{N}^*$).
    * Theo bài ra ta có: $24 \ \vdots \ a$, $36 \ \vdots \ a$ và $a$ lớn nhất nên $a = \text{ƯCLN}(24, 36)$ ($0{,}25$đ).
    * Phân tích ra thừa số nguyên tố: $24 = 2^3 \cdot 3$; $36 = 2^2 \cdot 3^2 \implies \text{ƯCLN}(24, 36) = 2^2 \cdot 3 = 12$ ($0{,}25$đ).
    * Vậy có thể chia được nhiều nhất thành $12$ tổ ($0{,}25$đ).
  * **b) (0,75đ):**
    * Khi đó, mỗi tổ có số bạn nam là: $24 : 12 = 2$ (bạn) ($0{,}375$đ).
    * Mỗi tổ có số bạn nữ là: $36 : 12 = 3$ (bạn) ($0{,}375$đ).

* **Mã đề 102:**
  * **a) (0,75đ):** Số tổ nhiều nhất là $\text{ƯCLN}(28, 42) = 14$ tổ.
  * **b) (0,75đ):** Mỗi tổ có $28 : 14 = 2$ bạn nam và $42 : 14 = 3$ bạn nữ.

* **Mã đề 103:**

  * **b) (0,75đ):** Mỗi nhóm có $32 : 16 = 2$ bạn nam và $48 : 16 = 3$ bạn nữ.

* **Mã đề 104:**

### CÂU 14 (1,0 ĐIỂM). BÀI TOÁN PHÂN LOẠI HỌC SINH GIỎI

* **Mã đề 101:** Cho $A = 2 + 2^2 + 2^3 + \dots + 2^{60}$.
  * Tổng $A$ có $60$ số hạng, ta nhóm $3$ số hạng liên tiếp thành một nhóm:
    $$A = (2 + 2^2 + 2^3) + 2^3(2 + 2^2 + 2^3) + \dots + 2^{57}(2 + 2^2 + 2^3)$$ ($0{,}5$đ)
    $$= 14 + 2^3 \cdot 14 + \dots + 2^{57} \cdot 14 = 14 \cdot (1 + 2^3 + \dots + 2^{57})$$ ($0{,}25$đ)
  * Vì $14 \ \vdots \ 7$ nên $A \ \vdots \ 7$ (đpcm) ($0{,}25$đ).

* **Mã đề 102:** Cho $B = 3 + 3^2 + 3^3 + \dots + 3^{60}$:
  * $B = (3 + 3^2 + 3^3) + 3^3(3 + 3^2 + 3^3) + \dots + 3^{57}(3 + 3^2 + 3^3)$
  * $= 39 \cdot (1 + 3^3 + \dots + 3^{57})$. Vì $39 \ \vdots \ 13$ nên $B \ \vdots \ 13$ (đpcm).

* **Mã đề 103:** Cho $C = 4 + 4^2 + 4^3 + \dots + 4^{60}$:
  * $C = (4 + 4^2 + 4^3) + 4^3(4 + 4^2 + 4^3) + \dots + 4^{57}(4 + 4^2 + 4^3)$
  * $= 84 \cdot (1 + 4^3 + \dots + 4^{57})$. Vì $84 \ \vdots \ 21$ nên $C \ \vdots \ 21$ (đpcm).

* **Mã đề 104:** Cho $D = 5 + 5^2 + 5^3 + \dots + 5^{60}$:
  * $D = (5 + 5^2 + 5^3) + 5^3(5 + 5^2 + 5^3) + \dots + 5^{57}(5 + 5^2 + 5^3)$
  * $= 155 \cdot (1 + 5^3 + \dots + 5^{57})$. Vì $155 \ \vdots \ 31$ nên $D \ \vdots \ 31$ (đpcm).
