### CÂU 14 (1,0 ĐIỂM). BÀI TOÁN PHÂN LOẠI HỌC SINH GIỎI

* **Mã đề 101:** Tổng $A = 1 + 3 + 3^2 + 3^3 + \dots + 3^{21}$ có $22$ số hạng.
  * Ta nhóm $2$ số hạng liền nhau:
    $$A = (1 + 3) + 3^2(1 + 3) + 3^4(1 + 3) + \dots + 3^{20}(1 + 3)$$ ($0{,}5$đ)
    $$= 4 \cdot (1 + 3^2 + 3^4 + \dots + 3^{20})$$ ($0{,}25$đ)
  * Vì $4 \ \vdots \ 4$ nên $A \ \vdots \ 4$ (đpcm) ($0{,}25$đ).

* **Mã đề 102:** Tổng $B = 1 + 4 + 4^2 + \dots + 4^{21}$ có $22$ số hạng:
  * $B = (1 + 4) + 4^2(1 + 4) + \dots + 4^{20}(1 + 4) = 5 \cdot (1 + 4^2 + \dots + 4^{20})$.
  * Vì $5 \ \vdots \ 5$ nên $B \ \vdots \ 5$ (đpcm).

* **Mã đề 103:** Tổng $C = 1 + 5 + 5^2 + \dots + 5^{21}$ có $22$ số hạng:
  * $C = (1 + 5) + 5^2(1 + 5) + \dots + 5^{20}(1 + 5) = 6 \cdot (1 + 5^2 + \dots + 5^{20})$.
  * Vì $6 \ \vdots \ 6$ nên $C \ \vdots \ 6$ (đpcm).

* **Mã đề 104:** Tổng $D = 1 + 2 + 2^2 + \dots + 2^{23}$ có $24$ số hạng:
  * $D = (1 + 2) + 2^2(1 + 2) + \dots + 2^{22}(1 + 2) = 3 \cdot (1 + 2^2 + \dots + 2^{22})$.
  * Vì $3 \ \vdots \ 3$ nên $D \ \vdots \ 3$ (đpcm).
