  title={\footnotesize\bfseries\color{white}\faKey\ 1. Giới thiệu các đơn vị đo độ dài}
]
{\footnotesize
\begin{itemize}\setlength{\itemsep}{1pt}\setlength{\leftskip}{-2.5mm}
  \item \textbf{Đề-xi-mét (viết tắt là $dm$):}\\
  Dùng đo độ dài gang tay, quyển sách, cái bảng nhỏ.
  \item \textbf{Mét (viết tắt là $m$):}\\
  Đơn vị đo độ dài cơ bản. Dùng đo chiều cao phòng học, cột cờ, độ dài cái sân, ngôi nhà.
  \item \textbf{Ki-lô-mét (viết tắt là $km$):}\\
  Đơn vị đo khoảng cách lớn: khoảng cách giữa hai thành phố, hai tỉnh, con đường dài.
\end{itemize}
}
\end{tcolorbox}
\end{minipage}

  title={\footnotesize\bfseries\color{white}\faSliders\ 2. Bảng chuyển đổi đơn vị đo độ dài}
]
{\footnotesize
\begin{itemize}\setlength{\itemsep}{1pt}\setlength{\leftskip}{-2.5mm}
  \item \textbf{Mối quan hệ giữa các đơn vị:}
  $$\mathbf{1\,dm = 10\,cm} \quad\iff\quad 10\,cm = 1\,dm$$
  $$\mathbf{1\,m = 10\,dm} \quad\iff\quad 1\,m = 100\,cm$$
  $$\mathbf{1\,km = 1\,000\,m}$$
  \item \textbf{Quy tắc tính toán với đơn vị đo:}
  \begin{itemize}\setlength{\itemsep}{0.5pt}\setlength{\leftskip}{-2mm}
    \item Phải đưa về \textbf{cùng đơn vị đo} trước khi cộng hoặc trừ.
    \item Viết kèm tên đơn vị vào kết quả phép tính.
    \item \textit{Ví dụ:} $40\,m + 25\,m = \mathbf{65\,m}$.
  \end{itemize}
\end{itemize}
}
\end{tcolorbox}
\end{minipage}

\textbf{1. Đổi đơn vị đo:}\\
- $3\,m = \mathbf{30}\,dm = \mathbf{300}\,cm$.\\
- $50\,dm = \mathbf{5}\,m$; \quad $2\,km = \mathbf{2\,000}\,m$.\\
- $4\,m\ 5\,dm = 40\,dm + 5\,dm = \mathbf{45\,dm}$.\\
\textbf{2. Tính toán kèm tên đơn vị:}\\
- $35\,m + 18\,m = \mathbf{53\,m}$.\\
- $100\,km - 45\,km = \mathbf{55\,km}$.\\
- $5\,m \times 4 = \mathbf{20\,m}$.
