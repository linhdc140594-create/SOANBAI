\textbf{Phần 2. Trắc nghiệm đúng sai}
\setcounterpageref{ex}{0}

\begin{ex} %[2D4H23]
Xét tính đúng sai của các phép trừ có nhớ:
\choiceTF
{\True $62 - 37 = 25$.}
{\True $85 - 49 = 36$.}
{$74 - 28 = 45$.}
{\True $74 - 28 = 46$.}
\loigiai{
\begin{itemize}
    \item $62 - 37 = 25$: Đúng.
    \item $85 - 49 = 36$: Đúng.
    \item $74 - 28 = 46 \neq 45$. Ý 3 Sai, Ý 4 Đúng.
\end{itemize}
\begin{itemize}
    \item a) \textbf{Đúng}.
    \item b) \textbf{Đúng}.
    \item c) \textbf{Sai}.
    \item d) \textbf{Đúng}.
\end{itemize}
}
\end{ex}

\begin{ex} %[2D4V23]
Đàn vịt có 72 con, đàn gà có 38 con. Xét tính đúng sai:
\choiceTF
{\True Số vịt nhiều hơn số gà là 34 con ($72 - 38 = 34$).}
{\True Số gà ít hơn số vịt là 34 con.}
{Tổng số gà và vịt là 100 con.}
{\True Tổng số gà và vịt là 110 con ($72 + 38 = 110$).}
\loigiai{
\begin{itemize}
    \item Hiệu: $72 - 38 = 34$: Đúng.
    \item Gà ít hơn vịt 34: Đúng.
    \item Tổng: $72 + 38 = 110 \neq 100$. Ý 3 Sai, Ý 4 Đúng.
\end{itemize}
\begin{itemize}
    \item a) \textbf{Đúng}.
    \item b) \textbf{Đúng}.
    \item c) \textbf{Sai}.
    \item d) \textbf{Đúng}.
\end{itemize}
}
\end{ex}
