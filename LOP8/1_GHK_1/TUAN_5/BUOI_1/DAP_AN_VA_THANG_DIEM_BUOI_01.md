## 2. HƯỚNG DẪN CHẤM TỰ LUẬN (7,5 điểm)

### CÂU 1 (2,5 điểm). Rút gọn các biểu thức sau (Mỗi ý 0,625 điểm)

#### Đề 101:
* **a) (0,625 điểm)** $A = (x + 2)(x^2 - 2x + 4) - (x - 2)(x^2 + 2x + 4)$
  * Áp dụng hằng đẳng thức: $A = (x^3 + 8) - (x^3 - 8)$ *(0,375 đ)*.
  * Phá ngoặc và thu gọn: $A = x^3 + 8 - x^3 + 8 = 16$ *(0,25 đ)*.
* **b) (0,625 điểm)** $B = (2x - 1)(4x^2 + 2x + 1) - 4x(2x^2 - 1)$
  * Khai triển: $B = (8x^3 - 1) - (8x^3 - 4x)$ *(0,375 đ)*.
  * Thu gọn: $B = 8x^3 - 1 - 8x^3 + 4x = 4x - 1$ *(0,25 đ)*.
* **c) (0,625 điểm)** $C = (x + 1)^3 - (x - 1)(x^2 + x + 1) - 3x(x + 1)$
  * Khai triển: $C = (x^3 + 3x^2 + 3x + 1) - (x^3 - 1) - (3x^2 + 3x)$ *(0,375 đ)*.
  * Thu gọn: $C = 2$ *(0,25 đ)*.
* **d) (0,625 điểm)** Chứng minh giá trị biểu thức không phụ thuộc biến $x$:
  * Khai triển: $D = (x^3 - 27) - (x^3 + 1) + 28$ *(0,375 đ)*.
  * Thu gọn: $D = x^3 - 27 - x^3 - 1 + 28 = 0$ (hằng số, đpcm) *(0,25 đ)*.

#### Đề 102:
* **a) (0,625 điểm)** $A = (x + 3)(x^2 - 3x + 9) - (x - 3)(x^2 + 3x + 9) = (x^3 + 27) - (x^3 - 27) = 54$.
* **b) (0,625 điểm)** $B = (2x + 1)(4x^2 - 2x + 1) - 4x(2x^2 + 1) = (8x^3 + 1) - (8x^3 + 4x) = 1 - 4x$.
* **c) (0,625 điểm)** $C = (x - 1)^3 - (x + 1)(x^2 - x + 1) + 3x(x - 1) = (x^3 - 3x^2 + 3x - 1) - (x^3 + 1) + (3x^2 - 3x) = -2$.
* **d) (0,625 điểm)** $D = (x - 2)(x^2 + 2x + 4) - (x + 2)(x^2 - 2x + 4) + 16 = (x^3 - 8) - (x^3 + 8) + 16 = 0$ (đpcm).

#### Đề 103:
* **a) (0,625 điểm)** $A = (x + 1)(x^2 - x + 1) - (x - 1)(x^2 + x + 1) = (x^3 + 1) - (x^3 - 1) = 2$.
* **b) (0,625 điểm)** $B = (3x - 1)(9x^2 + 3x + 1) - 9x(3x^2 - 1) = (27x^3 - 1) - (27x^3 - 9x) = 9x - 1$.
* **c) (0,625 điểm)** $C = (x + 2)^3 - (x - 2)(x^2 + 2x + 4) - 6x(x + 2) = (x^3 + 6x^2 + 12x + 8) - (x^3 - 8) - (6x^2 + 12x) = 16$.
* **d) (0,625 điểm)** $D = (x - 1)(x^2 + x + 1) - (x + 2)(x^2 - 2x + 4) + 9 = (x^3 - 1) - (x^3 + 8) + 9 = 0$ (đpcm).

#### Đề 104:
* **a) (0,625 điểm)** $A = (x + 4)(x^2 - 4x + 16) - (x - 4)(x^2 + 4x + 16) = (x^3 + 64) - (x^3 - 64) = 128$.
* **b) (0,625 điểm)** $B = (3x + 1)(9x^2 - 3x + 1) - 9x(3x^2 + 1) = (27x^3 + 1) - (27x^3 + 9x) = 1 - 9x$.
* **c) (0,625 điểm)** $C = (x - 2)^3 - (x + 2)(x^2 - 2x + 4) + 6x(x - 2) = (x^3 - 6x^2 + 12x - 8) - (x^3 + 8) + (6x^2 - 12x) = -16$.
* **d) (0,625 điểm)** $D = (x - 4)(x^2 + 4x + 16) - (x + 1)(x^2 - x + 1) + 65 = (x^3 - 64) - (x^3 + 1) + 65 = 0$ (đpcm).

### CÂU 2 (2,5 điểm). Tìm $x$ và tính giá trị biểu thức

#### Đề 101:
* **a) (1,25 điểm)** Tìm số thực $x$: $(x - 1)(x^2 + x + 1) - x(x - 2)(x + 2) = 15$
  * Khai triển: $(x^3 - 1) - x(x^2 - 4) = 15$ *(0,5 đ)*.
  * Thu gọn: $x^3 - 1 - x^3 + 4x = 15 \iff 4x - 1 = 15$ *(0,5 đ)*.
  * Tìm ra: $4x = 16 \iff x = 4$. Kết luận: Vậy $x = 4$ *(0,25 đ)*.
* **b) (1,25 điểm)** Rút gọn rồi tính giá trị của biểu thức: $P = (x + 3)(x^2 - 3x + 9) - (x - 1)(x^2 + x + 1) - 2x$ tại $x = 10$
  * Thu gọn: $P = (x^3 + 27) - (x^3 - 1) - 2x = 28 - 2x$ *(0,75 đ)*.
  * Thay số: Tại $x = 10 \implies P = 28 - 2(10) = 28 - 20 = 8$ *(0,5 đ)*.

#### Đề 102:
* **a) (1,25 điểm)** $(x + 1)(x^2 - x + 1) - x(x - 3)(x + 3) = 28 \iff (x^3 + 1) - (x^3 - 9x) = 28 \iff 9x + 1 = 28 \iff 9x = 27 \iff x = 3$.
* **b) (1,25 điểm)** $P = (x + 2)(x^2 - 2x + 4) - (x - 2)(x^2 + 2x + 4) - 3x = (x^3 + 8) - (x^3 - 8) - 3x = 16 - 3x$. Tại $x = 4 \implies P = 16 - 3(4) = 4$.

#### Đề 103:
* **a) (1,25 điểm)** $(x - 2)(x^2 + 2x + 4) - x(x - 1)(x + 1) = 1 \iff (x^3 - 8) - (x^3 - x) = 1 \iff x - 8 = 1 \iff x = 9$.
* **b) (1,25 điểm)** $P = (x + 1)(x^2 - x + 1) - (x - 3)(x^2 + 3x + 9) - 2x = (x^3 + 1) - (x^3 - 27) - 2x = 28 - 2x$. Tại $x = 12 \implies P = 28 - 2(12) = 4$.

#### Đề 104:
* **a) (1,25 điểm)** $(x + 2)(x^2 - 2x + 4) - x(x - 2)(x + 2) = 20 \iff (x^3 + 8) - (x^3 - 4x) = 20 \iff 4x + 8 = 20 \iff 4x = 12 \iff x = 3$.
* **b) (1,25 điểm)** $P = (x + 4)(x^2 - 4x + 16) - (x - 1)(x^2 + x + 1) - 5x = (x^3 + 64) - (x^3 - 1) - 5x = 65 - 5x$. Tại $x = 10 \implies P = 65 - 5(10) = 15$.

### CÂU 3 (2,5 điểm). Bài toán thực tế và nâng cao

#### Đề 101:
* **a) (1,5 điểm)** 
  * 1) Biểu thức thể tích thép còn lại: $V = a^3 - b^3 = (x + 2)^3 - (x - 2)^3$ *(0,25 đ)*.
    * Khai triển: $V = (x^3 + 6x^2 + 12x + 8) - (x^3 - 6x^2 + 12x - 8)$ *(0,5 đ)*.
    * Rút gọn: $V = 12x^2 + 16$ ($\text{cm}^3$) *(0,25 đ)*.
  * 2) Khi $x = 6\text{ cm}$:
    * Thay $x = 6$ vào biểu thức: $V = 12(6^2) + 16 = 12 \cdot 36 + 16 = 432 + 16 = 448$ ($\text{cm}^3$) *(0,5 đ)*.
* **b) (1,0 điểm)** Cho $a + b = 5$ và $ab = 6$. Tính $M = a^3 + b^3$:
  * Biến đổi: $M = (a + b)(a^2 - ab + b^2) = (a + b)[(a + b)^2 - 3ab]$ *(0,5 đ)*.
  * Thay số: $M = 5 \cdot [5^2 - 3 \cdot 6] = 5 \cdot [25 - 18] = 5 \cdot 7 = 35$ *(0,5 đ)*.

#### Đề 102:
* **a) (1,5 điểm)** 
  * 1) $V = (x + 3)^3 - (x - 3)^3 = (x^3 + 9x^2 + 27x + 27) - (x^3 - 9x^2 + 27x - 27) = 18x^2 + 54$ ($\text{cm}^3$) *(1,0 đ)*.
  * 2) Khi $x = 5\text{ cm} \implies V = 18(5^2) + 54 = 18 \cdot 25 + 54 = 450 + 54 = 504$ ($\text{cm}^3$) *(0,5 đ)*.
* **b) (1,0 điểm)** $M = a^3 + b^3 = (a + b)[(a + b)^2 - 3ab] = 4 \cdot [4^2 - 3 \cdot 3] = 4 \cdot [16 - 9] = 4 \cdot 7 = 28$.

#### Đề 103:
* **a) (1,5 điểm)** 
  * 1) $V = (x + 1)^3 - (x - 1)^3 = (x^3 + 3x^2 + 3x + 1) - (x^3 - 3x^2 + 3x - 1) = 6x^2 + 2$ ($\text{cm}^3$) *(1,0 đ)*.
  * 2) Khi $x = 8\text{ cm} \implies V = 6(8^2) + 2 = 6 \cdot 64 + 2 = 384 + 2 = 386$ ($\text{cm}^3$) *(0,5 đ)*.
* **b) (1,0 điểm)** $M = a^3 + b^3 = (a + b)[(a + b)^2 - 3ab] = 6 \cdot [6^2 - 3 \cdot 8] = 6 \cdot [36 - 24] = 6 \cdot 12 = 72$.

#### Đề 104:
* **a) (1,5 điểm)** 
  * 1) $V = (x + 2)^3 - (x - 2)^3 = 12x^2 + 16$ ($\text{cm}^3$) *(1,0 đ)*.
  * 2) Khi $x = 7\text{ cm} \implies V = 12(7^2) + 16 = 12 \cdot 49 + 16 = 588 + 16 = 604$ ($\text{cm}^3$) *(0,5 đ)*.
* **b) (1,0 điểm)** $M = a^3 + b^3 = (a + b)[(a + b)^2 - 3ab] = 7 \cdot [7^2 - 3 \cdot 10] = 7 \cdot [49 - 30] = 7 \cdot 19 = 133$.
