## 🎯 I. MỤC TIÊU ÔN TẬP & ĐÁNH GIÁ (TUẦN 8 - BUỔI 2)

Tuần 8 Buổi 2 là đề thi thử Giữa Học kỳ 1 số 02, quét toàn bộ 3 trụ cột kiến thức trọng tâm chuẩn ma trận khảo sát chất lượng:
1. **Đa thức nhiều biến & Các phép tính:**
   - Xác định bậc của đơn thức nhiều biến và đa thức sau khi thu gọn.
   - Tính giá trị của biểu thức đại số tại các giá trị nguyên cho trước.
   - Nhân đơn thức với đa thức, nhân đa thức với đa thức, chia đa thức cho đơn thức.
2. **Hằng đẳng thức đáng nhớ & Phân tích đa thức thành nhân tử:**
   - 7 hằng đẳng thức đáng nhớ (bình phương của một tổng/hiệu, hiệu hai bình phương).
   - Phân tích đa thức thành nhân tử bằng phương pháp đặt nhân tử chung, dùng hằng đẳng thức, nhóm hạng tử.
   - Vận dụng giải bài toán tìm $x$ (đưa về phương trình tích, hiệu hai bình phương).
3. **Tứ giác & Các hình tứ giác đặc biệt:**
   - Định lý tổng các góc trong một tứ giác.
   - Tính chất và dấu hiệu nhận biết hình bình hành, hình chữ nhật, hình thoi, hình vuông.
   - Bài toán hình học tổng hợp: Tam giác cân kết hợp phép đối xứng tâm chứng minh hình chữ nhật và hình bình hành.
4. **Vận dụng cao:** Tìm giá trị lớn nhất (GTLN) của tam thức bậc hai một biến dạng $-x^2 + 2ax + b$.

* **Mã đề 102:**

#### CÂU 12 (2,0 ĐIỂM): TÌM $x$, BIẾT

* **Mã đề 101:**
  - a) $3x(x - 4) - 3x^2 = 24 \iff -12x = 24 \iff x = -2$.
  - b) $2x(x - 3) + 5(x - 3) = 0 \iff (x - 3)(2x + 5) = 0 \iff x = 3$ hoặc $x = -\frac{5}{2}$.
  - c) $(x - 1)^2 - 16 = 0 \iff (x - 1 - 4)(x - 1 + 4) = 0 \iff (x - 5)(x + 3) = 0 \iff x = 5$ hoặc $x = -3$.
  - d) $x^2 - 4x + 4 = 25 \iff (x - 2)^2 = 25 \iff x - 2 = 5$ hoặc $x - 2 = -5 \iff x = 7$ hoặc $x = -3$.

* **Mã đề 102:**
  - a) $4x(x - 3) - 4x^2 = 24 \iff -12x = 24 \iff x = -2$.
  - b) $3x(x - 2) + 4(x - 2) = 0 \iff (x - 2)(3x + 4) = 0 \iff x = 2$ hoặc $x = -\frac{4}{3}$.
  - c) $(x - 2)^2 - 25 = 0 \iff (x - 2 - 5)(x - 2 + 5) = 0 \iff (x - 7)(x + 3) = 0 \iff x = 7$ hoặc $x = -3$.
  - d) $x^2 - 6x + 9 = 36 \iff (x - 3)^2 = 36 \iff x - 3 = 6$ hoặc $x - 3 = -6 \iff x = 9$ hoặc $x = -3$.

* **Mã đề 103:**
  - a) $2x(x - 5) - 2x^2 = 20 \iff -10x = 20 \iff x = -2$.
  - b) $4x(x - 4) + 3(x - 4) = 0 \iff (x - 4)(4x + 3) = 0 \iff x = 4$ hoặc $x = -\frac{3}{4}$.
  - c) $(x - 3)^2 - 36 = 0 \iff (x - 3 - 6)(x - 3 + 6) = 0 \iff (x - 9)(x + 3) = 0 \iff x = 9$ hoặc $x = -3$.
  - d) $x^2 - 8x + 16 = 49 \iff (x - 4)^2 = 49 \iff x - 4 = 7$ hoặc $x - 4 = -7 \iff x = 11$ hoặc $x = -3$.

* **Mã đề 104:**
  - a) $5x(x - 3) - 5x^2 = 30 \iff -15x = 30 \iff x = -2$.
  - b) $5x(x - 1) + 2(x - 1) = 0 \iff (x - 1)(5x + 2) = 0 \iff x = 1$ hoặc $x = -\frac{2}{5}$.
  - c) $(x - 4)^2 - 49 = 0 \iff (x - 4 - 7)(x - 4 + 7) = 0 \iff (x - 11)(x + 3) = 0 \iff x = 11$ hoặc $x = -3$.
  - d) $x^2 - 10x + 25 = 64 \iff (x - 5)^2 = 64 \iff x - 5 = 8$ hoặc $x - 5 = -8 \iff x = 13$ hoặc $x = -3$.

#### CÂU 14 (1,0 ĐIỂM): BÀI TOÁN NÂNG CAO (GTLN CỦA BIỂU THỨC BẬC HAI)

* **Mã đề 101:**
  - **Đề bài:** Cho biểu thức $B = -x^2 + 4x + 2022$. Tìm giá trị lớn nhất của biểu thức $B$.
  - **Lời giải:** Ta có $B = -(x^2 - 4x + 4) + 2026 = -(x - 2)^2 + 2026$.
    Vì $(x - 2)^2 \ge 0$ với mọi $x \implies -(x - 2)^2 \le 0 \implies B \le 2026$.
    Dấu "$=$" xảy ra khi $x - 2 = 0 \iff x = 2$. Vậy giá trị lớn nhất của $B$ là $2026$ khi $x = 2$.
