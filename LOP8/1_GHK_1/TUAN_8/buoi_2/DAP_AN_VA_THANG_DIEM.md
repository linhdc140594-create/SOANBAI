### CÂU 12 (2,0 ĐIỂM). TÌM $x$, BIẾT (4 Ý, MỖI Ý 0,5 ĐIỂM)

* **Mã đề 101:**
  * **a) (0,5đ):** $3x(x - 4) - 3x^2 = 24 \iff 3x^2 - 12x - 3x^2 = 24 \iff -12x = 24 \iff x = -2$.
  * **b) (0,5đ):** $2x(x - 3) + 5(x - 3) = 0 \iff (x - 3)(2x + 5) = 0 \iff x = 3$ hoặc $x = -\frac{5}{2}$.
  * **c) (0,5đ):** $(x - 1)^2 - 16 = 0 \iff (x - 1 - 4)(x - 1 + 4) = 0 \iff (x - 5)(x + 3) = 0 \iff x = 5$ hoặc $x = -3$.
  * **d) (0,5đ):** $x^2 - 4x + 4 = 25 \iff (x - 2)^2 = 25 \iff x - 2 = 5$ hoặc $x - 2 = -5 \iff x = 7$ hoặc $x = -3$.

* **Mã đề 102:**
  * **a) (0,5đ):** $4x(x - 3) - 4x^2 = 24 \iff -12x = 24 \iff x = -2$.
  * **b) (0,5đ):** $3x(x - 2) + 4(x - 2) = 0 \iff (x - 2)(3x + 4) = 0 \iff x = 2$ hoặc $x = -\frac{4}{3}$.
  * **c) (0,5đ):** $(x - 2)^2 - 25 = 0 \iff (x - 2 - 5)(x - 2 + 5) = 0 \iff (x - 7)(x + 3) = 0 \iff x = 7$ hoặc $x = -3$.
  * **d) (0,5đ):** $x^2 - 6x + 9 = 36 \iff (x - 3)^2 = 36 \iff x - 3 = 6$ hoặc $x - 3 = -6 \iff x = 9$ hoặc $x = -3$.

* **Mã đề 103:**
  * **a) (0,5đ):** $2x(x - 5) - 2x^2 = 20 \iff -10x = 20 \iff x = -2$.
  * **b) (0,5đ):** $4x(x - 4) + 3(x - 4) = 0 \iff (x - 4)(4x + 3) = 0 \iff x = 4$ hoặc $x = -\frac{3}{4}$.
  * **c) (0,5đ):** $(x - 3)^2 - 36 = 0 \iff (x - 3 - 6)(x - 3 + 6) = 0 \iff (x - 9)(x + 3) = 0 \iff x = 9$ hoặc $x = -3$.
  * **d) (0,5đ):** $x^2 - 8x + 16 = 49 \iff (x - 4)^2 = 49 \iff x - 4 = 7$ hoặc $x - 4 = -7 \iff x = 11$ hoặc $x = -3$.

* **Mã đề 104:**
  * **a) (0,5đ):** $5x(x - 3) - 5x^2 = 30 \iff -15x = 30 \iff x = -2$.
  * **b) (0,5đ):** $5x(x - 1) + 2(x - 1) = 0 \iff (x - 1)(5x + 2) = 0 \iff x = 1$ hoặc $x = -\frac{2}{5}$.
  * **c) (0,5đ):** $(x - 4)^2 - 49 = 0 \iff (x - 4 - 7)(x - 4 + 7) = 0 \iff (x - 11)(x + 3) = 0 \iff x = 11$ hoặc $x = -3$.
  * **d) (0,5đ):** $x^2 - 10x + 25 = 64 \iff (x - 5)^2 = 64 \iff x - 5 = 8$ hoặc $x - 5 = -8 \iff x = 13$ hoặc $x = -3$.

### CÂU 13 (2,5 ĐIỂM). BÀI TOÁN HÌNH HỌC TỔNG HỢP

* **Mã đề 101:**
  * **a) (1,25đ):**
    * Vì $\Delta ABC$ cân tại $A$ có $AM$ là đường trung tuyến nên $AM$ đồng thời là đường cao $\implies AM \perp BC \implies \widehat{AMC} = 90^\circ$ ($0{,}5$đ).
    * Tứ giác $AMCE$ có hai đường chéo $AC$ và $ME$ cắt nhau tại trung điểm $N$ của mỗi đường (theo giả thiết) nên $AMCE$ là hình bình hành ($0{,}5$đ).
    * Hình bình hành $AMCE$ có $\widehat{AMC} = 90^\circ$ nên $AMCE$ là hình chữ nhật ($0{,}25$đ).
  * **b) (1,25đ):**
    * Vì $AMCE$ là hình chữ nhật nên $AE \parallel MC$ và $AE = MC$ ($0{,}5$đ).
    * Mặt khác $M$ là trung điểm của $BC$ nên $MC = BM$. Do đó $AE = BM$ và $AE \parallel BM$ ($0{,}5$đ).
    * Tứ giác $ABME$ có một cặp cạnh đối song song và bằng nhau ($AE \parallel BM, AE = BM$) nên $ABME$ là hình bình hành ($0{,}25$đ).

* **Mã đề 102:**
  * **a) (1,25đ):** $\Delta ABC$ cân tại $A$ có $AH \perp BC \implies \widehat{AHC} = 90^\circ$ và $H$ là trung điểm $BC$. Tứ giác $AHCK$ có hai đường chéo $AC, HK$ cắt nhau tại trung điểm $I$ của mỗi đường $\implies AHCK$ là hình bình hành. Lại có $\widehat{AHC} = 90^\circ \implies AHCK$ là hình chữ nhật.
  * **b) (1,25đ):** Do $AHCK$ là hình chữ nhật $\implies AK \parallel HC$ và $AK = HC$. Mà $HC = BH \implies AK = BH$ và $AK \parallel BH \implies ABHK$ là hình bình hành.

* **Mã đề 103:**
  * **a) (1,25đ):** $\Delta MNP$ cân tại $M$, trung tuyến $MI \implies MI \perp NP \implies \widehat{MIP} = 90^\circ$. Tứ giác $MIPE$ có hai đường chéo $MP, IE$ cắt nhau tại trung điểm $K \implies MIPE$ là hình bình hành. Có $\widehat{MIP} = 90^\circ \implies MIPE$ là hình chữ nhật.
  * **b) (1,25đ):** $ME \parallel IP$ và $ME = IP$. Mà $IP = NI \implies ME = NI$ và $ME \parallel NI \implies MNIE$ là hình bình hành.

* **Mã đề 104:**
  * **a) (1,25đ):** $\Delta DEF$ cân tại $D$, đường cao $DH \implies DH \perp EF \implies \widehat{DHF} = 90^\circ$ và $H$ là trung điểm $EF$. Tứ giác $DHKF$ có hai đường chéo $DF, HK$ cắt nhau tại trung điểm $M \implies DHKF$ là hình bình hành. Có $\widehat{DHF} = 90^\circ \implies DHKF$ là hình chữ nhật.
  * **b) (1,25đ):** $DK \parallel HF$ và $DK = HF$. Mà $HF = EH \implies DK = EH$ và $DK \parallel EH \implies DEHK$ là hình bình hành.

### CÂU 14 (1,0 ĐIỂM). BÀI TOÁN NÂNG CAO (GTLN CỦA BIỂU THỨC BẬC HAI)

* **Mã đề 101:** Cho biểu thức $B = -x^2 + 4x + 2022$.
  * Biến đổi: $B = -(x^2 - 4x + 4) + 2026 = -(x - 2)^2 + 2026$ ($0{,}5$đ).
  * Lập luận: Vì $(x - 2)^2 \ge 0$ với mọi $x \implies -(x - 2)^2 \le 0 \implies B \le 2026$ ($0{,}25$đ).
  * Dấu "$=$" xảy ra khi $x - 2 = 0 \iff x = 2$. Vậy $\max B = 2026$ khi $x = 2$ ($0{,}25$đ).

* **Mã đề 102:** Cho biểu thức $B = -x^2 + 6x + 2017$.
  * Biến đổi: $B = -(x^2 - 6x + 9) + 2026 = -(x - 3)^2 + 2026 \le 2026$.
  * Dấu "$=$" xảy ra khi $x = 3$. Vậy $\max B = 2026$ khi $x = 3$.

* **Mã đề 103:** Cho biểu thức $B = -x^2 + 8x + 2010$.
  * Biến đổi: $B = -(x^2 - 8x + 16) + 2026 = -(x - 4)^2 + 2026 \le 2026$.
  * Dấu "$=$" xảy ra khi $x = 4$. Vậy $\max B = 2026$ khi $x = 4$.

* **Mã đề 104:** Cho biểu thức $B = -x^2 + 10x + 2001$.
  * Biến đổi: $B = -(x^2 - 10x + 25) + 2026 = -(x - 5)^2 + 2026 \le 2026$.
  * Dấu "$=$" xảy ra khi $x = 5$. Vậy $\max B = 2026$ khi $x = 5$.
