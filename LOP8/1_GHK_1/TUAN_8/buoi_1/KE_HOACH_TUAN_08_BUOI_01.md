## 🎯 I. MỤC TIÊU ÔN TẬP & ĐÁNH GIÁ (GIỮA HỌC KỲ 1)

Tuần 8 là tuần then chốt chuẩn bị cho kỳ thi Giữa Học kỳ 1. Đề thi quét toàn bộ **3 trụ cột kiến thức trọng tâm**:
1. **Chương 1: Đa thức nhiều biến & Các phép tính:**
   - Khái niệm đơn thức, đa thức, bậc, giá trị biểu thức.
   - Nhân đơn thức với đa thức, nhân đa thức với đa thức, chia đa thức cho đơn thức.
2. **Chương 2: Hằng đẳng thức đáng nhớ & Phân tích đa thức thành nhân tử:**
   - 7 hằng đẳng thức đáng nhớ (bình phương tổng/hiệu, hiệu hai bình phương).
   - Phân tích đa thức thành nhân tử bằng cách đặt nhân tử chung, dùng hằng đẳng thức, nhóm hạng tử.
   - Tìm $x$ đưa về dạng phương trình tích $A(x) \cdot B(x) = 0$.
3. **Chương 3: Tứ giác & Các hình tứ giác đặc biệt:**
   - Định lý tổng 4 góc trong một tứ giác.
   - Hình thang cân, hình bình hành, hình chữ nhật, hình thoi, hình vuông (tính chất và dấu hiệu nhận biết).
   - Bài toán hình học chứng minh hình chữ nhật và hình thoi qua điểm đối xứng và trung tuyến tam giác vuông.
4. **Vận dụng cao:** Cực trị của biểu thức bậc hai một biến (Tìm giá trị nhỏ nhất / lớn nhất).

#### CÂU 12 (2,0 ĐIỂM): TÌM $x$, BIẾT

* **Mã đề 101:**
  - a) $2x(x - 4) - 2x^2 = 16 \iff -8x = 16 \iff x = -2$.
  - b) $3x(x - 5) + 2(x - 5) = 0 \iff (x - 5)(3x + 2) = 0 \iff x = 5$ hoặc $x = -\frac{2}{3}$.
  - c) $(x + 2)^2 - 25 = 0 \iff (x + 2 - 5)(x + 2 + 5) = 0 \iff (x - 3)(x + 7) = 0 \iff x = 3$ hoặc $x = -7$.
  - d) $(2x - 3)^2 = 49 \iff 2x - 3 = 7$ hoặc $2x - 3 = -7 \iff x = 5$ hoặc $x = -2$.

* **Mã đề 102:**
  - a) $3x(x - 3) - 3x^2 = 18 \iff -9x = 18 \iff x = -2$.
  - b) $2x(x - 4) + 3(x - 4) = 0 \iff (x - 4)(2x + 3) = 0 \iff x = 4$ hoặc $x = -\frac{3}{2}$.
  - c) $(x + 3)^2 - 16 = 0 \iff (x + 3 - 4)(x + 3 + 4) = 0 \iff (x - 1)(x + 7) = 0 \iff x = 1$ hoặc $x = -7$.
  - d) $(2x - 5)^2 = 81 \iff 2x - 5 = 9$ hoặc $2x - 5 = -9 \iff x = 7$ hoặc $x = -2$.

* **Mã đề 103:**
  - a) $4x(x - 2) - 4x^2 = 16 \iff -8x = 16 \iff x = -2$.
  - b) $4x(x - 3) + 3(x - 3) = 0 \iff (x - 3)(4x + 3) = 0 \iff x = 3$ hoặc $x = -\frac{3}{4}$.
  - c) $(x + 4)^2 - 36 = 0 \iff (x + 4 - 6)(x + 4 + 6) = 0 \iff (x - 2)(x + 10) = 0 \iff x = 2$ hoặc $x = -10$.
  - d) $(2x - 1)^2 = 25 \iff 2x - 1 = 5$ hoặc $2x - 1 = -5 \iff x = 3$ hoặc $x = -2$.

* **Mã đề 104:**
  - a) $5x(x - 2) - 5x^2 = 20 \iff -10x = 20 \iff x = -2$.
  - b) $5x(x - 2) + 2(x - 2) = 0 \iff (x - 2)(5x + 2) = 0 \iff x = 2$ hoặc $x = -\frac{2}{5}$.
  - c) $(x + 1)^2 - 49 = 0 \iff (x + 1 - 7)(x + 1 + 7) = 0 \iff (x - 6)(x + 8) = 0 \iff x = 6$ hoặc $x = -8$.
  - d) $(2x - 7)^2 = 9 \iff 2x - 7 = 3$ hoặc $2x - 7 = -3 \iff x = 5$ hoặc $x = 2$.

#### CÂU 13 (2,5 ĐIỂM): BÀI TOÁN HÌNH HỌC (TỨ GIÁC ĐẶC BIỆT)

* **Mã đề 102:**
  - **Đề bài:** Cho tam giác $ABC$ vuông tại $A$ ($AB < AC$), đường trung tuyến $AM$. Gọi $K$ là điểm đối xứng với $A$ qua $M$.

* **Mã đề 103:**
  - **Đề bài:** Cho tam giác $MNP$ vuông tại $M$ ($MN < MP$), đường trung tuyến $MI$. Gọi $Q$ là điểm đối xứng với $M$ qua $I$.

#### CÂU 14 (1,0 ĐIỂM): BÀI TOÁN NÂNG CAO (CỰC TRỊ BIỂU THỨC BẬC HAI)

* **Mã đề 101:**
  - **Đề bài:** Cho biểu thức $A = x^2 - 6x + 2030$. Tìm giá trị nhỏ nhất của biểu thức $A$.
  - **Lời giải:** $A = (x^2 - 6x + 9) + 2021 = (x - 3)^2 + 2021 \ge 2021$. Dấu "$=$" xảy ra khi $x = 3$. Vậy $\min A = 2021$.
