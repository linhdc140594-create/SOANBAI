## 2. HƯỚNG DẪN CHẤM TỰ LUẬN (7,5 điểm)

### CÂU 1 (2,5 điểm). Rút gọn các biểu thức sau (Mỗi ý 0,625 điểm)

#### Đề 101:
* **a) (0,625 điểm)** $A = (x + 3)^2 + (x - 3)^2$
  * Khai triển: $A = (x^2 + 6x + 9) + (x^2 - 6x + 9)$ *(0,375 đ)*.
  * Thu gọn: $A = 2x^2 + 18$ *(0,25 đ)*.
* **b) (0,625 điểm)** $B = (2x + 3y)^2 - (2x - 3y)^2$
  * Khai triển: $B = (4x^2 + 12xy + 9y^2) - (4x^2 - 12xy + 9y^2)$ *(0,375 đ)*.
  * Phá ngoặc và rút gọn: $B = 24xy$ *(0,25 đ)*.
* **c) (0,625 điểm)** $C = (2x - 1)^2 - 4x(x - 2)$
  * Khai triển: $C = (4x^2 - 4x + 1) - (4x^2 - 8x)$ *(0,375 đ)*.
  * Thu gọn: $C = 4x + 1$ *(0,25 đ)*.
* **d) (0,625 điểm)** $D = (3x - 2)(3x + 2) - (3x - 1)^2 + 6x$
  * Khai triển: $D = (9x^2 - 4) - (9x^2 - 6x + 1) + 6x$ *(0,375 đ)*.
  * Thu gọn: $D = 12x - 5$ *(0,25 đ)*.

#### Đề 102:
* **a) (0,625 điểm)** $A = (x + 4)^2 + (x - 4)^2 = (x^2 + 8x + 16) + (x^2 - 8x + 16) = 2x^2 + 32$.
* **b) (0,625 điểm)** $B = (3x + 2y)^2 - (3x - 2y)^2 = (9x^2 + 12xy + 4y^2) - (9x^2 - 12xy + 4y^2) = 24xy$.
* **c) (0,625 điểm)** $C = (3x - 1)^2 - 9x(x - 1) = (9x^2 - 6x + 1) - (9x^2 - 9x) = 3x + 1$.
* **d) (0,625 điểm)** $D = (2x - 3)(2x + 3) - (2x - 1)^2 + 4x = (4x^2 - 9) - (4x^2 - 4x + 1) + 4x = 8x - 10$.

#### Đề 103:
* **a) (0,625 điểm)** $A = (x + 5)^2 + (x - 5)^2 = (x^2 + 10x + 25) + (x^2 - 10x + 25) = 2x^2 + 50$.
* **b) (0,625 điểm)** $B = (2x + 5y)^2 - (2x - 5y)^2 = (4x^2 + 20xy + 25y^2) - (4x^2 - 20xy + 25y^2) = 40xy$.
* **c) (0,625 điểm)** $C = (2x - 3)^2 - 4x(x - 3) = (4x^2 - 12x + 9) - (4x^2 - 12x) = 9$.
* **d) (0,625 điểm)** $D = (4x - 1)(4x + 1) - (4x - 2)^2 + 8x = (16x^2 - 1) - (16x^2 - 16x + 4) + 8x = 24x - 5$.

#### Đề 104:
* **a) (0,625 điểm)** $A = (x + 2)^2 + (x - 2)^2 = (x^2 + 4x + 4) + (x^2 - 4x + 4) = 2x^2 + 8$.
* **b) (0,625 điểm)** $B = (3x + 4y)^2 - (3x - 4y)^2 = (9x^2 + 24xy + 16y^2) - (9x^2 - 24xy + 16y^2) = 48xy$.
* **c) (0,625 điểm)** $C = (3x - 2)^2 - 9x(x - 2) = (9x^2 - 12x + 4) - (9x^2 - 18x) = 6x + 4$.
* **d) (0,625 điểm)** $D = (2x - 1)(2x + 1) - (2x - 3)^2 + 4x = (4x^2 - 1) - (4x^2 - 12x + 9) + 4x = 16x - 10$.

### CÂU 2 (2,5 điểm). Rút gọn và tìm $x$

* **a) Rút gọn biểu thức và thay số tính giá trị (1,25 điểm):**
  * **Đề 101:** $P = x^2 - 10x + 25 = (x - 5)^2$ *(0,75 đ)*.
    * Thay $x = 105 \implies P = (105 - 5)^2 = 100^2 = 10\,000$ *(0,5 đ)*.
  * **Đề 102:** $P = x^2 - 8x + 16 = (x - 4)^2$ *(0,75 đ)*.
    * Thay $x = 104 \implies P = (104 - 4)^2 = 100^2 = 10\,000$ *(0,5 đ)*.
  * **Đề 103:** $P = x^2 - 12x + 36 = (x - 6)^2$ *(0,75 đ)*.
    * Thay $x = 106 \implies P = (106 - 6)^2 = 100^2 = 10\,000$ *(0,5 đ)*.
  * **Đề 104:** $P = x^2 - 6x + 9 = (x - 3)^2$ *(0,75 đ)*.
    * Thay $x = 103 \implies P = (103 - 3)^2 = 100^2 = 10\,000$ *(0,5 đ)*.

* **b) Tìm $x$ (1,25 điểm):**
  * **Đề 101:** $(x + 4)^2 - (x - 2)(x + 2) = 36$
    * Khai triển: $(x^2 + 8x + 16) - (x^2 - 4) = 36$ *(0,5 đ)*.
    * Thu gọn: $8x + 20 = 36 \implies 8x = 16$ *(0,5 đ)*.
    * Kết luận: $x = 2$ *(0,25 đ)*.
  * **Đề 102:** $(x + 3)^2 - (x - 4)(x + 4) = 43$
    * Khai triển: $(x^2 + 6x + 9) - (x^2 - 16) = 43$ *(0,5 đ)*.
    * Thu gọn: $6x + 25 = 43 \implies 6x = 18$ *(0,5 đ)*.
    * Kết luận: $x = 3$ *(0,25 đ)*.
  * **Đề 103:** $(x + 5)^2 - (x - 1)(x + 1) = 56$
    * Khai triển: $(x^2 + 10x + 25) - (x^2 - 1) = 56$ *(0,5 đ)*.
    * Thu gọn: $10x + 26 = 56 \implies 10x = 30$ *(0,5 đ)*.
    * Kết luận: $x = 3$ *(0,25 đ)*.
  * **Đề 104:** $(x + 2)^2 - (x - 3)(x + 3) = 25$
    * Khai triển: $(x^2 + 4x + 4) - (x^2 - 9) = 25$ *(0,5 đ)*.
    * Thu gọn: $4x + 13 = 25 \implies 4x = 12$ *(0,5 đ)*.
    * Kết luận: $x = 3$ *(0,25 đ)*.

### CÂU 3 (2,5 điểm). Bài toán thực tế và nâng cao

* **a) Bài toán thực tế mở rộng diện tích (1,5 điểm):**
  * **Đề 101:**
    * 1) Biểu thức diện tích sân mới là $(x + 3)^2 = x^2 + 6x + 9$ ($\text{m}^2$).
      Diện tích tăng thêm là $\Delta S = (x + 3)^2 - x^2 = 6x + 9$ ($\text{m}^2$) *(1,0 đ)*.
    * 2) Ta có $6x + 9 = 57 \implies 6x = 48 \implies x = 8\text{ m}$. Cạnh ban đầu của sân trường là $8\text{ m}$ *(0,5 đ)*.
  * **Đề 102:**
    * 1) Diện tích tăng thêm: $\Delta S = (x + 2)^2 - x^2 = 4x + 4$ ($\text{m}^2$) *(1,0 đ)*.
    * 2) $4x + 4 = 44 \implies 4x = 40 \implies x = 10\text{ m}$. Cạnh ban đầu của sân là $10\text{ m}$ *(0,5 đ)*.
  * **Đề 103:**
    * 1) Diện tích tăng thêm: $\Delta S = (x + 4)^2 - x^2 = 8x + 16$ ($\text{m}^2$) *(1,0 đ)*.
    * 2) $8x + 16 = 80 \implies 8x = 64 \implies x = 8\text{ m}$. Cạnh ban đầu của vườn là $8\text{ m}$ *(0,5 đ)*.
  * **Đề 104:**
    * 1) Diện tích tăng thêm: $\Delta S = (x + 3)^2 - x^2 = 6x + 9$ ($\text{m}^2$) *(1,0 đ)*.
    * 2) $6x + 9 = 69 \implies 6x = 60 \implies x = 10\text{ m}$. Cạnh ban đầu của sân là $10\text{ m}$ *(0,5 đ)*.

* **b) Bài toán nâng cao cực trị / luôn dương (1,0 điểm):**
  * **Đề 101:** $A = x^2 - 6x + 11 = (x^2 - 6x + 9) + 2 = (x - 3)^2 + 2$ *(0,5 đ)*.
    * Vì $(x - 3)^2 \ge 0$ với mọi $x \in \mathbb{R} \implies A \ge 2 > 0$ với mọi $x$.
    * Vậy $A$ luôn nhận giá trị dương với mọi $x$, và giá trị nhỏ nhất của $A$ là $2$ khi $x = 3$ *(0,5 đ)*.
  * **Đề 102:** $A = x^2 - 8x + 20 = (x^2 - 8x + 16) + 4 = (x - 4)^2 + 4$ *(0,5 đ)*.
    * Vì $(x - 4)^2 \ge 0 \implies A \ge 4 > 0$. GTNN của $A$ là $4$ khi $x = 4$ *(0,5 đ)*.
  * **Đề 103:** $A = x^2 - 10x + 29 = (x^2 - 10x + 25) + 4 = (x - 5)^2 + 4$ *(0,5 đ)*.
    * Vì $(x - 5)^2 \ge 0 \implies A \ge 4 > 0$. GTNN của $A$ là $4$ khi $x = 5$ *(0,5 đ)*.
  * **Đề 104:** $A = x^2 - 4x + 9 = (x^2 - 4x + 4) + 5 = (x - 2)^2 + 5$ *(0,5 đ)*.
    * Vì $(x - 2)^2 \ge 0 \implies A \ge 5 > 0$. GTNN của $A$ là $5$ khi $x = 2$ *(0,5 đ)*.
