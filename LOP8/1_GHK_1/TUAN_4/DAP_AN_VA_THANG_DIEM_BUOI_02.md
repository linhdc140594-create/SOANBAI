## 2. HƯỚNG DẪN CHẤM TỰ LUẬN (7,5 điểm)

### CÂU 1 (2,5 điểm). Rút gọn các biểu thức sau (Mỗi ý 0,625 điểm)

#### Đề 101:
* **a) (0,625 điểm)** $A = (x + 2)^3 + (x - 2)^3$
  * Khai triển: $A = (x^3 + 6x^2 + 12x + 8) + (x^3 - 6x^2 + 12x - 8)$ *(0,375 đ)*.
  * Thu gọn: $A = 2x^3 + 24x$ *(0,25 đ)*.
* **b) (0,625 điểm)** $B = (x + 1)^3 - (x - 1)^3 - 6x^2$
  * Khai triển: $B = (x^3 + 3x^2 + 3x + 1) - (x^3 - 3x^2 + 3x - 1) - 6x^2$ *(0,375 đ)*.
  * Thu gọn: $B = 2$ *(0,25 đ)*.
* **c) (0,625 điểm)** $C = (x - 1)^3 - x(x + 2)(x - 2) + 3x^2$
  * Khai triển: $C = (x^3 - 3x^2 + 3x - 1) - (x^3 - 4x) + 3x^2$ *(0,375 đ)*.
  * Thu gọn: $C = 7x - 1$ *(0,25 đ)*.
* **d) (0,625 điểm)** $D = (x + 1)^3 - x^2(x + 3) - 3x$
  * Khai triển: $D = (x^3 + 3x^2 + 3x + 1) - (x^3 + 3x^2) - 3x$ *(0,375 đ)*.
  * Thu gọn: $D = 1$ *(0,25 đ)*.

#### Đề 102:
* **a) (0,625 điểm)** $A = (x + 3)^3 + (x - 3)^3 = (x^3 + 9x^2 + 27x + 27) + (x^3 - 9x^2 + 27x - 27) = 2x^3 + 54x$.
* **b) (0,625 điểm)** $B = (x + 2)^3 - (x - 2)^3 - 12x^2 = (12x^2 + 16) - 12x^2 = 16$.
* **c) (0,625 điểm)** $C = (x - 2)^3 - x(x + 3)(x - 3) + 6x^2 = (x^3 - 6x^2 + 12x - 8) - (x^3 - 9x) + 6x^2 = 21x - 8$.
* **d) (0,625 điểm)** $D = (x + 2)^3 - x^2(x + 6) - 12x = (x^3 + 6x^2 + 12x + 8) - (x^3 + 6x^2) - 12x = 8$.

#### Đề 103:
* **a) (0,625 điểm)** $A = (x + 1)^3 + (x - 1)^3 = (x^3 + 3x^2 + 3x + 1) + (x^3 - 3x^2 + 3x - 1) = 2x^3 + 6x$.
* **b) (0,625 điểm)** $B = (x + 3)^3 - (x - 3)^3 - 18x^2 = (18x^2 + 54) - 18x^2 = 54$.
* **c) (0,625 điểm)** $C = (x - 3)^3 - x(x + 2)(x - 2) + 9x^2 = (x^3 - 9x^2 + 27x - 27) - (x^3 - 4x) + 9x^2 = 31x - 27$.
* **d) (0,625 điểm)** $D = (x + 3)^3 - x^2(x + 9) - 27x = (x^3 + 9x^2 + 27x + 27) - (x^3 + 9x^2) - 27x = 27$.

#### Đề 104:
* **a) (0,625 điểm)** $A = (2x + 1)^3 + (2x - 1)^3 = (8x^3 + 12x^2 + 6x + 1) + (8x^3 - 12x^2 + 6x - 1) = 16x^3 + 12x$.
* **b) (0,625 điểm)** $B = (x + 4)^3 - (x - 4)^3 - 24x^2 = (24x^2 + 128) - 24x^2 = 128$.
* **c) (0,625 điểm)** $C = (x - 1)^3 - x(x + 3)(x - 3) + 3x^2 = (x^3 - 3x^2 + 3x - 1) - (x^3 - 9x) + 3x^2 = 12x - 1$.
* **d) (0,625 điểm)** $D = (2x + 1)^3 - 4x(2x^2 + 3x) - 1 = (8x^3 + 12x^2 + 6x + 1) - (8x^3 + 12x^2) - 1 = 6x$.

### CÂU 2 (2,5 điểm). Rút gọn và tìm $x$

* **a) Rút gọn biểu thức và thay số tính giá trị (1,25 điểm):**
  * **Đề 101:** $P = x^3 - 3x^2 + 3x - 1 = (x - 1)^3$ *(0,75 đ)*.
    * Thay $x = 101 \implies P = (101 - 1)^3 = 100^3 = 1\,000\,000$ *(0,5 đ)*.
  * **Đề 102:** $P = x^3 - 6x^2 + 12x - 8 = (x - 2)^3$ *(0,75 đ)*.
    * Thay $x = 102 \implies P = (102 - 2)^3 = 100^3 = 1\,000\,000$ *(0,5 đ)*.
  * **Đề 103:** $P = x^3 + 3x^2 + 3x + 1 = (x + 1)^3$ *(0,75 đ)*.
    * Thay $x = 99 \implies P = (99 + 1)^3 = 100^3 = 1\,000\,000$ *(0,5 đ)*.
  * **Đề 104:** $P = x^3 + 6x^2 + 12x + 8 = (x + 2)^3$ *(0,75 đ)*.
    * Thay $x = 98 \implies P = (98 + 2)^3 = 100^3 = 1\,000\,000$ *(0,5 đ)*.

* **b) Tìm $x$ (1,25 điểm):**
  * **Đề 101:** $(x + 1)^3 - x^2(x + 3) = 19$
    * Khai triển: $(x^3 + 3x^2 + 3x + 1) - (x^3 + 3x^2) = 19$ *(0,5 đ)*.
    * Thu gọn: $3x + 1 = 19 \implies 3x = 18$ *(0,5 đ)*.
    * Kết luận: $x = 6$ *(0,25 đ)*.
  * **Đề 102:** $(x + 2)^3 - x^2(x + 6) = 32$
    * Khai triển: $(x^3 + 6x^2 + 12x + 8) - (x^3 + 6x^2) = 32$ *(0,5 đ)*.
    * Thu gọn: $12x + 8 = 32 \implies 12x = 24$ *(0,5 đ)*.
    * Kết luận: $x = 2$ *(0,25 đ)*.
  * **Đề 103:** $(x + 1)^3 - x^2(x + 3) = 16$
    * Khai triển: $(x^3 + 3x^2 + 3x + 1) - (x^3 + 3x^2) = 16$ *(0,5 đ)*.
    * Thu gọn: $3x + 1 = 16 \implies 3x = 15$ *(0,5 đ)*.
    * Kết luận: $x = 5$ *(0,25 đ)*.
  * **Đề 104:** $(x + 2)^3 - x^2(x + 6) = 44$
    * Khai triển: $(x^3 + 6x^2 + 12x + 8) - (x^3 + 6x^2) = 44$ *(0,5 đ)*.
    * Thu gọn: $12x + 8 = 44 \implies 12x = 36$ *(0,5 đ)*.
    * Kết luận: $x = 3$ *(0,25 đ)*.

### CÂU 3 (2,5 điểm). Bài toán thực tế và nâng cao

* **a) Bài toán thực tế về thể tích khối lập phương (1,5 điểm):**
  * **Đề 101:**
    * 1) Biểu thức thể tích bể nước mới: $V_{\text{mới}} = (x + 0{,}5)^3 = x^3 + 1{,}5x^2 + 0{,}75x + 0{,}125$ ($\text{m}^3$).
      Lượng thể tích tăng thêm: $\Delta V = (x + 0{,}5)^3 - x^3 = 1{,}5x^2 + 0{,}75x + 0{,}125$ ($\text{m}^3$) *(0,75 đ)*.
    * 2) Với $x = 1{,}5\text{ m} \implies \Delta V = (1{,}5 + 0{,}5)^3 - 1{,}5^3 = 2^3 - 3{,}375 = 8 - 3{,}375 = 4{,}625\text{ m}^3$ *(0,5 đ)*.
      Đổi ra lít: $4{,}625 \cdot 1000 = 4625$ lít *(0,25 đ)*.
  * **Đề 102:**
    * 1) $V_{\text{mới}} = (x + 1)^3$; $\Delta V = (x + 1)^3 - x^3 = 3x^2 + 3x + 1$ ($\text{m}^3$) *(0,75 đ)*.
    * 2) Với $x = 1\text{ m} \implies \Delta V = 2^3 - 1^3 = 8 - 1 = 7\text{ m}^3 = 7000$ lít *(0,75 đ)*.
  * **Đề 103:**
    * 1) $V_{\text{mới}} = (x + 0{,}5)^3$; $\Delta V = 1{,}5x^2 + 0{,}75x + 0{,}125$ ($\text{m}^3$) *(0,75 đ)*.
    * 2) Với $x = 2\text{ m} \implies \Delta V = 2{,}5^3 - 2^3 = 15{,}625 - 8 = 7{,}625\text{ m}^3 = 7625$ lít *(0,75 đ)*.
  * **Đề 104:**
    * 1) $V_{\text{mới}} = (x + 0{,}5)^3$; $\Delta V = 1{,}5x^2 + 0{,}75x + 0{,}125$ ($\text{m}^3$) *(0,75 đ)*.
    * 2) Với $x = 1\text{ m} \implies \Delta V = 1{,}5^3 - 1^3 = 3{,}375 - 1 = 2{,}375\text{ m}^3 = 2375$ lít *(0,75 đ)*.

* **b) Chứng minh biểu thức không phụ thuộc vào biến $x$ (1,0 điểm):**
  * **Đề 101:** $M = (x + 2)^3 - (x - 2)^3 - 12x^2$
    * Khai triển: $M = (x^3 + 6x^2 + 12x + 8) - (x^3 - 6x^2 + 12x - 8) - 12x^2$ *(0,5 đ)*.
    * Thu gọn: $M = (12x^2 + 16) - 12x^2 = 16$.
    * Kết luận: Giá trị của biểu thức $M$ luôn bằng $16$ với mọi $x$, tức là không phụ thuộc vào biến $x$ *(0,5 đ)*.
  * **Đề 102:** $M = (x + 3)^3 - (x - 3)^3 - 18x^2$
    * Khai triển: $M = (x^3 + 9x^2 + 27x + 27) - (x^3 - 9x^2 + 27x - 27) - 18x^2 = 18x^2 + 54 - 18x^2 = 54$ *(0,5 đ)*.
    * Kết luận: $M = 54$ không phụ thuộc vào $x$ *(0,5 đ)*.
  * **Đề 103:** $M = (x + 1)^3 - (x - 1)^3 - 6x^2$
    * Khai triển: $M = (x^3 + 3x^2 + 3x + 1) - (x^3 - 3x^2 + 3x - 1) - 6x^2 = 6x^2 + 2 - 6x^2 = 2$ *(0,5 đ)*.
    * Kết luận: $M = 2$ không phụ thuộc vào $x$ *(0,5 đ)*.
  * **Đề 104:** $M = (x + 4)^3 - (x - 4)^3 - 24x^2$
    * Khai triển: $M = (x^3 + 12x^2 + 48x + 64) - (x^3 - 12x^2 + 48x - 64) - 24x^2 = 24x^2 + 128 - 24x^2 = 128$ *(0,5 đ)*.
    * Kết luận: $M = 128$ không phụ thuộc vào $x$ *(0,5 đ)*.
