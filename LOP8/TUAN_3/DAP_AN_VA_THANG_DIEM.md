### CÂU 1 (2,5 điểm). Các phép toán và bài toán về đa thức
* **Đề 101:**
  * a) $C = A + B = 5x^2 y + 2xy + 3$ *(0,75 đ)*.
  * b) $D = A - B = x^2 y - 4xy^2 + 8xy - 5$ *(0,75 đ)*.
  * c) Bậc của đa thức $C$ là $3$ (bậc của hạng tử $5x^2 y$) *(0,5 đ)*.
  * d) Tại $x = 1, y = -1 \implies C = 5(1)^2(-1) + 2(1)(-1) + 3 = -5 - 2 + 3 = -4$ *(0,5 đ)*.
* **Đề 102:**
  * a) $C = A + B = 7x^2 y + 2xy + 3$ *(0,75 đ)*.

  * c) Bậc của đa thức $C$ là $3$ (bậc của hạng tử $7x^2 y$) *(0,5 đ)*.
  * d) Tại $x = 1, y = -1 \implies C = 7(1)^2(-1) + 2(1)(-1) + 3 = -7 - 2 + 3 = -6$ *(0,5 đ)*.
* **Đề 103:**
  * a) $C = A + B = 7x^2 y + 2xy + 2$ *(0,75 đ)*.

* **Đề 104:**
