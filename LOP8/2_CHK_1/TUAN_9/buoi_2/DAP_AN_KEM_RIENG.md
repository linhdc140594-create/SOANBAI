### 2. CÂU 2 (5,0 ĐIỂM). TÌM SỐ THỰC $x$, BIẾT:

| Ý | Mã đề 101 | Mã đề 102 | Mã đề 103 | Mã đề 104 |
| :---: | :--- | :--- | :--- | :--- |
| **a** | $3(x - 2) = 15 \iff x = 7$ | $4(x - 3) = 16 \iff x = 7$ | $5(x - 1) = 20 \iff x = 5$ | $2(x - 5) = 14 \iff x = 12$ |
| **b** | $2x(x - 3) - 2x^2 = -18 \iff x = 3$ | $3x(x - 4) - 3x^2 = -36 \iff x = 3$ | $4x(x - 2) - 4x^2 = -24 \iff x = 3$ | $5x(x - 2) - 5x^2 = -40 \iff x = 4$ |
| **c** | $4x(x + 2) - 4x^2 = 16 \iff x = 2$ | $5x(x + 2) - 5x^2 = 20 \iff x = 2$ | $3x(x + 3) - 3x^2 = 18 \iff x = 2$ | $2x(x + 4) - 2x^2 = 16 \iff x = 2$ |
| **d** | $(x - 1)(x + 3) - x^2 = 5 \iff x = 4$ | $(x - 2)(x + 5) - x^2 = 5 \iff x = 5$ | $(x - 1)(x + 5) - x^2 = 7 \iff x = 3$ | $(x - 2)(x + 4) - x^2 = 6 \iff x = 7$ |
| **e** | $(x - 2)(x + 4) - x^2 = 6 \iff x = 7$ | $(x - 1)(x + 4) - x^2 = 8 \iff x = 4$ | $(x - 2)(x + 6) - x^2 = 8 \iff x = 5$ | $(x - 1)(x + 6) - x^2 = 9 \iff x = 3$ |
| **f** | $(2x - 1)(x + 3) - 2x^2 = 12 \iff x = 3$ | $(2x - 3)(x + 2) - 2x^2 = 5 \iff x = 11$ | $(3x - 1)(x + 2) - 3x^2 = 8 \iff x = 2$ | $(2x - 3)(x + 3) - 2x^2 = 6 \iff x = 5$ |
| **g** | $x^2 - 25 = 0 \iff x = \pm 5$ | $x^2 - 36 = 0 \iff x = \pm 6$ | $x^2 - 49 = 0 \iff x = \pm 7$ | $x^2 - 64 = 0 \iff x = \pm 8$ |
| **h** | $(x - 2)^2 = 9 \iff x \in \{5; -1\}$ | $(x - 3)^2 = 16 \iff x \in \{7; -1\}$ | $(x - 4)^2 = 25 \iff x \in \{9; -1\}$ | $(x - 5)^2 = 16 \iff x \in \{9; 1\}$ |
| **i** | $(x + 3)^2 = 16 \iff x \in \{1; -7\}$ | $(x + 2)^2 = 25 \iff x \in \{3; -7\}$ | $(x + 4)^2 = 36 \iff x \in \{2; -10\}$ | $(x + 5)^2 = 49 \iff x \in \{2; -12\}$ |
| **j** | $(x - 1)^2 - 36 = 0 \iff x \in \{7; -5\}$ | $(x - 2)^2 - 49 = 0 \iff x \in \{9; -5\}$ | $(x - 3)^2 - 64 = 0 \iff x \in \{11; -5\}$ | $(x - 4)^2 - 81 = 0 \iff x \in \{13; -5\}$ |

| **l** | $(2x + 3)^2 = 49 \iff x \in \{2; -5\}$ | $(2x + 1)^2 = 49 \iff x \in \{3; -4\}$ | $(3x + 1)^2 = 25 \iff x \in \left\{\dfrac{4}{3}; -2\right\}$ | $(2x - 5)^2 = 81 \iff x \in \{7; -2\}$ |
