### CÂU 12 (2,0 ĐIỂM) - TÌM $x$
*(Mỗi ý đúng trọn vẹn được **0,5 điểm**)*

#### 🔹 Mã đề 101:
* **a) (0,5 điểm):**
  $$\dfrac{2x - 1}{3} = \dfrac{x + 2}{2} \iff 2(2x - 1) = 3(x + 2) \iff 4x - 2 = 3x + 6 \iff x = 8.$$
  Vậy $x = 8$. *(0,5đ)*
* **b) (0,5 điểm):**
  $$(2x - 6)(x + 5) = 0 \iff \left[\begin{aligned} 2x - 6 &= 0 \\ x + 5 &= 0 \end{aligned}\right. \iff \left[\begin{aligned} x &= 3 \\ x &= -5 \end{aligned}\right.$$
  Vậy $x \in \{3; -5\}$. *(0,5đ)*
* **c) (0,5 điểm):**
  $$\dfrac{x^2 - 9}{x - 3} = 0 \iff \text{ĐKXĐ: } x \ne 3.$$
  Khi đó $\dfrac{(x - 3)(x + 3)}{x - 3} = 0 \iff x + 3 = 0 \iff x = -3\text{ (thỏa mãn ĐKXĐ)}.$$
  Vậy $x = -3$. *(0,5đ)*
* **d) (0,5 điểm):**
  $$x^2 - 6x + 9 = 0 \iff (x - 3)^2 = 0 \iff x - 3 = 0 \iff x = 3.$$
  Vậy $x = 3$. *(0,5đ)*

#### 🔹 Mã đề 102:
* **a) (0,5 điểm):** $\dfrac{3x - 1}{4} = \dfrac{x + 3}{2} \iff 3x - 1 = 2(x + 3) \iff 3x - 1 = 2x + 6 \iff x = 7$. Vậy $x = 7$. *(0,5đ)*
* **b) (0,5 điểm):** $(3x - 9)(x + 4) = 0 \iff x = 3$ hoặc $x = -4$. Vậy $x \in \{3; -4\}$. *(0,5đ)*
* **c) (0,5 điểm):** $\dfrac{x^2 - 16}{x - 4} = 0 \iff$ ĐKXĐ $x \ne 4$. Rút gọn: $x + 4 = 0 \iff x = -4$ (TM). Vậy $x = -4$. *(0,5đ)*
* **d) (0,5 điểm):** $x^2 - 8x + 16 = 0 \iff (x - 4)^2 = 0 \iff x = 4$. Vậy $x = 4$. *(0,5đ)*

#### 🔹 Mã đề 103:

### CÂU 13 (2,0 ĐIỂM) - HÌNH HỌC ĐỊNH LÍ PYTHAGORE & HỆ QUẢ ĐỊNH LÍ THALÈS

#### 🔹 Mã đề 101:
* **a) (1,0 điểm):**
  - Áp dụng định lí Pythagore vào tam giác $ABC$ vuông tại $A$:
    $$BC^2 = AB^2 + AC^2 = 6^2 + 8^2 = 36 + 64 = 100.$$ *(0,5đ)*
  - Suy ra $BC = \sqrt{100} = 10\text{ cm}$. *(0,5đ)*
* **b) (1,0 điểm):**
  - Vì $DE \parallel BC$ ($D \in AB, E \in AC$), áp dụng hệ quả của định lí Thalès trong tam giác $ABC$:
    $$\dfrac{AD}{AB} = \dfrac{AE}{AC} = \dfrac{DE}{BC}.$$ *(0,25đ)*
  - Thay số: $\dfrac{3}{6} = \dfrac{AE}{8} = \dfrac{DE}{10} = \dfrac{1}{2}$. *(0,25đ)*
  - Tính được:
    $$AE = \dfrac{1}{2} \cdot 8 = 4\text{ cm}. \quad (0{,}25\text{ đ})$$
    $$DE = \dfrac{1}{2} \cdot 10 = 5\text{ cm}. \quad (0{,}25\text{ đ})$$

#### 🔹 Mã đề 102:
* **a) (1,0 điểm):**
  - Áp dụng định lí Pythagore: $BC = \sqrt{AB^2 + AC^2} = \sqrt{9^2 + 12^2} = \sqrt{225} = 15\text{ cm}$. *(1,0đ)*
* **b) (1,0 điểm):**
  - Vì $DE \parallel BC$, theo hệ quả định lí Thalès: $\dfrac{AD}{AB} = \dfrac{AE}{AC} = \dfrac{DE}{BC} \iff \dfrac{6}{9} = \dfrac{AE}{12} = \dfrac{DE}{15} = \dfrac{2}{3}$. *(0,5đ)*
  - Suy ra: $AE = \dfrac{2}{3} \cdot 12 = 8\text{ cm}$ và $DE = \dfrac{2}{3} \cdot 15 = 10\text{ cm}$. *(0,5đ)*

#### 🔹 Mã đề 103:
* **a) (1,0 điểm):**
  - Áp dụng định lí Pythagore: $BC = \sqrt{AB^2 + AC^2} = \sqrt{8^2 + 6^2} = \sqrt{100} = 10\text{ cm}$. *(1,0đ)*
* **b) (1,0 điểm):**
  - Vì $DE \parallel BC$, theo hệ quả định lí Thalès: $\dfrac{AD}{AB} = \dfrac{AE}{AC} = \dfrac{DE}{BC} \iff \dfrac{4}{8} = \dfrac{AE}{6} = \dfrac{DE}{10} = \dfrac{1}{2}$. *(0,5đ)*
  - Suy ra: $AE = \dfrac{1}{2} \cdot 6 = 3\text{ cm}$ và $DE = \dfrac{1}{2} \cdot 10 = 5\text{ cm}$. *(0,5đ)*

#### 🔹 Mã đề 104:

### CÂU 14 (0,5 ĐIỂM) - BÀI TOÁN CỰC TRỊ PHÂN HÓA ĐIỂM 10

#### 🔹 Mã đề 101:
* Ta có mẫu số: $x^2 - 4x + 7 = (x^2 - 4x + 4) + 3 = (x - 2)^2 + 3$. *(0,25đ)*
* Vì $(x - 2)^2 \ge 0$ với mọi $x \in \mathbb{R}$, nên $(x - 2)^2 + 3 \ge 3 > 0$.
  Do tử số $12 > 0$ và mẫu số nhỏ nhất bằng $3$, ta có:
  $$A = \dfrac{12}{(x - 2)^2 + 3} \le \dfrac{12}{3} = 4.$$
  Dấu "$=$" xảy ra khi $(x - 2)^2 = 0 \iff x = 2$.
  Vậy giá trị lớn nhất của biểu thức $A$ là $4$, đạt được khi $x = 2$. *(0,25đ)*

#### 🔹 Mã đề 102:
* Ta có mẫu số: $x^2 - 6x + 14 = (x - 3)^2 + 5 \ge 5 > 0$ với mọi $x \in \mathbb{R}$. *(0,25đ)*
* Suy ra $B = \dfrac{15}{(x - 3)^2 + 5} \le \dfrac{15}{5} = 3$. Dấu "$=$" xảy ra khi $x = 3$.
  Vậy giá trị lớn nhất của biểu thức $B$ là $3$, đạt được khi $x = 3$. *(0,25đ)*

#### 🔹 Mã đề 103:
