## 📝 II. LỜI GIẢI CHI TIẾT MÃ ĐỀ 101

### 📌 BÀI 1 (5,0 ĐIỂM) - TRANG 1/2

* **a) (0,5 điểm)** Rút gọn $\dfrac{3x + 9}{x^2 - 9}$
  * Tử thức: $3x + 9 = 3(x + 3)$
  * Mẫu thức: $x^2 - 9 = (x - 3)(x + 3)$ *(0,25đ)*
  * Ta có: $\dfrac{3(x + 3)}{(x - 3)(x + 3)} = \dfrac{3}{x - 3}$ *(0,25đ)*

* **b) (0,5 điểm)** Rút gọn $\dfrac{4x + 16}{x^2 - 16}$
  * Tử thức: $4x + 16 = 4(x + 4)$
  * Mẫu thức: $x^2 - 16 = (x - 4)(x + 4)$ *(0,25đ)*
  * Ta có: $\dfrac{4(x + 4)}{(x - 4)(x + 4)} = \dfrac{4}{x - 4}$ *(0,25đ)*

* **c) (0,5 điểm)** Rút gọn $\dfrac{x^2 - 16}{(x + 4)^2}$
  * Tử thức: $x^2 - 16 = (x - 4)(x + 4)$ *(0,25đ)*
  * Ta có: $\dfrac{(x - 4)(x + 4)}{(x + 4)^2} = \dfrac{x - 4}{x + 4}$ *(0,25đ)*

* **d) (0,5 điểm)** Rút gọn $\dfrac{x^2 - 25}{(x + 5)^2}$
  * Tử thức: $x^2 - 25 = (x - 5)(x + 5)$ *(0,25đ)*
  * Ta có: $\dfrac{(x - 5)(x + 5)}{(x + 5)^2} = \dfrac{x - 5}{x + 5}$ *(0,25đ)*

* **e) (0,5 điểm)** Rút gọn $\dfrac{x^2 - 6x + 9}{2x - 6}$
  * Tử thức: $x^2 - 6x + 9 = (x - 3)^2$
  * Mẫu thức: $2x - 6 = 2(x - 3)$ *(0,25đ)*
  * Ta có: $\dfrac{(x - 3)^2}{2(x - 3)} = \dfrac{x - 3}{2}$ *(0,25đ)*

* **f) (0,5 điểm)** Rút gọn $\dfrac{x^2 - 8x + 16}{3x - 12}$
  * Tử thức: $x^2 - 8x + 16 = (x - 4)^2$
  * Mẫu thức: $3x - 12 = 3(x - 4)$ *(0,25đ)*
  * Ta có: $\dfrac{(x - 4)^2}{3(x - 4)} = \dfrac{x - 4}{3}$ *(0,25đ)*

* **g) (0,5 điểm)** Rút gọn $\dfrac{x^2 - 3x}{x^2 - 9}$
  * Tử thức: $x^2 - 3x = x(x - 3)$
  * Mẫu thức: $x^2 - 9 = (x - 3)(x + 3)$ *(0,25đ)*
  * Ta có: $\dfrac{x(x - 3)}{(x - 3)(x + 3)} = \dfrac{x}{x + 3}$ *(0,25đ)*

* **h) (0,5 điểm)** Rút gọn $\dfrac{x^2 + 4x}{x^2 - 16}$
  * Tử thức: $x^2 + 4x = x(x + 4)$
  * Mẫu thức: $x^2 - 16 = (x - 4)(x + 4)$ *(0,25đ)*
  * Ta có: $\dfrac{x(x + 4)}{(x - 4)(x + 4)} = \dfrac{x}{x - 4}$ *(0,25đ)*

* **i) (0,5 điểm)** Rút gọn $\dfrac{x^2 - 4x + 4}{x^2 - 4}$
  * Tử thức: $x^2 - 4x + 4 = (x - 2)^2$
  * Mẫu thức: $x^2 - 4 = (x - 2)(x + 2)$ *(0,25đ)*
  * Ta có: $\dfrac{(x - 2)^2}{(x - 2)(x + 2)} = \dfrac{x - 2}{x + 2}$ *(0,25đ)*

* **j) (0,5 điểm)** Rút gọn $\dfrac{x^2 + 6x + 9}{x^2 - 9}$
  * Tử thức: $x^2 + 6x + 9 = (x + 3)^2$
  * Mẫu thức: $x^2 - 9 = (x - 3)(x + 3)$ *(0,25đ)*
  * Ta có: $\dfrac{(x + 3)^2}{(x - 3)(x + 3)} = \dfrac{x + 3}{x - 3}$ *(0,25đ)*

### 📌 BÀI 2 (5,0 ĐIỂM) - TRANG 2/2

* **a) (0,5 điểm)** Rút gọn $\dfrac{5x + 10}{x^2 - 4}$
  * Tử thức: $5x + 10 = 5(x + 2)$
  * Mẫu thức: $x^2 - 4 = (x - 2)(x + 2)$ *(0,25đ)*
  * Ta có: $\dfrac{5(x + 2)}{(x - 2)(x + 2)} = \dfrac{5}{x - 2}$ *(0,25đ)*

* **b) (0,5 điểm)** Rút gọn $\dfrac{2x - 8}{x^2 - 16}$
  * Tử thức: $2x - 8 = 2(x - 4)$
  * Mẫu thức: $x^2 - 16 = (x - 4)(x + 4)$ *(0,25đ)*
  * Ta có: $\dfrac{2(x - 4)}{(x - 4)(x + 4)} = \dfrac{2}{x + 4}$ *(0,25đ)*

* **c) (0,5 điểm)** Rút gọn $\dfrac{x^2 - 36}{(x - 6)^2}$
  * Tử thức: $x^2 - 36 = (x - 6)(x + 6)$ *(0,25đ)*
  * Ta có: $\dfrac{(x - 6)(x + 6)}{(x - 6)^2} = \dfrac{x + 6}{x - 6}$ *(0,25đ)*

* **d) (0,5 điểm)** Rút gọn $\dfrac{x^2 - 49}{(x - 7)^2}$
  * Tử thức: $x^2 - 49 = (x - 7)(x + 7)$ *(0,25đ)*
  * Ta có: $\dfrac{(x - 7)(x + 7)}{(x - 7)^2} = \dfrac{x + 7}{x - 7}$ *(0,25đ)*

* **e) (0,5 điểm)** Rút gọn $\dfrac{x - 3}{9 - x^2}$
  * Mẫu thức: $9 - x^2 = -(x^2 - 9) = -(x - 3)(x + 3)$ *(0,25đ)*
  * Ta có: $\dfrac{x - 3}{-(x - 3)(x + 3)} = -\dfrac{1}{x + 3}$ *(0,25đ)*

* **f) (0,5 điểm)** Rút gọn $\dfrac{x - 5}{25 - x^2}$
  * Mẫu thức: $25 - x^2 = -(x^2 - 25) = -(x - 5)(x + 5)$ *(0,25đ)*
  * Ta có: $\dfrac{x - 5}{-(x - 5)(x + 5)} = -\dfrac{1}{x + 5}$ *(0,25đ)*

* **g) (0,5 điểm)** Rút gọn $\dfrac{xy - 2y + 3x - 6}{x^2 - 4}$
  * Tử thức: $xy - 2y + 3x - 6 = y(x - 2) + 3(x - 2) = (x - 2)(y + 3)$
  * Mẫu thức: $x^2 - 4 = (x - 2)(x + 2)$ *(0,25đ)*
  * Ta có: $\dfrac{(x - 2)(y + 3)}{(x - 2)(x + 2)} = \dfrac{y + 3}{x + 2}$ *(0,25đ)*

* **h) (0,5 điểm)** Rút gọn $\dfrac{xy + 3y + 2x + 6}{x^2 - 9}$
  * Tử thức: $xy + 3y + 2x + 6 = y(x + 3) + 2(x + 3) = (x + 3)(y + 2)$
  * Mẫu thức: $x^2 - 9 = (x - 3)(x + 3)$ *(0,25đ)*
  * Ta có: $\dfrac{(x + 3)(y + 2)}{(x - 3)(x + 3)} = \dfrac{y + 2}{x - 3}$ *(0,25đ)*

* **i) (0,5 điểm)** Rút gọn $\dfrac{xy - 4y + 3x - 12}{x^2 - 16}$
  * Tử thức: $xy - 4y + 3x - 12 = y(x - 4) + 3(x - 4) = (x - 4)(y + 3)$
  * Mẫu thức: $x^2 - 16 = (x - 4)(x + 4)$ *(0,25đ)*
  * Ta có: $\dfrac{(x - 4)(y + 3)}{(x - 4)(x + 4)} = \dfrac{y + 3}{x + 4}$ *(0,25đ)*

* **j) (0,5 điểm)** Rút gọn $\dfrac{xy + 5y - 2x - 10}{x^2 - 25}$
  * Tử thức: $xy + 5y - 2x - 10 = y(x + 5) - 2(x + 5) = (x + 5)(y - 2)$
  * Mẫu thức: $x^2 - 25 = (x - 5)(x + 5)$ *(0,25đ)*
  * Ta có: $\dfrac{(x + 5)(y - 2)}{(x - 5)(x + 5)} = \dfrac{y - 2}{x - 5}$ *(0,25đ)*
