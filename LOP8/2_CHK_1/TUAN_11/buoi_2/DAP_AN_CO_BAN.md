### 📌 MÃ ĐỀ 101

#### CÂU 1 (5,0 điểm). Thực hiện các phép tính:
- **a) (0,4đ)** $2x(3x + 4) = 2x \cdot 3x + 2x \cdot 4 = 6x^2 + 8x$.
- **b) (0,4đ)** $3x(2x^2 - 4x + 1) = 3x \cdot 2x^2 - 3x \cdot 4x + 3x \cdot 1 = 6x^3 - 12x^2 + 3x$.
- **c) (0,4đ)** $(4x^2y - 3xy^2) + (2x^2y + 5xy^2) = (4x^2y + 2x^2y) + (-3xy^2 + 5xy^2) = 6x^2y + 2xy^2$.
- **d) (0,4đ)** $(5x^3 - 2x^2 + 4) - (2x^3 - 2x^2 - 5) = 5x^3 - 2x^2 + 4 - 2x^3 + 2x^2 + 5 = 3x^3 + 9$.
- **e) (0,4đ)** $(x + 3)(x + 5) = x^2 + 5x + 3x + 15 = x^2 + 8x + 15$.
- **f) (0,4đ)** $(x - 2)(x + 6) = x^2 + 6x - 2x - 12 = x^2 + 4x - 12$.
- **g) (0,4đ)** $(2x + 3)^2 = (2x)^2 + 2 \cdot 2x \cdot 3 + 3^2 = 4x^2 + 12x + 9$.
- **h) (0,4đ)** $(3x - 2)^2 = (3x)^2 - 2 \cdot 3x \cdot 2 + 2^2 = 9x^2 - 12x + 4$.
- **i) (0,4đ)** $(2x - 5)(2x + 5) = (2x)^2 - 5^2 = 4x^2 - 25$.
- **j) (0,4đ)** $(12x^4y^3 - 8x^3y^2 + 4x^2y) : 4x^2y = 12x^4y^3 : 4x^2y - 8x^3y^2 : 4x^2y + 4x^2y : 4x^2y = 3x^2y^2 - 2xy + 1$.
- **k) (0,5đ)**
  - Khai triển: $(x + 4)^2 - x(x + 5) = (x^2 + 8x + 16) - (x^2 + 5x)$ *(0,25đ)*
  - Thu gọn: $= x^2 + 8x + 16 - x^2 - 5x = 3x + 16$ *(0,25đ)*
- **l) (0,5đ)** Đặt tính chia đa thức $(2x^3 - 5x^2 + 6x - 2) : (2x - 1)$:
  - Lấy $2x^3 : 2x = x^2$, nhân lại và trừ: $(2x^3 - 5x^2 + 6x - 2) - x^2(2x - 1) = -4x^2 + 6x - 2$ *(0,2đ)*
  - Lấy $-4x^2 : 2x = -2x$, nhân lại và trừ: $(-4x^2 + 6x - 2) - (-2x)(2x - 1) = 4x - 2$ *(0,15đ)*
  - Lấy $4x : 2x = 2$, nhân lại và trừ dư $0$.
  - Vậy thương là: $x^2 - 2x + 2$ *(0,15đ)*

#### CÂU 2 (5,0 điểm). Phân tích các đa thức sau thành nhân tử:
- **a) (0,4đ)** $3x^2 - 6x = 3x(x - 2)$.
- **b) (0,4đ)** $5x^2y - 10xy^2 = 5xy(x - 2y)$.
- **c) (0,4đ)** $x(x - 3) + 5(x - 3) = (x - 3)(x + 5)$.
- **d) (0,4đ)** $x^2 - 16 = x^2 - 4^2 = (x - 4)(x + 4)$.
- **e) (0,4đ)** $4x^2 - 9 = (2x)^2 - 3^2 = (2x - 3)(2x + 3)$.
- **f) (0,4đ)** $x^2 - 6x + 9 = x^2 - 2 \cdot x \cdot 3 + 3^2 = (x - 3)^2$.
- **g) (0,4đ)** $4x^2 - 12x + 9 = (2x)^2 - 2 \cdot 2x \cdot 3 + 3^2 = (2x - 3)^2$.
- **h) (0,4đ)** Nhóm hạng tử: $xy + 3y + 2x + 6 = (xy + 3y) + (2x + 6) = y(x + 3) + 2(x + 3) = (x + 3)(y + 2)$.
- **i) (0,4đ)** Nhóm hạng tử: $xy - 2y + 3x - 6 = (xy - 2y) + (3x - 6) = y(x - 2) + 3(x - 2) = (x - 2)(y + 3)$.
- **j) (0,4đ)** Nhóm 3 hạng tử đầu: $(x^2 - 2xy + y^2) - 16 = (x - y)^2 - 4^2 = (x - y - 4)(x - y + 4)$.
- **k) (0,5đ)**
  - Tách hạng tử: $x^2 - 5x + 6 = x^2 - 2x - 3x + 6$ *(0,25đ)*
  - Đưa về tích: $= x(x - 2) - 3(x - 2) = (x - 2)(x - 3)$ *(0,25đ)*
- **l) (0,5đ)**
  - Đặt nhân tử chung: $2x^3 - 8x = 2x(x^2 - 4)$ *(0,25đ)*
  - Áp dụng hằng đẳng thức: $= 2x(x - 2)(x + 2)$ *(0,25đ)*
