## 📌 TRANG 8: DẠNG 8 -- TÌM NGUYÊN HÀM F(x) VÀ TOÁN THỰC TẾ

### Bài 15 (4,0 điểm -- 1,0 điểm/ý). Tìm nguyên hàm $F(x)$ thỏa mãn điều kiện cho trước:
* **a)** $F(x) = \int (2x - 5) \, dx = x^2 - 5x + C$.
  Vì $F(1) = 3 \implies 1^2 - 5(1) + C = 3 \implies -4 + C = 3 \implies C = 7$.
  Vậy $\mathbf{F(x) = x^2 - 5x + 7}$.
* **b)** $F(x) = \int (3x^2 - 4x + 2) \, dx = x^3 - 2x^2 + 2x + C$.
  Vì $F(2) = 7 \implies 2^3 - 2(2^2) + 2(2) + C = 7 \implies 4 + C = 7 \implies C = 3$.
  Vậy $\mathbf{F(x) = x^3 - 2x^2 + 2x + 3}$.
* **c)** $F(x) = \int \dfrac{1}{2x - 1} \, dx = \dfrac{1}{2}\ln|2x - 1| + C$.
  Vì $F(1) = 4 \implies \dfrac{1}{2}\ln|2(1) - 1| + C = 4 \implies \dfrac{1}{2}\ln 1 + C = 4 \implies C = 4$.
  Vậy $\mathbf{F(x) = \dfrac{1}{2}\ln|2x - 1| + 4}$.
* **d)** $F(x) = \int (2\cos x + 3e^x) \, dx = 2\sin x + 3e^x + C$.
  Vì $F(0) = 5 \implies 2\sin 0 + 3e^0 + C = 5 \implies 3 + C = 5 \implies C = 2$.
  Vậy $\mathbf{F(x) = 2\sin x + 3e^x + 2}$.

### Bài 16 (4,0 điểm -- 2,0 điểm/ý). Bài toán thực tế chuyển động (Toán ứng dụng):
* **a)** Phương trình vị trí của chất điểm:
  $$s(t) = \int v(t) \, dt = \int (3t^2 - 4t + 1) \, dt = t^3 - 2t^2 + t + C.$$
  Biết tại $t = 0$, $s(0) = 5 \implies 0^3 - 2(0)^2 + 0 + C = 5 \implies C = 5$.
  Do đó: $s(t) = t^3 - 2t^2 + t + 5\text{ (m)}$.
  Tại thời điểm $t = 3\text{ s}$: $s(3) = 3^3 - 2(3)^2 + 3 + 5 = 27 - 18 + 3 + 5 = 17\text{ (m)}$.
  Quãng đường chất điểm đi được sau $3$ giây:
  $$\Delta s = s(3) - s(0) = 17 - 5 = \mathbf{12\text{ (m)}}.$$
* **b)** Phương trình vận tốc của đoàn tàu:
  $$v(t) = \int a(t) \, dt = \int (-2) \, dt = -2t + C.$$
  Biết vận tốc ban đầu tại $t = 0$ là $v_0 = 20\text{ m/s} \implies -2(0) + C = 20 \implies C = 20$.
  Vậy phương trình vận tốc: $v(t) = -2t + 20\text{ (m/s)}$.
  Tàu dừng lại khi $v(t) = 0 \iff -2t + 20 = 0 \iff \mathbf{t = 10\text{ (giây)}}$.
  Phương trình quãng đường đi được từ lúc hãm phanh:
  $$s(t) = \int v(t) \, dt = \int (-2t + 20) \, dt = -t^2 + 20t + C'.$$
  Chọn gốc vị trí lúc bắt đầu hãm phanh $s(0) = 0 \implies C' = 0 \implies s(t) = -t^2 + 20t$.
  Quãng đường tàu đi được từ lúc hãm phanh đến khi dừng hẳn ($t = 10\text{ s}$):
  $$s(10) = -(10)^2 + 20(10) = -100 + 200 = \mathbf{100\text{ (m)}}.$$
