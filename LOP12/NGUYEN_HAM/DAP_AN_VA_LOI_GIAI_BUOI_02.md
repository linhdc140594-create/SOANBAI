## 📄 TRANG 7: TÌM NGUYÊN HÀM $F(x)$ VỚI ĐIỀU KIỆN $F(x_0) = y_0$

### Bài 13 (4,0 điểm). Hàm đa thức và phân thức
* **a)** $F(x) = \int (3x^2 - 4x + 5) dx = x^3 - 2x^2 + 5x + C$.  
  $F(1) = 1 - 2 + 5 + C = 4 + C = 6 \implies C = 2$.  
  $\implies \mathbf{F(x) = x^3 - 2x^2 + 5x + 2}$.
* **b)** $F(x) = \int \frac{1}{2x - 3} dx = \frac{1}{2}\ln|2x - 3| + C$.  
  Trên $(\frac{3}{2}; +\infty)$, $2x - 3 > 0 \implies F(x) = \frac{1}{2}\ln(2x - 3) + C$.  
  $F(2) = \frac{1}{2}\ln 1 + C = C = 3 \implies C = 3$.  
  $\implies \mathbf{F(x) = \frac{1}{2}\ln(2x - 3) + 3}$.
* **c)** $\frac{2x + 1}{x + 1} = 2 - \frac{1}{x + 1} \implies F(x) = 2x - \ln|x + 1| + C$.  
  Trên $(-1; +\infty)$, $x + 1 > 0 \implies F(x) = 2x - \ln(x + 1) + C$.  
  $F(0) = 0 - 0 + C = 4 \implies C = 4$.  
  $\implies \mathbf{F(x) = 2x - \ln(x + 1) + 4}$.
* **d)** $F(x) = \frac{1}{2}\ln|\frac{x - 1}{x + 1}| + C$. Trên $(1; +\infty)$, $\frac{x - 1}{x + 1} > 0$.  
  $F(2) = \frac{1}{2}\ln\frac{1}{3} + C = -\frac{1}{2}\ln 3 + C = \ln 3 \implies C = \frac{3}{2}\ln 3$.  
  $\implies \mathbf{F(x) = \frac{1}{2}\ln\left(\frac{x - 1}{x + 1}\right) + \frac{3}{2}\ln 3}$.

### Bài 14 (4,0 điểm). Hàm lượng giác và hàm số mũ
* **a)** $F(x) = \int (2\sin 2x + 3\cos x) dx = -\cos 2x + 3\sin x + C$.  
  $F(0) = -1 + 0 + C = 2 \implies C = 3$.  
  $\implies \mathbf{F(x) = -\cos 2x + 3\sin x + 3}$.
* **b)** $f(x) = 4\cos^2 x = 2 + 2\cos 2x \implies F(x) = 2x + \sin 2x + C$.  
  $F(\frac{\pi}{4}) = \frac{\pi}{2} + \sin\frac{\pi}{2} + C = \frac{\pi}{2} + 1 + C = \frac{\pi}{2} \implies C = -1$.  
  $\implies \mathbf{F(x) = 2x + \sin 2x - 1}$.
* **c)** $F(x) = \int (3e^{3x} - 2x) dx = e^{3x} - x^2 + C$.  
  $F(0) = 1 - 0 + C = 5 \implies C = 4$.  
  $\implies \mathbf{F(x) = e^{3x} - x^2 + 4}$.
* **d)** $F(x) = \int (2^x \ln 2 + e^{2x}) dx = 2^x + \frac{1}{2}e^{2x} + C$.  
  $F(0) = 1 + \frac{1}{2} + C = \frac{3}{2} + C = \frac{5}{2} \implies C = 1$.  
  $\implies \mathbf{F(x) = 2^x + \frac{1}{2}e^{2x} + 1}$.

### Bài 15 (4,0 điểm). Chuyển động học (Vật lý 12)
* **a) (2,0 điểm) [Ô tô hãm phanh]:**
  * *1)* Ta có $v(t) = \int a(t) \, dt = \int -4 \, dt = -4t + C_1$.  
    Tại $t = 0, v(0) = 20 \implies C_1 = 20$. Do đó: $\mathbf{v(t) = 20 - 4t\text{ (m/s)}}$.  
    Xe dừng hẳn khi $v(t) = 0 \iff 20 - 4t = 0 \iff \mathbf{t = 5\text{ (giây)}}$.
  * *2)* Quãng đường: $s(t) = \int v(t) \, dt = \int (20 - 4t) \, dt = 20t - 2t^2 + C_2$.  
    Với $s(0) = 0 \implies C_2 = 0 \implies s(t) = 20t - 2t^2$.  
    Quãng đường trượt đến khi dừng: $s(5) = 20(5) - 2(5^2) = 100 - 50 = \mathbf{50\text{ (m)}}$.
* **b) (2,0 điểm) [Tàu hỏa tăng tốc]:**

  * *2)* Quãng đường: $s(t) = \int 0{,}3t^2 \, dt = 0{,}1t^3 + C_2$.

### Bài 16 (4,0 điểm). Sinh học và Kinh tế học
* **a) (2,0 điểm) [Sinh học -- Tăng trưởng vi khuẩn]:**
  * *1)* Ta có $N(t) = \int N'(t) \, dt = \int 150e^{0{,}3t} \, dt = \frac{150}{0{,}3}e^{0{,}3t} + C = 500e^{0{,}3t} + C$.  
    Tại $t = 0, N(0) = 500 + C = 500 \implies C = 0$.  
    Vậy hàm số biểu diễn số lượng vi khuẩn là: $\mathbf{N(t) = 500e^{0{,}3t}}$.
  * *2)* Số lượng vi khuẩn sau 4 giờ:  
    $N(4) = 500 \cdot e^{0{,}3 \times 4} = 500 \cdot e^{1{,}2} \approx 500 \times 3{,}320117 \approx \mathbf{1\,660\text{ con}}$.
* **b) (2,0 điểm) [Kinh tế -- Chi phí sản xuất]:**
  * *1)* Ta có tổng chi phí $C(x) = \int C'(x) \, dx = \int (3x^2 - 12x + 40) \, dx = x^3 - 6x^2 + 40x + C_0$.  
    Chi phí cố định ban đầu $C(0) = 500 \implies C_0 = 500$.  
    Vậy hàm tổng chi phí là: $\mathbf{C(x) = x^3 - 6x^2 + 40x + 500\text{ (nghìn đồng)}}$.
  * *2)* Chi phí khi sản xuất 10 sản phẩm:  
    $C(10) = 10^3 - 6(10^2) + 40(10) + 500 = 1\,000 - 600 + 400 + 500 = \mathbf{1\,300\text{ nghìn đồng}}$ ($1\,300\,000$ đồng).
