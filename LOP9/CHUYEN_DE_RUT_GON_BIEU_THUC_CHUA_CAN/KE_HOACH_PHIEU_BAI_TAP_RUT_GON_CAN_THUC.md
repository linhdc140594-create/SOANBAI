## 🎯 I. MỤC TIÊU & NGUYÊN TẮC CỐT LÕI

Theo đúng định hướng chỉ đạo của Thầy:
1. **Trọng tâm tuyệt đối:** Phiếu bài tập **CHỈ TẬP TRUNG 100% VÀO KỸ NĂNG RÚT GỌN BIỂU THỨC CHỨA CĂN**, loại bỏ hoàn toàn các câu hỏi phụ rườm rà (không hỏi tìm $x$ nguyên, không hỏi so sánh $P$ với $m$, không hỏi tìm $x$ để $P > 0$).
2. **Lộ trình lũy tiến từ phần cơ bản nhất:** Thiết kế mạch kiến thức tăng dần độ khó qua 4 cấp độ bài tập:
   * **Cấp độ 1:** Rút gọn biểu thức số chứa căn bậc hai (Áp dụng $\sqrt{A^2} = |A|$, đưa thừa số ra/vào dấu căn, trục căn thức ở mẫu số).
   * **Cấp độ 2:** Rút gọn biểu thức chứa căn bậc hai có biến cơ bản (Đồng dạng căn thức có biến, phân tích tử và mẫu thành nhân tử để triệt tiêu trực tiếp).
   * **Cấp độ 3:** Rút gọn biểu thức phân thức chứa căn bậc hai có biến (Kỹ năng quy đồng mẫu thức, mẫu liên hợp, mẫu hiệu hai bình phương $x - a^2$).
   * **Cấp độ 4:** Rút gọn biểu thức tổng hợp chuẩn form thi tuyển sinh vào lớp 10 (Kỹ năng đổi dấu mẫu số, hằng đẳng thức lập phương, ngoặc lồng nhau).
3. **Quy cách xuất bản:**
   * Thiết kế chuẩn **4 trang A4** (tương đương 2 tờ in 2 mặt), trình bày đẹp mắt, thoáng đãng.
   * Dưới mỗi bài tập đều có **dòng kẻ chấm mờ viết tay (`\dongke`)** đạt chuẩn khoảng cách viết tay THCS để học sinh làm bài trực tiếp vào phiếu.
   * Số liệu toán học chuẩn xác 100%, nghiệm và kết quả rút gọn tối giản, đẹp mắt.

### 🔹 TRANG 1: CẤP ĐỘ 1 - RÚT GỌN BIỂU THỨC SỐ CHỨA CĂN (CƠ BẢN NHẤT)

#### Bài 1 (1,5 điểm). Áp dụng hằng đẳng thức $\sqrt{A^2} = |A|$, rút gọn các biểu thức sau:
* $a)$ $A_1 = \sqrt{(3 - \sqrt{5})^2} + \sqrt{5}$
  - *Hướng dẫn:* $= |3 - \sqrt{5}| + \sqrt{5} = 3 - \sqrt{5} + \sqrt{5} = 3$.
* $b)$ $A_2 = \sqrt{(\sqrt{2} - 1)^2} + \sqrt{(\sqrt{2} - 3)^2}$
  - *Hướng dẫn:* $= (\sqrt{2} - 1) + (3 - \sqrt{2}) = 2$.
* $c)$ $A_3 = \sqrt{4 - 2\sqrt{3}} - \sqrt{3}$
  - *Hướng dẫn:* $= \sqrt{(\sqrt{3} - 1)^2} - \sqrt{3} = \sqrt{3} - 1 - \sqrt{3} = -1$.
* $d)$ $A_4 = \sqrt{7 + 4\sqrt{3}} - \sqrt{7 - 4\sqrt{3}}$
  - *Hướng dẫn:* $= \sqrt{(2 + \sqrt{3})^2} - \sqrt{(2 - \sqrt{3})^2} = (2 + \sqrt{3}) - (2 - \sqrt{3}) = 2\sqrt{3}$.

#### Bài 2 (1,5 điểm). Đưa thừa số ra ngoài dấu căn, rút gọn các biểu thức sau:
* $a)$ $B_1 = 2\sqrt{12} - 3\sqrt{27} + 2\sqrt{75}$
  - *Hướng dẫn:* $= 4\sqrt{3} - 9\sqrt{3} + 10\sqrt{3} = 5\sqrt{3}$.
* $b)$ $B_2 = 3\sqrt{20} - 2\sqrt{45} + 4\sqrt{80}$
  - *Hướng dẫn:* $= 6\sqrt{5} - 6\sqrt{5} + 16\sqrt{5} = 16\sqrt{5}$.
* $c)$ $B_3 = \sqrt{18} - 2\sqrt{50} + 3\sqrt{8} + \sqrt{98}$
  - *Hướng dẫn:* $= 3\sqrt{2} - 10\sqrt{2} + 6\sqrt{2} + 7\sqrt{2} = 6\sqrt{2}$.
* $d)$ $B_4 = (2\sqrt{3} - \sqrt{27} + \sqrt{48}) \cdot \sqrt{3}$
  - *Hướng dẫn:* $= (2\sqrt{3} - 3\sqrt{3} + 4\sqrt{3})\sqrt{3} = 3\sqrt{3} \cdot \sqrt{3} = 9$.

#### Bài 3 (1,5 điểm). Trục căn thức ở mẫu và rút gọn các biểu thức sau:
* $a)$ $C_1 = \dfrac{2}{\sqrt{3} - 1} - \dfrac{2}{\sqrt{3} + 1}$
  - *Hướng dẫn:* $= \dfrac{2(\sqrt{3} + 1) - 2(\sqrt{3} - 1)}{3 - 1} = \dfrac{4}{2} = 2$.
* $b)$ $C_2 = \dfrac{1}{3 - \sqrt{8}} - \dfrac{1}{3 + \sqrt{8}}$
  - *Hướng dẫn:* $= (3 + \sqrt{8}) - (3 - \sqrt{8}) = 2\sqrt{8} = 4\sqrt{2}$.
* $c)$ $C_3 = \dfrac{\sqrt{15} - \sqrt{5}}{\sqrt{3} - 1} - \dfrac{10}{\sqrt{5}}$
  - *Hướng dẫn:* $= \dfrac{\sqrt{5}(\sqrt{3} - 1)}{\sqrt{3} - 1} - 2\sqrt{5} = \sqrt{5} - 2\sqrt{5} = -\sqrt{5}$.

### 🔹 TRANG 2: CẤP ĐỘ 2 - RÚT GỌN BIỂU THỨC CHỨA CĂN CÓ BIẾN CƠ BẢN

#### Bài 4 (1,5 điểm). Rút gọn biểu thức chứa căn thức đồng dạng có biến:
* $a)$ $D_1 = 2\sqrt{4x} - 3\sqrt{9x} + \sqrt{25x}$ (với $x \ge 0$)
  - *Hướng dẫn:* $= 4\sqrt{x} - 9\sqrt{x} + 5\sqrt{x} = 0$.
* $b)$ $D_2 = 3\sqrt{8x} - 2\sqrt{18x} + \sqrt{50x}$ (với $x \ge 0$)
  - *Hướng dẫn:* $= 6\sqrt{2x} - 6\sqrt{2x} + 5\sqrt{2x} = 5\sqrt{2x}$.
* $c)$ $D_3 = \dfrac{1}{2}\sqrt{48x} - \dfrac{2}{3}\sqrt{27x} + \dfrac{\sqrt{75x}}{5}$ (với $x \ge 0$)
  - *Hướng dẫn:* $= 2\sqrt{3x} - 2\sqrt{3x} + \sqrt{3x} = \sqrt{3x}$.

#### Bài 5 (2,0 điểm). Phân tích tử và mẫu thành nhân tử rồi rút gọn phân thức:
* $a)$ $E_1 = \dfrac{x - 4}{\sqrt{x} - 2}$ (với $x \ge 0, x \neq 4$)
  - *Hướng dẫn:* $= \dfrac{(\sqrt{x} - 2)(\sqrt{x} + 2)}{\sqrt{x} - 2} = \sqrt{x} + 2$.
* $b)$ $E_2 = \dfrac{x - 9}{\sqrt{x} + 3}$ (với $x \ge 0$)
  - *Hướng dẫn:* $= \dfrac{(\sqrt{x} - 3)(\sqrt{x} + 3)}{\sqrt{x} + 3} = \sqrt{x} - 3$.
* $c)$ $E_3 = \dfrac{x - 2\sqrt{x}}{\sqrt{x} - 2}$ (với $x > 0, x \neq 4$)
  - *Hướng dẫn:* $= \dfrac{\sqrt{x}(\sqrt{x} - 2)}{\sqrt{x} - 2} = \sqrt{x}$.
* $d)$ $E_4 = \dfrac{x + 3\sqrt{x}}{\sqrt{x} + 3}$ (với $x \ge 0$)
  - *Hướng dẫn:* $= \dfrac{\sqrt{x}(\sqrt{x} + 3)}{\sqrt{x} + 3} = \sqrt{x}$.
* $e)$ $E_5 = \dfrac{x - 2\sqrt{x} + 1}{\sqrt{x} - 1}$ (với $x \ge 0, x \neq 1$)
  - *Hướng dẫn:* $= \dfrac{(\sqrt{x} - 1)^2}{\sqrt{x} - 1} = \sqrt{x} - 1$.
* $f)$ $E_6 = \dfrac{x + \sqrt{x} - 6}{\sqrt{x} - 2}$ (với $x \ge 0, x \neq 4$)
  - *Hướng dẫn:* $= \dfrac{(\sqrt{x} - 2)(\sqrt{x} + 3)}{\sqrt{x} - 2} = \sqrt{x} + 3$.

### 🔹 TRANG 3: CẤP ĐỘ 3 - RÚT GỌN PHÂN THỨC QUY ĐỒNG MẪU THỨC

#### Bài 6 (2,0 điểm). Rút gọn các biểu thức sau bằng phương pháp quy đồng mẫu thức:
* $a)$ $F_1 = \left(\dfrac{1}{\sqrt{x} - 2} - \dfrac{1}{\sqrt{x} + 2}\right) \cdot \dfrac{x - 4}{4}$ (với $x \ge 0, x \neq 4$)
  - *Hướng dẫn:* $= \dfrac{(\sqrt{x} + 2) - (\sqrt{x} - 2)}{x - 4} \cdot \dfrac{x - 4}{4} = \dfrac{4}{x - 4} \cdot \dfrac{x - 4}{4} = 1$.
* $b)$ $F_2 = \left(\dfrac{1}{\sqrt{x} - 1} + \dfrac{1}{\sqrt{x} + 1}\right) : \dfrac{2\sqrt{x}}{x - 1}$ (với $x > 0, x \neq 1$)
  - *Hướng dẫn:* $= \dfrac{(\sqrt{x} + 1) + (\sqrt{x} - 1)}{x - 1} \cdot \dfrac{x - 1}{2\sqrt{x}} = \dfrac{2\sqrt{x}}{x - 1} \cdot \dfrac{x - 1}{2\sqrt{x}} = 1$.
* $c)$ $F_3 = \left(\dfrac{\sqrt{x}}{\sqrt{x} + 1} - \dfrac{\sqrt{x}}{\sqrt{x} - 1}\right) : \dfrac{2\sqrt{x}}{x - 1}$ (với $x > 0, x \neq 1$)
  - *Hướng dẫn:* $= \dfrac{\sqrt{x}(\sqrt{x} - 1) - \sqrt{x}(\sqrt{x} + 1)}{x - 1} \cdot \dfrac{x - 1}{2\sqrt{x}} = \dfrac{-2\sqrt{x}}{x - 1} \cdot \dfrac{x - 1}{2\sqrt{x}} = -1$.

#### Bài 7 (2,0 điểm). Rút gọn các biểu thức có mẫu thức chứa $x - a^2$:
* $a)$ $G_1 = \dfrac{\sqrt{x}}{\sqrt{x} + 3} + \dfrac{2\sqrt{x}}{\sqrt{x} - 3} - \dfrac{3x + 9}{x - 9}$ (với $x \ge 0, x \neq 9$)
  - *Hướng dẫn:* $= \dfrac{\sqrt{x}(\sqrt{x} - 3) + 2\sqrt{x}(\sqrt{x} + 3) - (3x + 9)}{x - 9} = \dfrac{3\sqrt{x} - 9}{x - 9} = \dfrac{3}{\sqrt{x} + 3}$.
* $b)$ $G_2 = \dfrac{\sqrt{x}}{\sqrt{x} - 2} + \dfrac{\sqrt{x}}{\sqrt{x} + 2} - \dfrac{x - 2\sqrt{x}}{x - 4}$ (với $x \ge 0, x \neq 4$)
  - *Hướng dẫn:* $= \dfrac{\sqrt{x}(\sqrt{x} + 2) + \sqrt{x}(\sqrt{x} - 2) - (x - 2\sqrt{x})}{x - 4} = \dfrac{x + 2\sqrt{x}}{x - 4} = \dfrac{\sqrt{x}}{\sqrt{x} - 2}$.

### 🔹 TRANG 4: CẤP ĐỘ 4 - RÚT GỌN BIỂU THỨC TỔNG HỢP (CHUẨN THI VÀO LỚP 10)

#### Bài 8 (2,0 điểm). Rút gọn các biểu thức có yếu tố đổi dấu ở mẫu:
* $a)$ $H_1 = \left(\dfrac{\sqrt{x}}{\sqrt{x} - 2} - \dfrac{4}{x - 2\sqrt{x}}\right) : \dfrac{\sqrt{x} + 2}{\sqrt{x}}$ (với $x > 0, x \neq 4$)
  - *Hướng dẫn:* $= \left(\dfrac{\sqrt{x}}{\sqrt{x} - 2} - \dfrac{4}{\sqrt{x}(\sqrt{x} - 2)}\right) \cdot \dfrac{\sqrt{x}}{\sqrt{x} + 2} = \dfrac{x - 4}{\sqrt{x}(\sqrt{x} - 2)} \cdot \dfrac{\sqrt{x}}{\sqrt{x} + 2} = \dfrac{(\sqrt{x} - 2)(\sqrt{x} + 2)}{\sqrt{x}(\sqrt{x} - 2)} \cdot \dfrac{\sqrt{x}}{\sqrt{x} + 2} = 1$.
* $b)$ $H_2 = \dfrac{2\sqrt{x}}{\sqrt{x} + 3} + \dfrac{\sqrt{x} + 1}{\sqrt{x} - 3} + \dfrac{3 - 11\sqrt{x}}{x - 9}$ (với $x \ge 0, x \neq 9$)
  - *Hướng dẫn:* Đổi dấu mẫu: quy đồng với mẫu chung $(\sqrt{x} - 3)(\sqrt{x} + 3)$:
    Tử $= 2\sqrt{x}(\sqrt{x} - 3) + (\sqrt{x} + 1)(\sqrt{x} + 3) + 3 - 11\sqrt{x} = 2x - 6\sqrt{x} + x + 4\sqrt{x} + 3 + 3 - 11\sqrt{x} = 3x - 13\sqrt{x} + 6 = (3\sqrt{x} - 2)(\sqrt{x} - 3)$.
    Rút gọn $= \dfrac{3\sqrt{x} - 2}{\sqrt{x} + 3}$.

#### Bài 9 (2,0 điểm). Rút gọn các biểu thức tổng hợp chuẩn form Đề thi Tuyển sinh vào 10:
* $a)$ $K_1 = \left(\dfrac{\sqrt{x} + 1}{\sqrt{x} - 1} - \dfrac{\sqrt{x} - 1}{\sqrt{x} + 1} + \dfrac{4\sqrt{x}}{x - 1}\right) : \dfrac{4\sqrt{x}}{x - 1}$ (với $x > 0, x \neq 1$)
  - *Hướng dẫn:* Ngoặc $= \dfrac{(\sqrt{x} + 1)^2 - (\sqrt{x} - 1)^2 + 4\sqrt{x}}{x - 1} = \dfrac{4\sqrt{x} + 4\sqrt{x}}{x - 1} = \dfrac{8\sqrt{x}}{x - 1}$.
    Chia $= \dfrac{8\sqrt{x}}{x - 1} \cdot \dfrac{x - 1}{4\sqrt{x}} = 2$.
* $b)$ $K_2 = \left(\dfrac{x + 2}{x\sqrt{x} - 1} + \dfrac{\sqrt{x} + 1}{x + \sqrt{x} + 1} - \dfrac{1}{\sqrt{x} - 1}\right) : \dfrac{\sqrt{x} - 1}{2}$ (với $x \ge 0, x \neq 1$)
  - *Hướng dẫn:* Dùng $x\sqrt{x} - 1 = (\sqrt{x} - 1)(x + \sqrt{x} + 1)$.
    Tử trong ngoặc $= (x + 2) + (\sqrt{x} + 1)(\sqrt{x} - 1) - (x + \sqrt{x} + 1) = x - \sqrt{x} = \sqrt{x}(\sqrt{x} - 1)$.
    Trong ngoặc $= \dfrac{\sqrt{x}}{x + \sqrt{x} + 1}$.
    Chia $\implies K_2 = \dfrac{2\sqrt{x}}{(\sqrt{x} - 1)(x + \sqrt{x} + 1)} = \dfrac{2\sqrt{x}}{x\sqrt{x} - 1}$.
