### CÂU 1 (2,5 điểm). Giải phương trình tích
* **Đề 101:**
  * a) $(2x - 3)(x + 1) + (x + 1)(x - 4) = 0 \Leftrightarrow (x + 1)(2x - 3 + x - 4) = 0 \Leftrightarrow (x + 1)(3x - 7) = 0 \Leftrightarrow x = -1$ hoặc $x = \dfrac{7}{3}$. *(1,25 đ)*
  * b) $x^2 - 6x + 9 - 4(x - 3) = 0 \Leftrightarrow (x - 3)^2 - 4(x - 3) = 0 \Leftrightarrow (x - 3)(x - 7) = 0 \Leftrightarrow x = 3$ hoặc $x = 7$. *(1,25 đ)*
* **Đề 102:**
  * a) $(3x - 2)(x + 2) + (x + 2)(x - 5) = 0 \Leftrightarrow (x + 2)(4x - 7) = 0 \Leftrightarrow x = -2$ hoặc $x = \dfrac{7}{4}$. *(1,25 đ)*
  * b) $x^2 - 8x + 16 - 3(x - 4) = 0 \Leftrightarrow (x - 4)^2 - 3(x - 4) = 0 \Leftrightarrow (x - 4)(x - 7) = 0 \Leftrightarrow x = 4$ hoặc $x = 7$. *(1,25 đ)*
* **Đề 103:**
  * a) $(2x - 5)(x + 3) + (x + 3)(x - 1) = 0 \Leftrightarrow (x + 3)(3x - 6) = 0 \Leftrightarrow x = -3$ hoặc $x = 2$. *(1,25 đ)*
  * b) $x^2 - 10x + 25 - 2(x - 5) = 0 \Leftrightarrow (x - 5)^2 - 2(x - 5) = 0 \Leftrightarrow (x - 5)(x - 7) = 0 \Leftrightarrow x = 5$ hoặc $x = 7$. *(1,25 đ)*
* **Đề 104:**
  * a) $(3x - 4)(x + 1) + (x + 1)(x - 2) = 0 \Leftrightarrow (x + 1)(4x - 6) = 0 \Leftrightarrow x = -1$ hoặc $x = \dfrac{3}{2}$. *(1,25 đ)*
  * b) $x^2 - 12x + 36 - 5(x - 6) = 0 \Leftrightarrow (x - 6)^2 - 5(x - 6) = 0 \Leftrightarrow (x - 6)(x - 11) = 0 \Leftrightarrow x = 6$ hoặc $x = 11$. *(1,25 đ)*

### CÂU 2 (2,5 điểm). Phương trình chứa ẩn ở mẫu
* **Đề 101:**
  * a) ĐKXĐ: $x \neq 2, x \neq -1$. Quy đồng khử mẫu: $(2x - 1)(x + 1) = (2x + 3)(x - 2) \Leftrightarrow 2x^2 + x - 1 = 2x^2 - x - 6 \Leftrightarrow 2x = -5 \Leftrightarrow x = -\dfrac{5}{2}$ (TMĐK). *(1,25 đ)*
  * b) ĐKXĐ: $x \neq \pm 2$. MTC: $x^2 - 4$. $(x + 2)^2 - (x - 2)^2 = 16 \Leftrightarrow 8x = 16 \Leftrightarrow x = 2$. Đối chiếu ĐKXĐ $\implies$ Loại $x = 2$. Vậy phương trình vô nghiệm $S = \emptyset$. *(1,25 đ)*
* **Đề 102:**
  * a) ĐKXĐ: $x \neq 1, x \neq 3$. $(2x + 1)(x - 3) = (2x - 3)(x - 1) \Leftrightarrow 2x^2 - 5x - 3 = 2x^2 - 5x + 3 \Leftrightarrow -3 = 3$ (vô lý). Vậy phương trình vô nghiệm $S = \emptyset$. *(1,25 đ)*
  * b) ĐKXĐ: $x \neq \pm 3$. $(x + 3)^2 - (x - 3)^2 = 24 \Leftrightarrow 12x = 24 \Leftrightarrow x = 2$ (TMĐK). Tập nghiệm $S = \{2\}$. *(1,25 đ)*
* **Đề 103:**
  * a) ĐKXĐ: $x \neq 1, x \neq -2$. $(2x - 3)(x + 2) = (2x + 1)(x - 1) \Leftrightarrow 2x^2 + x - 6 = 2x^2 - x - 1 \Leftrightarrow 2x = 5 \Leftrightarrow x = \dfrac{5}{2}$ (TMĐK). *(1,25 đ)*
  * b) ĐKXĐ: $x \neq \pm 1$. $(x + 1)^2 - (x - 1)^2 = 8 \Leftrightarrow 4x = 8 \Leftrightarrow x = 2$ (TMĐK). Tập nghiệm $S = \{2\}$. *(1,25 đ)*
* **Đề 104:**
  * a) ĐKXĐ: $x \neq -1, x \neq -5$. $(2x - 1)(x + 5) = (2x + 5)(x + 1) \Leftrightarrow 2x^2 + 9x - 5 = 2x^2 + 7x + 5 \Leftrightarrow 2x = 10 \Leftrightarrow x = 5$ (TMĐK). *(1,25 đ)*
  * b) ĐKXĐ: $x \neq \pm 2$. $(x + 2)^2 - (x - 2)^2 = 8 \Leftrightarrow 8x = 8 \Leftrightarrow x = 1$ (TMĐK). Tập nghiệm $S = \{1\}$. *(1,25 đ)*

### CÂU 3 (2,5 điểm). Bài toán chuyển động thực tế (Trích Đề 27 - DETHI2010)
* **Các bước chấm chi tiết:**
  * Gọi vận tốc dự định ban đầu của ô tô là $v$ ($v > 0$, đơn vị: km/h) *(0,5 đ)*.
  * Quãng đường đi nửa đầu là $100\text{ km}$, thời gian đi nửa đầu là $\dfrac{100}{v}$ (giờ). Thời gian ô tô dừng lại nghỉ là $15\text{ phút} = \dfrac{1}{4}$ (giờ) *(0,5 đ)*.
  * Vận tốc trên nửa quãng đường còn lại là $v + 20$ (km/h), thời gian đi nửa quãng đường sau là $\dfrac{100}{v + 20}$ (giờ) *(0,5 đ)*.
  * Do ô tô đến Y đúng giờ quy định nên tổng thời gian thực tế bằng thời gian dự định ban đầu:
    $$\dfrac{100}{v} + \dfrac{1}{4} + \dfrac{100}{v + 20} = \dfrac{200}{v} \iff \dfrac{100}{v} - \dfrac{100}{v + 20} = \dfrac{1}{4}$$
    $$\iff \dfrac{2000}{v(v + 20)} = \dfrac{1}{4} \iff v(v + 20) = 8000 \iff v^2 + 20v - 8000 = 0$$
    $$\iff (v - 80)(v + 100) = 0 \iff \left[\begin{array}{l} v = 80 \text{ (thỏa mãn điều kiện)} \\ v = -100 \text{ (loại vì } v > 0\text{)} \end{array}\right. \quad \text{*(0,75 đ)*}$$
  * Đối chiếu điều kiện và kết luận: Vận tốc dự định ban đầu của ô tô là $80\text{ km/h}$ *(0,25 đ)*.
* **Áp dụng chung cho 4 mã đề:** Cả 4 mã đề $101, 102, 103, 104$ đều sử dụng bài toán chuẩn Đề 27, kết quả chung $v = 80\text{ km/h}$.

### CÂU 3 (2,5 điểm). Bài toán thực tế chuyển động dưới nước (Trích Đề 41 - DETHI2010)
* **Các bước chấm chi tiết:**
  * Gọi vận tốc thực của ca nô là $v$ ($v > 3$, đơn vị: km/h) *(0,5 đ)*.
  * Vận tốc ca nô khi xuôi dòng là $v + 3$ (km/h); thời gian ca nô xuôi dòng $90\text{ km}$ là $\dfrac{90}{v + 3}$ (giờ) *(0,5 đ)*.
  * Vận tốc ca nô khi ngược dòng là $v - 3$ (km/h); thời gian ca nô ngược dòng $48\text{ km}$ là $\dfrac{48}{v - 3}$ (giờ) *(0,5 đ)*.
  * Vì tổng thời gian cả đi xuôi dòng và ngược dòng là $9$ giờ nên ta có phương trình:
    $$\dfrac{90}{v + 3} + \dfrac{48}{v - 3} = 9 \iff \dfrac{30}{v + 3} + \dfrac{16}{v - 3} = 3$$
    $$\iff 30(v - 3) + 16(v + 3) = 3(v^2 - 9) \iff 46v - 42 = 3v^2 - 27$$
    $$\iff 3v^2 - 46v + 15 = 0 \iff (3v - 1)(v - 15) = 0 \iff \left[\begin{array}{l} v = 15 \text{ (thỏa mãn } v > 3\text{)} \\ v = \dfrac{1}{3} \text{ (loại vì không thỏa mãn } v > 3\text{)} \end{array}\right. \quad \text{*(0,75 đ)*}$$
  * Kết luận: Vận tốc thực của ca nô là $15\text{ km/h}$ *(0,25 đ)*.
* **Áp dụng chung cho 4 mã đề:** Cả 4 mã đề $101, 102, 103, 104$ đều sử dụng bài toán chuẩn Đề 41, kết quả chung $v = 15\text{ km/h}$.
