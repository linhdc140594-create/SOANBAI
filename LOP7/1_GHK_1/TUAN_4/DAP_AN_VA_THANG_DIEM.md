### CÂU 2 (2,5 điểm). Thực hiện phép tính (hợp lý nếu có thể)
*(Mỗi ý đúng hoàn toàn đạt 0,625 điểm)*

* **Mã đề 101:**
  * **a)** $0{,}45 + \frac{11}{20} - \frac{3}{4} = \frac{9}{20} + \frac{11}{20} - \frac{15}{20} = \frac{20}{20} - \frac{15}{20} = 1 - \frac{3}{4} = \frac{1}{4}$.
  * **b)** $\frac{7}{12} \cdot 1{,}(3) + \frac{5}{12} \cdot 1{,}(3) - \frac{1}{3} = \left(\frac{7}{12} + \frac{5}{12}\right) \cdot \frac{4}{3} - \frac{1}{3} = 1 \cdot \frac{4}{3} - \frac{1}{3} = 1$.
  * **c)** $0{,}(7) + \frac{2}{9} - \left(0{,}25 + \frac{3}{4}\right) = \frac{7}{9} + \frac{2}{9} - \left(\frac{1}{4} + \frac{3}{4}\right) = 1 - 1 = 0$.
  * **d)** $\frac{5}{6} : \left[0{,}75 - \left(\frac{1}{2} - 0{,}(3)\right)\right] = \frac{5}{6} : \left[\frac{3}{4} - \left(\frac{1}{2} - \frac{1}{3}\right)\right] = \frac{5}{6} : \left[\frac{3}{4} - \frac{1}{6}\right] = \frac{5}{6} : \frac{7}{12} = \frac{5}{6} \cdot \frac{12}{7} = \frac{10}{7}$.

* **Mã đề 102:**
  * **a)** $0{,}35 + \frac{13}{20} - \frac{1}{2} = \frac{7}{20} + \frac{13}{20} - \frac{10}{20} = 1 - \frac{1}{2} = \frac{1}{2}$.
  * **b)** $\frac{8}{15} \cdot 1{,}(6) + \frac{7}{15} \cdot 1{,}(6) - \frac{2}{3} = \left(\frac{8}{15} + \frac{7}{15}\right) \cdot \frac{5}{3} - \frac{2}{3} = 1 \cdot \frac{5}{3} - \frac{2}{3} = 1$.
  * **c)** $0{,}(8) + \frac{1}{9} - \left(0{,}4 + \frac{3}{5}\right) = \frac{8}{9} + \frac{1}{9} - 1 = 1 - 1 = 0$.
  * **d)** $\frac{7}{12} : \left[0{,}5 - \left(\frac{1}{3} - 0{,}(1)\right)\right] = \frac{7}{12} : \left[\frac{1}{2} - \left(\frac{1}{3} - \frac{1}{9}\right)\right] = \frac{7}{12} : \left[\frac{1}{2} - \frac{2}{9}\right] = \frac{7}{12} : \frac{5}{18} = \frac{21}{10} = 2{,}1$.

* **Mã đề 103:**
  * **a)** $0{,}65 + \frac{7}{20} - \frac{2}{5} = \frac{13}{20} + \frac{7}{20} - \frac{8}{20} = 1 - \frac{2}{5} = \frac{3}{5}$.
  * **b)** $\frac{9}{14} \cdot 2{,}(3) + \frac{5}{14} \cdot 2{,}(3) - \frac{1}{3} = 1 \cdot \frac{7}{3} - \frac{1}{3} = \frac{6}{3} = 2$.
  * **c)** $0{,}(5) + \frac{4}{9} - \left(0{,}125 + \frac{7}{8}\right) = \frac{5}{9} + \frac{4}{9} - 1 = 1 - 1 = 0$.
  * **d)** $\frac{3}{4} : \left[0{,}8 - \left(\frac{2}{5} - 0{,}(2)\right)\right] = \frac{3}{4} : \left[\frac{4}{5} - \left(\frac{2}{5} - \frac{2}{9}\right)\right] = \frac{3}{4} : \frac{28}{45} = \frac{135}{112}$.

* **Mã đề 104:**
  * **a)** $0{,}55 + \frac{9}{20} - \frac{3}{5} = \frac{11}{20} + \frac{9}{20} - \frac{12}{20} = 1 - \frac{3}{5} = \frac{2}{5}$.
  * **b)** $\frac{11}{18} \cdot 1{,}(6) + \frac{7}{18} \cdot 1{,}(6) - \frac{1}{3} = 1 \cdot \frac{5}{3} - \frac{1}{3} = \frac{4}{3}$.
  * **c)** $0{,}(4) + \frac{5}{9} - \left(0{,}375 + \frac{5}{8}\right) = \frac{4}{9} + \frac{5}{9} - 1 = 1 - 1 = 0$.
  * **d)** $\frac{5}{8} : \left[0{,}6 - \left(\frac{1}{2} - 0{,}(1)\right)\right] = \frac{5}{8} : \left[\frac{3}{5} - \frac{7}{18}\right] = \frac{5}{8} : \frac{19}{90} = \frac{225}{76}$.

### CÂU 3 (2,5 điểm). Tìm số hữu tỉ $x$, biết:
*(Mỗi ý đúng hoàn toàn đạt 0,625 điểm)*

* **Mã đề 101:**
  * **a)** $x - 0{,}75 = \frac{1}{2} \Rightarrow x = \frac{1}{2} + \frac{3}{4} = \frac{5}{4}$.
  * **b)** $\frac{2}{3}x + 0{,}(6) = \frac{4}{3} \Rightarrow \frac{2}{3}x + \frac{2}{3} = \frac{4}{3} \Rightarrow \frac{2}{3}x = \frac{2}{3} \Rightarrow x = 1$.
  * **c)** $1{,}(2) - \left(x - \frac{1}{3}\right) = \frac{5}{9} \Rightarrow \frac{11}{9} - \left(x - \frac{3}{9}\right) = \frac{5}{9} \Rightarrow x - \frac{1}{3} = \frac{6}{9} = \frac{2}{3} \Rightarrow x = 1$.
  * **d)** $0{,}(3)x^2 - \frac{1}{12} = \frac{1}{4} \Rightarrow \frac{1}{3}x^2 = \frac{1}{3} \Rightarrow x^2 = 1 \Rightarrow x = \pm 1$.

* **Mã đề 102:**
  * **a)** $x - 0{,}25 = \frac{3}{4} \Rightarrow x = \frac{3}{4} + \frac{1}{4} = 1$.
  * **b)** $\frac{3}{4}x + 0{,}(3) = \frac{13}{12} \Rightarrow \frac{3}{4}x + \frac{1}{3} = \frac{13}{12} \Rightarrow \frac{3}{4}x = \frac{3}{4} \Rightarrow x = 1$.
  * **c)** $1{,}(4) - \left(x - \frac{2}{3}\right) = \frac{7}{9} \Rightarrow \frac{13}{9} - \left(x - \frac{6}{9}\right) = \frac{7}{9} \Rightarrow x - \frac{2}{3} = \frac{6}{9} \Rightarrow x = \frac{4}{3}$.
  * **d)** $0{,}(6)x^2 - \frac{1}{6} = \frac{1}{2} \Rightarrow \frac{2}{3}x^2 = \frac{2}{3} \Rightarrow x^2 = 1 \Rightarrow x = \pm 1$.

* **Mã đề 103:**
  * **a)** $x - 0{,}6 = \frac{2}{5} \Rightarrow x = \frac{2}{5} + \frac{3}{5} = 1$.
  * **b)** $\frac{4}{5}x + 0{,}(4) = \frac{16}{15} \Rightarrow \frac{4}{5}x + \frac{4}{9} = \frac{16}{15} \Rightarrow \frac{4}{5}x = \frac{28}{45} \Rightarrow x = \frac{7}{9}$.
  * **c)** $1{,}(5) - \left(x - \frac{4}{9}\right) = \frac{8}{9} \Rightarrow \frac{14}{9} - \left(x - \frac{4}{9}\right) = \frac{8}{9} \Rightarrow x - \frac{4}{9} = \frac{6}{9} \Rightarrow x = \frac{10}{9}$.
  * **d)** $0{,}(2)x^2 - \frac{1}{18} = \frac{1}{6} \Rightarrow \frac{2}{9}x^2 = \frac{2}{9} \Rightarrow x^2 = 1 \Rightarrow x = \pm 1$.

* **Mã đề 104:**
  * **a)** $x - 0{,}4 = \frac{3}{5} \Rightarrow x = \frac{3}{5} + \frac{2}{5} = 1$.
  * **b)** $\frac{5}{6}x + 0{,}(5) = \frac{25}{18} \Rightarrow \frac{5}{6}x + \frac{5}{9} = \frac{25}{18} \Rightarrow \frac{5}{6}x = \frac{5}{6} \Rightarrow x = 1$.
  * **c)** $1{,}(7) - \left(x - \frac{5}{9}\right) = \frac{7}{9} \Rightarrow \frac{16}{9} - \left(x - \frac{5}{9}\right) = \frac{7}{9} \Rightarrow x - \frac{5}{9} = 1 \Rightarrow x = \frac{14}{9}$.
  * **d)** $0{,}(5)x^2 - \frac{1}{9} = \frac{4}{9} \Rightarrow \frac{5}{9}x^2 = \frac{5}{9} \Rightarrow x^2 = 1 \Rightarrow x = \pm 1$.

### CÂU 4 (2,5 điểm). Bài toán thực tế
*(Mỗi ý đúng hoàn toàn đạt 1,25 điểm)*

* **Mã đề 101:**
  * **a)** Hóa đơn $164\,800$ đồng. Chữ số hàng trăm là $8 \ge 5$, làm tròn đến hàng nghìn là $165\,000$ đồng.
  * **b)** Giảm $10\%$ khi thanh toán ví điện tử: $164\,800 \times (1 - 0{,}1) = 148\,320$ đồng. Làm tròn đến hàng nghìn (hàng trăm là 3) là $148\,000$ đồng. An tiết kiệm được: $165\,000 - 148\,000 = 17\,000$ đồng.

* **Mã đề 102:**
  * **a)** Hóa đơn $186\,400$ đồng. Chữ số hàng trăm là $4 < 5$, làm tròn đến hàng nghìn là $186\,000$ đồng.
  * **b)** Giảm $10\%$ qua thẻ thành viên: $186\,400 \times 0{,}9 = 167\,760$ đồng. Làm tròn đến hàng nghìn là $168\,000$ đồng. Bình tiết kiệm được: $186\,000 - 168\,000 = 18\,000$ đồng.

* **Mã đề 103:**
  * **a)** Hóa đơn $235\,600$ đồng. Chữ số hàng trăm là $6 \ge 5$, làm tròn đến hàng nghìn là $236\,000$ đồng.
  * **b)** Giảm $10\%$ quét mã QR: $235\,600 \times 0{,}9 = 212\,040$ đồng. Làm tròn đến hàng nghìn là $212\,000$ đồng. Cường tiết kiệm được: $236\,000 - 212\,000 = 24\,000$ đồng.

* **Mã đề 104:**
  * **a)** Hóa đơn $278\,500$ đồng. Chữ số hàng trăm là $5 \ge 5$, làm tròn đến hàng nghìn là $279\,000$ đồng.
  * **b)** Giảm $10\%$ qua thẻ: $278\,500 \times 0{,}9 = 250\,650$ đồng. Làm tròn đến hàng nghìn là $251\,000$ đồng. Dũng tiết kiệm được: $279\,000 - 251\,000 = 28\,000$ đồng.
