### CÂU 3 (2,5 điểm). Tìm số hữu tỉ $x$, biết:
*(Mỗi ý đúng hoàn toàn đạt 0,625 điểm)*

* **Mã đề 101:**
  * **a) (0,625đ):** $x + \dfrac{3}{4} = \dfrac{1}{6} \Rightarrow x = \dfrac{1}{6} - \dfrac{3}{4} = \dfrac{2 - 9}{12} \Rightarrow x = -\dfrac{7}{12}$.
  * **b) (0,625đ):** $\dfrac{3}{4}x - \dfrac{1}{2} = \dfrac{5}{6} \Rightarrow \dfrac{3}{4}x = \dfrac{5}{6} + \dfrac{1}{2} = \dfrac{4}{3} \Rightarrow x = \dfrac{4}{3} : \dfrac{3}{4} = \dfrac{16}{9}$.
  * **c) (0,625đ):** $\left(x - \dfrac{1}{2}\right)^2 = \dfrac{4}{9} \Rightarrow x - \dfrac{1}{2} = \dfrac{2}{3}$ hoặc $x - \dfrac{1}{2} = -\dfrac{2}{3}$.
    * TH1: $x = \dfrac{2}{3} + \dfrac{1}{2} = \dfrac{7}{6}$. *(0,3125đ)*
    * TH2: $x = -\dfrac{2}{3} + \dfrac{1}{2} = -\dfrac{1}{6}$. *(0,3125đ)*
    * Vậy $x \in \left\{\dfrac{7}{6}; -\dfrac{1}{6}\right\}$.
  * **d) (0,625đ):** $\left(x + \dfrac{2}{3}\right)\left(2x - \dfrac{3}{4}\right) = 0 \Rightarrow x + \dfrac{2}{3} = 0$ hoặc $2x - \dfrac{3}{4} = 0$.
    * TH1: $x = -\dfrac{2}{3}$. *(0,3125đ)*
    * TH2: $2x = \dfrac{3}{4} \Rightarrow x = \dfrac{3}{8}$. *(0,3125đ)*
    * Vậy $x \in \left\{-\dfrac{2}{3}; \dfrac{3}{8}\right\}$.

* **Mã đề 102:**
  * **a) (0,625đ):** $x - \dfrac{2}{3} = \dfrac{5}{6} \Rightarrow x = \dfrac{5}{6} + \dfrac{2}{3} = \dfrac{9}{6} = \dfrac{3}{2}$.
  * **b) (0,625đ):** $\dfrac{2}{3}x + \dfrac{1}{4} = -\dfrac{5}{12} \Rightarrow \dfrac{2}{3}x = -\dfrac{5}{12} - \dfrac{1}{4} = -\dfrac{8}{12} = -\dfrac{2}{3} \Rightarrow x = -\dfrac{2}{3} : \dfrac{2}{3} = -1$.
  * **c) (0,625đ):** $\left(x + \dfrac{1}{3}\right)^2 = \dfrac{25}{36} \Rightarrow x + \dfrac{1}{3} = \dfrac{5}{6}$ hoặc $x + \dfrac{1}{3} = -\dfrac{5}{6}$.
    * TH1: $x = \dfrac{5}{6} - \dfrac{1}{3} = \dfrac{3}{6} = \dfrac{1}{2}$. *(0,3125đ)*
    * TH2: $x = -\dfrac{5}{6} - \dfrac{1}{3} = -\dfrac{7}{6}$. *(0,3125đ)*
    * Vậy $x \in \left\{\dfrac{1}{2}; -\dfrac{7}{6}\right\}$.
  * **d) (0,625đ):** $\left(x - \dfrac{3}{5}\right)\left(3x + \dfrac{1}{2}\right) = 0 \Rightarrow x - \dfrac{3}{5} = 0$ hoặc $3x + \dfrac{1}{2} = 0$.
    * TH1: $x = \dfrac{3}{5}$. *(0,3125đ)*
    * TH2: $3x = -\dfrac{1}{2} \Rightarrow x = -\dfrac{1}{6}$. *(0,3125đ)*
    * Vậy $x \in \left\{\dfrac{3}{5}; -\dfrac{1}{6}\right\}$.

* **Mã đề 103:**
  * **a) (0,625đ):** $\dfrac{3}{5} - x = \dfrac{1}{10} \Rightarrow x = \dfrac{3}{5} - \dfrac{1}{10} = \dfrac{5}{10} = \dfrac{1}{2}$.
  * **b) (0,625đ):** $\dfrac{4}{5}x - \dfrac{2}{3} = \dfrac{1}{3} \Rightarrow \dfrac{4}{5}x = \dfrac{1}{3} + \dfrac{2}{3} = 1 \Rightarrow x = 1 : \dfrac{4}{5} = \dfrac{5}{4}$.
  * **c) (0,625đ):** $\left(x - \dfrac{2}{3}\right)^2 = \dfrac{1}{16} \Rightarrow x - \dfrac{2}{3} = \dfrac{1}{4}$ hoặc $x - \dfrac{2}{3} = -\dfrac{1}{4}$.
    * TH1: $x = \dfrac{1}{4} + \dfrac{2}{3} = \dfrac{11}{12}$. *(0,3125đ)*
    * TH2: $x = -\dfrac{1}{4} + \dfrac{2}{3} = \dfrac{5}{12}$. *(0,3125đ)*
    * Vậy $x \in \left\{\dfrac{11}{12}; \dfrac{5}{12}\right\}$.
  * **d) (0,625đ):** $\left(x + \dfrac{4}{7}\right)\left(2x - \dfrac{5}{3}\right) = 0 \Rightarrow x + \dfrac{4}{7} = 0$ hoặc $2x - \dfrac{5}{3} = 0$.
    * TH1: $x = -\dfrac{4}{7}$. *(0,3125đ)*
    * TH2: $2x = \dfrac{5}{3} \Rightarrow x = \dfrac{5}{6}$. *(0,3125đ)*
    * Vậy $x \in \left\{-\dfrac{4}{7}; \dfrac{5}{6}\right\}$.

* **Mã đề 104:**
  * **a) (0,625đ):** $\dfrac{5}{6} - x = \dfrac{1}{4} \Rightarrow x = \dfrac{5}{6} - \dfrac{1}{4} = \dfrac{10 - 3}{12} = \dfrac{7}{12}$.
  * **b) (0,625đ):** $\dfrac{5}{6}x + \dfrac{1}{3} = -\dfrac{1}{2} \Rightarrow \dfrac{5}{6}x = -\dfrac{1}{2} - \dfrac{1}{3} = -\dfrac{5}{6} \Rightarrow x = -\dfrac{5}{6} : \dfrac{5}{6} = -1$.
  * **c) (0,625đ):** $\left(x + \dfrac{1}{4}\right)^2 = \dfrac{9}{25} \Rightarrow x + \dfrac{1}{4} = \dfrac{3}{5}$ hoặc $x + \dfrac{1}{4} = -\dfrac{3}{5}$.
    * TH1: $x = \dfrac{3}{5} - \dfrac{1}{4} = \dfrac{7}{20}$. *(0,3125đ)*
    * TH2: $x = -\dfrac{3}{5} - \dfrac{1}{4} = -\dfrac{17}{20}$. *(0,3125đ)*
    * Vậy $x \in \left\{\dfrac{7}{20}; -\dfrac{17}{20}\right\}$.
  * **d) (0,625đ):** $\left(x - \dfrac{5}{6}\right)\left(4x + \dfrac{2}{3}\right) = 0 \Rightarrow x - \dfrac{5}{6} = 0$ hoặc $4x + \dfrac{2}{3} = 0$.
    * TH1: $x = \dfrac{5}{6}$. *(0,3125đ)*
    * TH2: $4x = -\dfrac{2}{3} \Rightarrow x = -\dfrac{2}{12} = -\dfrac{1}{6}$. *(0,3125đ)*
    * Vậy $x \in \left\{\dfrac{5}{6}; -\dfrac{1}{6}\right\}$.

### CÂU 4 (2,5 điểm). Hình học (Góc gãy khúc giữa hai đường thẳng song song, kẻ tia phụ $Oz$)
*(Mỗi ý đúng hoàn toàn đạt 1,25 điểm)*

* **Cấu trúc thang điểm chuẩn (áp dụng chung 4 mã đề):**
  * **a) (1,25 điểm):**
    * Vẽ qua điểm $O$ tia $Oz \parallel Ax$ (tia $Oz$ nằm trong góc $\widehat{AOB}$, cùng hướng với tia $Ax$). *(0,25đ)*
    * Ta có $Ax \parallel By$ (theo giả thiết) và $Oz \parallel Ax$ (theo cách vẽ). *(0,5đ)*
    * Suy ra $Oz \parallel By$ (tính chất: hai đường thẳng phân biệt cùng song song với đường thẳng thứ ba thì song song với nhau). *(0,5đ)*
  * **b) (1,25 điểm):**
    * Vì $Ax \parallel Oz$ nên $\widehat{AOz} = \widehat{xAO}$ (hai góc so le trong). *(0,5đ)*
    * Vì $By \parallel Oz$ nên $\widehat{BOz} = \widehat{yBO}$ (hai góc so le trong). *(0,375đ)*
    * Vì tia $Oz$ nằm trong góc $\widehat{AOB}$ nên:
      $\widehat{AOB} = \widehat{AOz} + \widehat{BOz}$. *(0,25đ)*
    * Thay số và tính chính xác kết quả $\widehat{AOB}$. *(0,125đ)*

* **Số liệu chi tiết từng mã đề:**
  * **Mã đề 101 ($\widehat{xAO} = 40^\circ, \widehat{yBO} = 50^\circ$):**
    * $\widehat{AOz} = \widehat{xAO} = 40^\circ$ (so le trong).
    * $\widehat{BOz} = \widehat{yBO} = 50^\circ$ (so le trong).
    * $\widehat{AOB} = \widehat{AOz} + \widehat{BOz} = 40^\circ + 50^\circ = 90^\circ$.
  * **Mã đề 102 ($\widehat{xAO} = 35^\circ, \widehat{yBO} = 55^\circ$):**
    * $\widehat{AOz} = \widehat{xAO} = 35^\circ$ (so le trong).
    * $\widehat{BOz} = \widehat{yBO} = 55^\circ$ (so le trong).
    * $\widehat{AOB} = \widehat{AOz} + \widehat{BOz} = 35^\circ + 55^\circ = 90^\circ$.
  * **Mã đề 103 ($\widehat{xAO} = 45^\circ, \widehat{yBO} = 65^\circ$):**
    * $\widehat{AOz} = \widehat{xAO} = 45^\circ$ (so le trong).
    * $\widehat{BOz} = \widehat{yBO} = 65^\circ$ (so le trong).
    * $\widehat{AOB} = \widehat{AOz} + \widehat{BOz} = 45^\circ + 65^\circ = 110^\circ$.
  * **Mã đề 104 ($\widehat{xAO} = 50^\circ, \widehat{yBO} = 60^\circ$):**
    * $\widehat{AOz} = \widehat{xAO} = 50^\circ$ (so le trong).
    * $\widehat{BOz} = \widehat{yBO} = 60^\circ$ (so le trong).
    * $\widehat{AOB} = \widehat{AOz} + \widehat{BOz} = 50^\circ + 60^\circ = 110^\circ$.
