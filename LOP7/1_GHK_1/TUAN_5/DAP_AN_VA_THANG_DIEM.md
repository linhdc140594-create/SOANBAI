  * **b)** $\dfrac{13}{17} \cdot |-2{,}4| + \dfrac{4}{17} \cdot 2{,}4 = \left(\dfrac{13}{17} + \dfrac{4}{17}\right) \cdot 2{,}4 = 1 \cdot 2{,}4 = 2{,}4 = \dfrac{12}{5}$. *(0,625đ)*

  * **d)** $\dfrac{5}{6} : \left[\dfrac{2}{3} - \left(0{,}75 - \left|-\dfrac{1}{2}\right|\right)\right] = \dfrac{5}{6} : \left[\dfrac{2}{3} - \left(\dfrac{3}{4} - \dfrac{1}{2}\right)\right] = \dfrac{5}{6} : \left[\dfrac{2}{3} - \dfrac{1}{4}\right] = \dfrac{5}{6} : \dfrac{5}{12} = \dfrac{5}{6} \cdot \dfrac{12}{5} = 2$. *(0,625đ)*

### CÂU 3 (2,5 điểm). Tìm số thực $x$, biết:
*(Mỗi ý đúng hoàn toàn đạt 0,625 điểm)*

* **Mã đề 101:**
  * **a)** $|x| - \dfrac{3}{4} = \dfrac{1}{2} \Rightarrow |x| = \dfrac{1}{2} + \dfrac{3}{4} = \dfrac{5}{4} \Rightarrow x = \dfrac{5}{4}$ hoặc $x = -\dfrac{5}{4}$. *(0,625đ)*
  * **b)** $\left|x - \dfrac{1}{2}\right| = \dfrac{3}{4} \Rightarrow x - \dfrac{1}{2} = \dfrac{3}{4}$ hoặc $x - \dfrac{1}{2} = -\dfrac{3}{4} \Rightarrow x = \dfrac{5}{4}$ hoặc $x = -\dfrac{1}{4}$. *(0,625đ)*
  * **c)** $2\left|x + \dfrac{1}{3}\right| - \dfrac{1}{2} = \dfrac{5}{6} \Rightarrow 2\left|x + \dfrac{1}{3}\right| = \dfrac{4}{3} \Rightarrow \left|x + \dfrac{1}{3}\right| = \dfrac{2}{3} \Rightarrow x = \dfrac{1}{3}$ hoặc $x = -1$. *(0,625đ)*
  * **d)** $\left|2x - \dfrac{1}{5}\right| = \dfrac{4}{5}$:
    * TH1: $2x - \dfrac{1}{5} = \dfrac{4}{5} \Rightarrow 2x = 1 \Rightarrow x = \dfrac{1}{2}$.
    * TH2: $2x - \dfrac{1}{5} = -\dfrac{4}{5} \Rightarrow 2x = -\dfrac{3}{5} \Rightarrow x = -\dfrac{3}{10}$.
    * Vậy $x \in \left\{\dfrac{1}{2}; -\dfrac{3}{10}\right\}$. *(0,625đ)*

* **Mã đề 102:**
  * **a)** $|x| - \dfrac{2}{3} = \dfrac{1}{6} \Rightarrow |x| = \dfrac{1}{6} + \dfrac{2}{3} = \dfrac{5}{6} \Rightarrow x = \pm\dfrac{5}{6}$. *(0,625đ)*
  * **b)** $\left|x - \dfrac{1}{3}\right| = \dfrac{2}{3} \Rightarrow x - \dfrac{1}{3} = \dfrac{2}{3}$ hoặc $x - \dfrac{1}{3} = -\dfrac{2}{3} \Rightarrow x = 1$ hoặc $x = -\dfrac{1}{3}$. *(0,625đ)*
  * **c)** $3\left|x + \dfrac{1}{4}\right| - \dfrac{1}{2} = 1 \Rightarrow 3\left|x + \dfrac{1}{4}\right| = \dfrac{3}{2} \Rightarrow \left|x + \dfrac{1}{4}\right| = \dfrac{1}{2} \Rightarrow x = \dfrac{1}{4}$ hoặc $x = -\dfrac{3}{4}$. *(0,625đ)*
  * **d)** $\left|2x - \dfrac{1}{3}\right| = \dfrac{5}{3} \Rightarrow 2x - \dfrac{1}{3} = \dfrac{5}{3} \Rightarrow 2x = 2 \Rightarrow x = 1$ hoặc $2x - \dfrac{1}{3} = -\dfrac{5}{3} \Rightarrow 2x = -\dfrac{4}{3} \Rightarrow x = -\dfrac{2}{3}$. *(0,625đ)*

* **Mã đề 103:**
  * **a)** $|x| - \dfrac{1}{2} = \dfrac{2}{5} \Rightarrow |x| = \dfrac{2}{5} + \dfrac{1}{2} = \dfrac{9}{10} \Rightarrow x = \pm\dfrac{9}{10}$. *(0,625đ)*
  * **b)** $\left|x - \dfrac{2}{5}\right| = \dfrac{3}{5} \Rightarrow x - \dfrac{2}{5} = \dfrac{3}{5}$ hoặc $x - \dfrac{2}{5} = -\dfrac{3}{5} \Rightarrow x = 1$ hoặc $x = -\dfrac{1}{5}$. *(0,625đ)*
  * **c)** $2\left|x + \dfrac{1}{2}\right| - \dfrac{3}{4} = \dfrac{3}{4} \Rightarrow 2\left|x + \dfrac{1}{2}\right| = \dfrac{3}{2} \Rightarrow \left|x + \dfrac{1}{2}\right| = \dfrac{3}{4} \Rightarrow x = \dfrac{1}{4}$ hoặc $x = -\dfrac{5}{4}$. *(0,625đ)*
  * **d)** $\left|2x - \dfrac{1}{4}\right| = \dfrac{7}{4} \Rightarrow 2x - \dfrac{1}{4} = \dfrac{7}{4} \Rightarrow 2x = 2 \Rightarrow x = 1$ hoặc $2x - \dfrac{1}{4} = -\dfrac{7}{4} \Rightarrow 2x = -\dfrac{3}{2} \Rightarrow x = -\dfrac{3}{4}$. *(0,625đ)*

* **Mã đề 104:**
  * **a)** $|x| - \dfrac{3}{5} = \dfrac{1}{10} \Rightarrow |x| = \dfrac{1}{10} + \dfrac{3}{5} = \dfrac{7}{10} \Rightarrow x = \pm\dfrac{7}{10}$. *(0,625đ)*
  * **b)** $\left|x - \dfrac{3}{4}\right| = \dfrac{1}{4} \Rightarrow x - \dfrac{3}{4} = \dfrac{1}{4}$ hoặc $x - \dfrac{3}{4} = -\dfrac{1}{4} \Rightarrow x = 1$ hoặc $x = \dfrac{1}{2}$. *(0,625đ)*
  * **c)** $4\left|x + \dfrac{1}{5}\right| - \dfrac{2}{3} = \dfrac{1}{3} \Rightarrow 4\left|x + \dfrac{1}{5}\right| = 1 \Rightarrow \left|x + \dfrac{1}{5}\right| = \dfrac{1}{4} \Rightarrow x = \dfrac{1}{20}$ hoặc $x = -\dfrac{9}{20}$. *(0,625đ)*
  * **d)** $\left|2x - \dfrac{1}{2}\right| = \dfrac{3}{2} \Rightarrow 2x - \dfrac{1}{2} = \dfrac{3}{2} \Rightarrow 2x = 2 \Rightarrow x = 1$ hoặc $2x - \dfrac{1}{2} = -\dfrac{3}{2} \Rightarrow 2x = -1 \Rightarrow x = -\dfrac{1}{2}$. *(0,625đ)*
