### 🔹 CÂU 13 (2,0 ĐIỂM): BÀI TOÁN HÌNH HỌC (GÓC GÃY KHÚC & TIÊN ĐỀ EUCLID)

#### Mã đề 101:
* **a) (1,0 điểm):**
  - Vì $Ax \parallel By$ (theo giả thiết) và $Oz \parallel Ax$ (theo cách vẽ). *(0,5đ)*
  - Áp dụng tính chất: Hai đường thẳng phân biệt cùng song song với đường thẳng thứ ba thì song song với nhau. Suy ra $Oz \parallel By$. *(0,5đ)*
* **b) (1,0 điểm):**
  - Vì $Oz \parallel Ax$, nên $\widehat{AOz} = \widehat{xAO} = 40^\circ$ (hai góc so le trong). *(0,25đ)*
  - Vì $Oz \parallel By$, nên $\widehat{BOz} = \widehat{yBO} = 50^\circ$ (hai góc so le trong). *(0,25đ)*
  - Vì tia $Oz$ nằm giữa hai tia $OA$ và $OB$ nên:
    $$\widehat{AOB} = \widehat{AOz} + \widehat{BOz} = 40^\circ + 50^\circ = 90^\circ \quad (0{,}5\text{đ})$$

#### Mã đề 102:

### 🔹 CÂU 14 (0,5 ĐIỂM): VẬN DỤNG CAO ĐIỂM 10 (BẤT ĐẲNG THỨC GIÁ TRỊ TUYỆT ĐỐI)

#### Mã đề 101:
* Ta có: $A = |2026 - x| + |x - 2|$.
* Áp dụng bất đẳng thức $|A| + |B| \ge |A + B|$, ta có:
  $$A = |2026 - x| + |x - 2| \ge |(2026 - x) + (x - 2)| = |2024| = 2024 \quad (0{,}25\text{đ})$$
* Dấu "$=$" xảy ra khi $(2026 - x)(x - 2) \ge 0 \iff 2 \le x \le 2026$.
* Vậy giá trị nhỏ nhất của $A$ là $2024$ khi $2 \le x \le 2026$. *(0,25đ)*

#### Mã đề 102:
* $A = |2025 - x| + |x - 1| \ge |2025 - x + x - 1| = 2024$.
* Dấu "$=$" xảy ra khi $1 \le x \le 2025$. Vậy $\min A = 2024$ khi $1 \le x \le 2025$.

#### Mã đề 103:
* $A = |2026 - x| + |x - 6| \ge |2026 - x + x - 6| = 2020$.
* Dấu "$=$" xảy ra khi $6 \le x \le 2026$. Vậy $\min A = 2020$ khi $6 \le x \le 2026$.

#### Mã đề 104:
* $A = |2024 - x| + |x - 4| \ge |2024 - x + x - 4| = 2020$.
* Dấu "$=$" xảy ra khi $4 \le x \le 2024$. Vậy $\min A = 2020$ khi $4 \le x \le 2024$.
