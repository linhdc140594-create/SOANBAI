### CÂU 12 (2,0 ĐIỂM): TÌM SỐ HỮU TỈ $x$ (MỖI Ý 0,5 ĐIỂM)

#### Mã đề 101:
* **a)** $x - \dfrac{2}{5} = \dfrac{7}{10} \iff x = \dfrac{7}{10} + \dfrac{4}{10} \iff x = \dfrac{11}{10}$ *(0,5 đ)*.
* **b)** $\dfrac{3}{4}x + \dfrac{1}{2} = \dfrac{7}{8} \iff \dfrac{3}{4}x = \dfrac{7}{8} - \dfrac{4}{8} = \dfrac{3}{8} \iff x = \dfrac{3}{8} : \dfrac{3}{4} = \dfrac{1}{2}$ *(0,5 đ)*.
* **c)** $\left(x - \dfrac{1}{2}\right)^2 = \dfrac{9}{25} \iff x - \dfrac{1}{2} = \dfrac{3}{5}$ hoặc $x - \dfrac{1}{2} = -\dfrac{3}{5}$.
  Suy ra $x = \dfrac{11}{10}$ hoặc $x = -\dfrac{1}{10}$ *(0,5 đ)*.
* **d)** $\left|2x - \dfrac{1}{3}\right| = \dfrac{5}{3} \iff 2x - \dfrac{1}{3} = \dfrac{5}{3}$ hoặc $2x - \dfrac{1}{3} = -\dfrac{5}{3}$.
  Suy ra $2x = 2 \implies x = 1$ hoặc $2x = -\dfrac{4}{3} \implies x = -\dfrac{2}{3}$ *(0,5 đ)*.

### CÂU 13 (2,0 ĐIỂM): HÌNH HỌC CHỨNG MINH C-C-C & TIA PHÂN GIÁC

#### Mã đề 101:
* **a) (1,0 điểm):**
  - Xét $\Delta OAC$ và $\Delta OBC$, ta có:
    * $OA = OB$ (theo giả thiết) *(0,25 đ)*
    * $AC = BC$ (theo giả thiết) *(0,25 đ)*
    * $OC$ là cạnh chung *(0,25 đ)*
  - Suy ra $\Delta OAC = \Delta OBC$ (c.c.c) *(0,25 đ)*.
* **b) (1,0 điểm):**
  - Do $\Delta OAC = \Delta OBC \implies \widehat{AOC} = \widehat{BOC}$ (hai góc tương ứng) *(0,25 đ)*.
  - Mà tia $OC$ nằm bên trong góc $\widehat{xOy}$ *(0,25 đ)*,
  - Nên $OC$ là tia phân giác của góc $\widehat{xOy}$ *(0,25 đ)*.
  - Với $\widehat{xOy} = 70^\circ$, ta có: $\widehat{AOC} = \dfrac{\widehat{xOy}}{2} = \dfrac{70^\circ}{2} = 35^\circ$ *(0,25 đ)*.

### CÂU 14 (0,5 ĐIỂM): VẬN DỤNG CAO ĐIỂM 10 (BẤT ĐẲNG THỨC GIÁ TRỊ TUYỆT ĐỐI)

#### Mã đề 101:
* Áp dụng bất đẳng thức $|A| + |B| \ge |A + B|$, ta có:
  $$A = |x - 2026| + |x - 10| = |x - 2026| + |10 - x| \ge |(x - 2026) + (10 - x)| = |-2016| = 2016 \quad (0{,}25 \text{ đ})$$
* Dấu "$=$" xảy ra khi $(x - 2026)(10 - x) \ge 0 \iff 10 \le x \le 2026$.
  Vậy giá trị nhỏ nhất của $A$ là $2016$ khi $10 \le x \le 2026$ *(0,25 đ)*.

#### Mã đề 102:
* $A = |x - 2025| + |15 - x| \ge |x - 2025 + 15 - x| = |-2010| = 2010$ *(0,25 đ)*.
* Dấu "$=$" xảy ra khi $15 \le x \le 2025$. Vậy $\min A = 2010$ *(0,25 đ)*.

#### Mã đề 103:
* $A = |x - 2024| + |20 - x| \ge |x - 2024 + 20 - x| = |-2004| = 2004$ *(0,25 đ)*.
* Dấu "$=$" xảy ra khi $20 \le x \le 2024$. Vậy $\min A = 2004$ *(0,25 đ)*.

#### Mã đề 104:
* $A = |x - 2023| + |25 - x| \ge |x - 2023 + 25 - x| = |-1998| = 1998$ *(0,25 đ)*.
* Dấu "$=$" xảy ra khi $25 \le x \le 2023$. Vậy $\min A = 1998$ *(0,25 đ)*.
