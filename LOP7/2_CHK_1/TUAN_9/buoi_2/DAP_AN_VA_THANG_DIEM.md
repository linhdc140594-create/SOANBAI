### CÂU 12 (2,0 ĐIỂM): TÌM SỐ HỮU TỈ $x$ (MỖI Ý 0,5 ĐIỂM)

* **b)** $\dfrac{3}{4}x - \dfrac{1}{3} = \dfrac{5}{12} \iff \dfrac{3}{4}x = \dfrac{5}{12} + \dfrac{4}{12} = \dfrac{9}{12} = \dfrac{3}{4} \iff x = 1$ *(0,5 đ)*.
* **c)** $\left(x + \dfrac{1}{2}\right)^2 = \dfrac{9}{16} \iff x + \dfrac{1}{2} = \pm \dfrac{3}{4}$.
  Suy ra $x = \dfrac{3}{4} - \dfrac{2}{4} = \dfrac{1}{4}$ hoặc $x = -\dfrac{3}{4} - \dfrac{2}{4} = -\dfrac{5}{4}$ *(0,5 đ)*.
* **d)** $\left|3x - \dfrac{1}{4}\right| = \dfrac{5}{4} \iff 3x - \dfrac{1}{4} = \dfrac{5}{4}$ hoặc $3x - \dfrac{1}{4} = -\dfrac{5}{4}$.
  Suy ra $3x = \dfrac{6}{4} = \dfrac{3}{2} \implies x = \dfrac{1}{2}$ hoặc $3x = -1 \implies x = -\dfrac{1}{3}$ *(0,5 đ)*.

### CÂU 13 (2,0 ĐIỂM): HÌNH HỌC VỀ GÓC NGOÀI & TIA PHÂN GIÁC

#### Mã đề 101:
* **a) (1,0 điểm):**
  - Trong $\Delta ABC$, ta có: $\widehat{B} + \widehat{C} = 180^\circ - \widehat{A} = 180^\circ - 80^\circ = 100^\circ$ *(0,25 đ)*.
  - Vì $BI, CI$ lần lượt là tia phân giác của $\widehat{B}$ và $\widehat{C}$ nên:
    $$\widehat{IBC} + \widehat{ICB} = \dfrac{\widehat{B}}{2} + \dfrac{\widehat{C}}{2} = \dfrac{\widehat{B} + \widehat{C}}{2} = \dfrac{100^\circ}{2} = 50^\circ \quad (0{,}25\text{ đ})$$
  - Xét $\Delta IBC$, ta có:
    $$\widehat{BIC} = 180^\circ - (\widehat{IBC} + \widehat{ICB}) = 180^\circ - 50^\circ = 130^\circ \quad (0{,}5\text{ đ})$$
* **b) (1,0 điểm):**
  - Hai góc ngoài tại đỉnh $B$ và $C$ lần lượt kề bù với $\widehat{B}$ và $\widehat{C}$, do đó:
    $$\widehat{x'BC} + \widehat{y'CB} = (180^\circ - \widehat{B}) + (180^\circ - \widehat{C}) = 360^\circ - (\widehat{B} + \widehat{C}) = 360^\circ - 100^\circ = 260^\circ \quad (0{,}25\text{ đ})$$
  - Vì $BK, CK$ lần lượt là phân giác của hai góc ngoài nên:
    $$\widehat{KBC} + \widehat{KCB} = \dfrac{\widehat{x'BC} + \widehat{y'CB}}{2} = \dfrac{260^\circ}{2} = 130^\circ \quad (0{,}25\text{ đ})$$
  - Xét $\Delta KBC$, ta có:
    $$\widehat{BKC} = 180^\circ - (\widehat{KBC} + \widehat{KCB}) = 180^\circ - 130^\circ = 50^\circ \quad (0{,}5\text{ đ})$$

#### Mã đề 102:
* **a)** $\widehat{B} + \widehat{C} = 180^\circ - 70^\circ = 110^\circ \implies \widehat{IBC} + \widehat{ICB} = 55^\circ \implies \widehat{BIC} = 180^\circ - 55^\circ = 125^\circ$ *(1,0 đ)*.
* **b)** Tổng hai góc ngoài $= 360^\circ - 110^\circ = 250^\circ \implies \widehat{KBC} + \widehat{KCB} = 125^\circ \implies \widehat{BKC} = 180^\circ - 125^\circ = 55^\circ$ *(1,0 đ)*.

#### Mã đề 103:
* **a)** $\widehat{B} + \widehat{C} = 180^\circ - 60^\circ = 120^\circ \implies \widehat{IBC} + \widehat{ICB} = 60^\circ \implies \widehat{BIC} = 180^\circ - 60^\circ = 120^\circ$ *(1,0 đ)*.
* **b)** Tổng hai góc ngoài $= 360^\circ - 120^\circ = 240^\circ \implies \widehat{KBC} + \widehat{KCB} = 120^\circ \implies \widehat{BKC} = 180^\circ - 120^\circ = 60^\circ$ *(1,0 đ)*.

#### Mã đề 104:
* **a)** $\widehat{B} + \widehat{C} = 180^\circ - 90^\circ = 90^\circ \implies \widehat{IBC} + \widehat{ICB} = 45^\circ \implies \widehat{BIC} = 180^\circ - 45^\circ = 135^\circ$ *(1,0 đ)*.
* **b)** Tổng hai góc ngoài $= 360^\circ - 90^\circ = 270^\circ \implies \widehat{KBC} + \widehat{KCB} = 135^\circ \implies \widehat{BKC} = 180^\circ - 135^\circ = 45^\circ$ *(1,0 đ)*.

### CÂU 14 (0,5 ĐIỂM): VẬN DỤNG CAO ĐIỂM 10 (GTLN CỦA PHÂN THỨC CHỨA GIÁ TRỊ TUYỆT ĐỐI)

#### Mã đề 101:
* Vì $|x - 3| \ge 0$ với mọi $x \in \mathbb{R}$ nên $|x - 3| + 4 \ge 4$.
  Suy ra:
  $$B = \dfrac{12}{|x - 3| + 4} \le \dfrac{12}{4} = 3 \quad (0{,}25\text{ đ})$$
* Dấu "$=$" xảy ra khi $|x - 3| = 0 \iff x = 3$.
  Vậy giá trị lớn nhất của biểu thức $B$ là $3$ khi $x = 3$ *(0,25 đ)*.

#### Mã đề 102:
* $|x - 5| \ge 0 \implies |x - 5| + 3 \ge 3 \implies B = \dfrac{15}{|x - 5| + 3} \le \dfrac{15}{3} = 5$ *(0,25 đ)*.
* Dấu "$=$" xảy ra khi $x = 5$. Vậy $\max B = 5$ khi $x = 5$ *(0,25 đ)*.

#### Mã đề 103:
* $|x - 2| \ge 0 \implies |x - 2| + 6 \ge 6 \implies B = \dfrac{18}{|x - 2| + 6} \le \dfrac{18}{6} = 3$ *(0,25 đ)*.
* Dấu "$=$" xảy ra khi $x = 2$. Vậy $\max B = 3$ khi $x = 2$ *(0,25 đ)*.

#### Mã đề 104:
* $|x - 4| \ge 0 \implies |x - 4| + 5 \ge 5 \implies B = \dfrac{20}{|x - 4| + 5} \le \dfrac{20}{5} = 4$ *(0,25 đ)*.
* Dấu "$=$" xảy ra khi $x = 4$. Vậy $\max B = 4$ khi $x = 4$ *(0,25 đ)*.
