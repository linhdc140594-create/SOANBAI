### CÂU 12 (2,0 ĐIỂM): TÌM SỐ HỮU TỈ $x$ (MỖI Ý 0,5 ĐIỂM)

#### Mã đề 101:
* **a)** $x - \dfrac{3}{5} = \dfrac{7}{10} \iff x = \dfrac{7}{10} + \dfrac{6}{10} \iff x = \dfrac{13}{10}$ *(0,5 đ)*.
* **b)** $\dfrac{2}{3}x + \dfrac{1}{2} = \dfrac{5}{6} \iff \dfrac{2}{3}x = \dfrac{5}{6} - \dfrac{3}{6} = \dfrac{1}{3} \iff x = \dfrac{1}{3} : \dfrac{2}{3} = \dfrac{1}{2}$ *(0,5 đ)*.
* **c)** $\left(x - \dfrac{1}{3}\right)^2 = \dfrac{4}{9} \iff x - \dfrac{1}{3} = \dfrac{2}{3}$ hoặc $x - \dfrac{1}{3} = -\dfrac{2}{3}$.
  Suy ra $x = 1$ hoặc $x = -\dfrac{1}{3}$ *(0,5 đ)*.
* **d)** $\left|2x - \dfrac{1}{2}\right| = \dfrac{3}{2} \iff 2x - \dfrac{1}{2} = \dfrac{3}{2}$ hoặc $2x - \dfrac{1}{2} = -\dfrac{3}{2}$.
  Suy ra $2x = 2 \implies x = 1$ hoặc $2x = -1 \implies x = -\dfrac{1}{2}$ *(0,5 đ)*.

#### Mã đề 102:

### CÂU 13 (2,0 ĐIỂM): HÌNH HỌC TAM GIÁC VUÔNG, ĐƯỜNG CAO & PHÂN GIÁC

#### Mã đề 101:
* **a) (1,0 điểm):**
  - Xét $\Delta ABC$ vuông tại $A$, ta có: $\widehat{B} + \widehat{C} = 90^\circ$ *(0,25 đ)*.
    $\implies \widehat{C} = 90^\circ - \widehat{B} = 90^\circ - 60^\circ = 30^\circ$ *(0,25 đ)*.
  - Xét $\Delta ABH$ vuông tại $H$, ta có: $\widehat{HAB} + \widehat{B} = 90^\circ$ *(0,25 đ)*.
    $\implies \widehat{HAB} = 90^\circ - \widehat{B} = 90^\circ - 60^\circ = 30^\circ$ *(0,25 đ)*.
* **b) (1,0 điểm):**
  - Xét $\Delta AHC$ vuông tại $H$, ta có: $\widehat{HAC} = 90^\circ - \widehat{C} = 90^\circ - 30^\circ = 60^\circ$.
    Vì $AD$ là tia phân giác của $\widehat{HAC}$ nên:
    $\widehat{HAD} = \widehat{DAC} = \dfrac{\widehat{HAC}}{2} = \dfrac{60^\circ}{2} = 30^\circ$ *(0,25 đ)*.
  - Ta có: $\widehat{BAD} = \widehat{BAH} + \widehat{HAD} = 30^\circ + 30^\circ = 60^\circ$ *(0,25 đ)*.
  - Xét $\Delta ADC$, góc $\widehat{BDA}$ là góc ngoài tại đỉnh $D$ nên:
    $\widehat{BDA} = \widehat{DAC} + \widehat{C} = 30^\circ + 30^\circ = 60^\circ$ *(0,25 đ)*.
  - Do đó: $\widehat{BAD} = \widehat{BDA} = 60^\circ$ (ĐPCM) *(0,25 đ)*.

#### Mã đề 102:

* **b)** $\widehat{HAC} = 50^\circ \implies \widehat{HAD} = \widehat{DAC} = 25^\circ$.
  $\widehat{BAD} = 40^\circ + 25^\circ = 65^\circ$. $\widehat{BDA} = 25^\circ + 40^\circ = 65^\circ \implies \widehat{BAD} = \widehat{BDA} = 65^\circ$ *(1,0 đ)*.

### CÂU 14 (0,5 ĐIỂM): VẬN DỤNG CAO ĐIỂM 10 (BẤT ĐẲNG THỨC GIÁ TRỊ TUYỆT ĐỐI)

#### Mã đề 101:
* Ta có: $A = |x - 2026| + |x - 2| = |x - 2026| + |2 - x|$.
  Áp dụng bất đẳng thức $|a| + |b| \ge |a + b|$, ta được:
  $$A \ge |(x - 2026) + (2 - x)| = |-2024| = 2024 \quad (0{,}25\text{ đ})$$
* Dấu "$=$" xảy ra khi $(x - 2026)(2 - x) \ge 0 \iff 2 \le x \le 2026$.
  Vậy giá trị nhỏ nhất của $A$ là $2024$ khi $2 \le x \le 2026$ *(0,25 đ)*.

#### Mã đề 102:
* $A = |x - 2025| + |3 - x| \ge |x - 2025 + 3 - x| = 2022$ *(0,25 đ)*.
* Dấu "$=$" xảy ra khi $3 \le x \le 2025$. Vậy $\min A = 2022$ *(0,25 đ)*.

#### Mã đề 103:
* $A = |x - 2024| + |4 - x| \ge |x - 2024 + 4 - x| = 2020$ *(0,25 đ)*.
* Dấu "$=$" xảy ra khi $4 \le x \le 2024$. Vậy $\min A = 2020$ *(0,25 đ)*.

#### Mã đề 104:
* $A = |x - 2023| + |5 - x| \ge |x - 2023 + 5 - x| = 2018$ *(0,25 đ)*.
* Dấu "$=$" xảy ra khi $5 \le x \le 2023$. Vậy $\min A = 2018$ *(0,25 đ)*.
